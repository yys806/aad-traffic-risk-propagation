## 1. 项目在研究什么

项目关注**混合自动驾驶交通中的车辆级碰撞冲突风险及其关系解释**。

当前最基本的问题是：当一辆车出现急刹、低 TTC、低 THW 等碰撞前风险状态后，后续车辆是否会出现相关风险；这种联系能否由相邻车辆逐步传递、共同交通状态、感知/通信信息或统一控制解释；改变上游车辆后，下游车辆的风险是否会稳定变化。

研究最终希望回答三个层次的问题：

1. 风险事件是什么，怎样从车辆轨迹中可靠提取。
2. 不同车辆或不同时刻的风险事件为什么会联系起来。
3. 哪些联系只是相关，哪些能够通过干预获得因果证据。

这个方向仍允许重新凝练。新对话可以提出新的问题表述、事件定义、因果框架和实验方案，不要因为已有代码就默认方法已经确定。

## 2. 老师提出的两个核心问题

### 2.1 创新点需要从已有文献中提炼

现有研究已经包括交通冲突风险图、因果风险预测、相邻车辆级联风险和非局部交通流。项目需要说清楚：

- 已有工作研究到哪里；
- 本项目与它们的差异是什么；
- “远距离关系”是否只是普通多跳传播；
- 是否存在可观察、可干预、可证伪的交通机制。

### 2.2 风险必须有明确范围

当前工作定义为：

**混合自动驾驶场景中，跟驰或合流车辆持续接近，按当前运动状态继续行驶可能发生追尾，因此至少一辆车需要制动或调整轨迹的碰撞前交通冲突。**

具体边界：

- 碰撞前的追尾型冲突是当前主要研究对象。
- 实际碰撞作为事故结果记录。
- 事故后的停车、道路占用和排队属于事故后果。
- 低速排队但车间距稳定时属于拥堵，不记为碰撞风险事件。
- 拥堵仍可作为场景背景、共同原因或副作用控制。
- 急刹只有同时形成持续碰撞接近时才纳入冲突分析。

这个定义解决了当前汇报中的范围问题，但以后仍可讨论是否加入换道冲突、危险合流、侧向碰撞或其他事故类型。若扩展范围，需要重新定义事件和指标，不能直接混在现有追尾事件中。

## 3. 相关文献脉络

目前文献按以下方向理解：

1. **交通冲突风险图与因果预测**  
   Wang 等用风险图描述冲突事件的时空演化；Lyu 等在高速公路分流区构建因果图进行实时冲突预测。它们主要解决风险表征和预测问题。

2. **相邻车辆级联风险**  
   Luo 等结合 TTC、DRAC 和前后车状态构造级联风险度量，研究风险在连续车队中的累积，主要属于局部逐跳关系。

3. **非局部交通流**  
   Huang 和 Du、Sun 和 Tan、Friedrich 等研究车辆利用前方一定范围内信息的规则，以及这些规则对速度、密度和交通流稳定性的影响。研究尺度主要是交通流，不是单车碰撞冲突事件。

4. **拥堵波传播**  
   Guan 等研究混合交通中低速和拥堵状态如何形成并传播。该方向与碰撞冲突有关联，但风险定义和研究目标不同。

5. **量子相关文献**  
   Brunner 等的 Bell 非局部性综述讨论量子测量之间无法由局域隐变量解释的统计相关；Song 等使用量子概率描述自动驾驶决策中的犹豫和不确定性。两类工作都不能证明经典车辆之间存在量子作用。

量子文献当前只承担两种作用：

- 提供“远距离相关需要排除局部解释和共同原因”的概念启发；
- 提供描述决策不确定性的备选数学视角。

是否继续保留量子视角是开放问题。论文不能把 Bell 非局部性直接当作交通传播机制；车辆关系仍需由感知、通信、道路环境、集中控制或其他可测机制解释。

文献总表及本地 PDF 位于 `literature/`。

## 4. 当前实验平台与数据

当前正式分析只使用 DRIFT 轨迹。这里的 DRIFT 是现阶段可用的平台，不代表后续必须只使用 DRIFT，也不代表 DRIFT 优于其他控制方法。

DRIFT 当前可用的依据：

- 90 次正式运行可以稳定输出车辆状态；
- 原始必要字段和车道元数据完整；
- 可以提取风险事件、建立局部关系并完成时间置换；
- 支持固定随机种子后重新运行，为闭环干预提供基础。

正式反事实干预还没有完成，因此只能说“DRIFT 已满足当前数据分析和下一步实验的基本要求”。

### 4.1 数据范围

- 3 个场景：`ring`、`figure8`、`merge`
- 6 种自动驾驶渗透率
- 每个场景共 30 次运行
- DRIFT 轨迹文件：90 个
- 状态记录：542,644 条
- 累计车辆时间：26.52 车辆小时

车辆小时的实现不是程序运行时间。代码对每个文件计算：

```text
车辆时间 = 状态记录行数 × 该文件时间步长
```

具体为：

| 场景 | 状态记录 | 时间步 | 车辆时间 |
|---|---:|---:|---:|
| figure8 | 50,820 | 0.1 s | 5,082 s |
| ring | 79,860 | 0.1 s | 7,986 s |
| merge | 411,964 | 0.2 s | 82,392.8 s |

总计 `95,460.8 / 3600 = 26.5169` 车辆小时，四舍五入为 26.52。

### 4.2 原始车辆状态

原始 emission 字段包括：

- 时间和车辆：`time`、`id`
- 位置：`x`、`y`、`edge_id`、`lane_number`
- 运动状态：`speed`、`realized_accel`
- 跟驰关系：`headway`、`leader_id`、`follower_id`、`leader_rel_speed`
- 其他字段：`distance`、`relative_position`、`road_grade`
- DRIFT 控制诊断：四种噪声/安全保护组合下的目标加速度

当前代码进一步得到：

- 车道标识：`edge_id:lane_number`
- 闭合速度：`-leader_rel_speed`
- TTC：`headway / closing_speed`
- THW：`headway / speed`
- 每 50 m 一个局部区域
- 事件前后帧的速度、加速度、间距、前车和车道变化

**DRAC 已在文档中定义，但当前事件提取代码还没有正式计算和使用 DRAC。** 后续若把 DRAC 写成实验指标，必须先补充实现、测试和结果。

## 5. 当前风险事件数据

当前 DRIFT 数据处理结果：

```text
1,745 条逐帧风险检测
    ↓ 连续帧合并
508 个事件片段
    ↓ 去除 105 个 SUMO 安全速度覆盖候选
403 个普通风险片段
    ↓ 去除 21 个车辆记录边界片段
382 个最终分析事件
```

逐帧检测包括低 TTC、临界 TTC、低 THW、普通急刹、near-miss 和安全速度覆盖候选。同一车辆在同一危险过程中可能触发多个指标，因此同车不同类型事件可能重复描述同一物理过程。这是后续需要检查的问题。

当前事件阈值：

- TTC 不超过 2 s：低 TTC 候选
- TTC 不超过 1 s：临界 TTC
- THW 不超过 1 s：近距离跟驰
- 加速度不超过 `-3 m/s²`：明显制动
- 加速度低于 `-15 m/s²`：SUMO 安全速度覆盖候选，单独排除

这些阈值是当前基线设置，可以通过敏感性分析重新选择。

## 6. 当前局部关系基线

风险事件被看作节点，事件之间满足时间、空间和车辆关系条件时建立有向边。

当前局部条件：

- 源事件早于目标事件；
- 时间差不超过 3 s；
- 同一区域关系的纵向距离不超过 50 m；
- 关系类型包括同车连续、前车到后车、后车到前车和同区域关系；
- 每个目标事件只保留评分最高的一个局部前驱。

当前结果：

| 统计项 | 结果 |
|---|---:|
| 候选局部边 | 355 |
| 最终一跳边 | 196 |
| 同车连续关系 | 100 |
| 前车到后车关系 | 90 |
| 同区域关系 | 6 |
| 跨车辆一跳边 | 96（49.0%） |
| 传播链 | 186 |
| 多跳链 | 33 |
| 最大深度 | 4 条边 |

术语解释：

- **一跳**：两个事件由一条边直接连接，如“前车急刹 → 后车低 TTC”。
- **多跳**：多条一跳边首尾相接，如 `E1 → E2 → E3`。
- **同车关系**：同一辆车的风险状态随时间发展，如“低 THW → 低 TTC → 急刹”。
- **远距离候选关系**：局部基线无法解释、没有连续中间传播链，但仍存在稳定联系的事件对。
- **候选**：值得验证的关联，还不是因果关系。

目前的多跳链可以混合同车关系和跨车辆关系，不能直接解释成风险经过多辆车传播。尤其需要检查同一物理冲突被低 THW、低 TTC 和急刹分别记录后形成的伪多跳。

## 7. 时间置换、负对照与反事实

### 7.1 已完成：时间置换

每次运行保留单辆车自己的事件数量和相对时间结构，只把整段事件时间随机循环平移，再按同一规则重建跨车辆边。每个运行置换 100 次。

该检验主要排除“事件只是碰巧在相近时间发生”。

结果：

- merge：30 次运行中 5 次达到 `p <= 0.05`
- figure-eight：0/30
- ring：当前阈值下没有有效风险事件，未检验

`5/30` 表示 5 次独立运行通过时间检验，不是 5 个事件，也不是 5 条因果边。结果只说明部分合流运行存在非随机时间联系。

### 7.2 尚未完成：负对照

负对照需要选择理论上不应受源车辆影响、但交通背景与目标车辆相近的对象。例如选择与目标车辆速度、车道、密度和时间相似，却不在源车辆感知/通信/控制路径上的车辆。

负对照主要排除共同交通状态、统一控制或选择偏差造成的伪相关。

### 7.3 尚未完成：闭环反事实

当前设想是固定初始状态和随机种子，只改变车辆 A 的信息、控制或行为，再重新运行仿真，检查车辆 B 的风险事件和安全指标是否稳定变化。

反事实实验用于提供更强的因果证据，但具体干预变量、匹配方式、效应指标和统计方法都还可以重新设计。

## 8. 当前已经知道什么

可以确认：

1. DRIFT 当前数据可用于车辆级风险事件提取和局部关系分析。
2. 数据清洗后保留了 382 个可分析事件。
3. 当前规则能够建立同车、相邻车辆和同区域的局部关系。
4. 部分 merge 运行的跨车辆时间联系高于随机时间平移结果。
5. 当前分析不需要 GPU；重新训练模型时才需要 GPU。

不能确认：

1. 不能说已经发现远距离或超距因果作用。
2. 不能把一跳边或多跳链直接称为因果传播。
3. 不能说 DRIFT 全面优于其他控制方法。
4. 不能说量子理论解释了交通风险传播。
5. 不能说 DRAC 已经用于当前实验。
6. 不能把 ring 没有事件解释成 ring 场景没有风险，可能只是当前阈值不合适。

## 9. 方法没有被锁定

以下内容都是当前实现或候选方案，可以调整：

- 风险事件定义和阈值；
- 是否只研究追尾冲突；
- 局部关系的 3 s 和 50 m 窗口；
- 一跳边的评分和每个目标只保留一个前驱的规则；
- 同车多指标事件的合并方式；
- 远距离候选关系的定义；
- 时间置换和负对照设计；
- 因果发现、结构因果模型、时序方法、点过程或图模型的选择；
- 反事实干预对象和效应指标；
- 是否加入真实交通数据或其他仿真平台；
- 量子概率是否值得继续保留。

新对话应先比较几种合理路线，再决定后续方法，不要为了复用现有代码而强行维持现有方案。
