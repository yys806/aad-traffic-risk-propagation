# AAD

AAD研究联网车辆远端风险消息是否能够在普通物理影响到达前，通过“消息—采用—动作—风险”链路改变目标区域总体风险。

当前处于阶段 0的测量、现实边界和协议锁定工作。现有结果全部为 `scientific_claim_eligible=false`；阶段 1.1尚未启动。

## 常用入口

- 论文：[`paper/`](paper/)
- 文献：[`literature/`](literature/)
- 原始数据：`dataset/`（本机目录，不进入 Git）
- 总计划：[`docs/论文实验推进/总计划.md`](docs/论文实验推进/总计划.md)
- 当前状态：[`docs/RESEARCH_STATUS.md`](docs/RESEARCH_STATUS.md)
- 阶段/结果/历史：[`docs/STAGE_INDEX.md`](docs/STAGE_INDEX.md)、[`docs/RESULTS_INDEX.md`](docs/RESULTS_INDEX.md)、[`docs/HISTORY_INDEX.md`](docs/HISTORY_INDEX.md)
- 机器注册表：[`docs/PROJECT_REGISTRY.json`](docs/PROJECT_REGISTRY.json)
- 代码说明：[`code/README.md`](code/README.md)

当前计划与新运行使用“阶段 X.X”；机器标识使用 `stage_X_Y`。旧编号只在历史归档和旧证据中保留。
