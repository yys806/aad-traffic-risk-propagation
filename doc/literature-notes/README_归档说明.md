# 项目文献归档说明

本目录是“交通风险传播与类超距作用”项目的统一文献库。

## 分类目录

- `01_风险事件与安全指标`：冲突风险、事故风险预测和安全指标。
- `02_混合自动驾驶传播与控制`：混合交通、通信时延、通信拓扑和车队控制。
- `03_闭环仿真与场景测试`：自动驾驶安全验证、场景生成和交通信号控制应用。
- `04_人类行为交互与轨迹预测`：驾驶行为、交互建模和轨迹预测。
- `05_非局部风险与因果验证`：非局部交通流、因果识别和类超距理论参照。
- `NC_统一汇总`：全部 Nature Communications 论文的集中副本；NC 论文同时保留在对应主题目录中。
- `_work`：抽取文本、文献清单、下载记录和其他处理产物。
