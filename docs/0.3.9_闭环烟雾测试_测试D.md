## 三、这个结果说明什么

1. **闭环接入没有接线错误**：位置误差 3.7e-11 m（双精度舍入量级）。若存在「差一帧」「setSpeed 少发一帧」「净距用错口径（少 2 m minGap）」这类错误，误差会是 0.1–2 m 量级，实测没有。
2. **vType 的完整定义生效**：净距用 `getLanePosition` 手算（不用 `getLeader`），结果与纯 Python 一致。
3. **测试 C + D 合起来覆盖了「搬进 SUMO 数字会不会变」这个核心担忧**：
   - C 证明「积分器 + 坐标容器」等价（开环，误差 1.86e-10）；
   - D 证明「闭环接线」等价（误差 3.7e-11）。

## 四、这个测试**没**证明什么（必须一起记）

1. **场景仍是平衡态匀速**：头车全程 22.1028 m/s，无扰动、无事件、无 DRAC 超阈。
   **没有覆盖**：头车急减速、波传播、事件触发、DRAC≥3.4 计数。
2. **只有 5 车、60 s、单车道、无换道**。
3. **噪声情形只比了一个结构指标**（最小净距，差 1.6e-3 m），没有逐帧对账；
   两侧噪声抽样顺序未严格对齐，因此 D2 不能用于判定「有噪声时完全等价」。
4. 1600 veh/h、45 m 车头距、T′=1.0 这套正式参数下的行为，还没在 SUMO 里跑过。
