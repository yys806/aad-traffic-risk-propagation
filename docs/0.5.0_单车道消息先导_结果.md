## 五、混杂检查

### 5.1 暴露时长：辅助归一，未排除

低速（`v<10 m/s`）车·秒归一后仍降（A2 −35.95%、A3 −43.26%）。控速本身改变分母，
**不作主指标，不能声称已排除暴露解释**。

### 5.2 接收车 vs 非接收车（**指标名：每百低速车·秒的段数比值，不是原始段数**）

| 臂 | 接收车 | 非接收车 |
|---|---|---|
| A2 | −65.15%（10/10） | −32.81%（10/10） |
| A3 | −47.26%（10/10） | −42.37%（**9/10**） |
| A2L | −51.93%（10/10） | −26.67%（10/10） |
| A3L | −41.62%（10/10） | −29.11%（**9/10**） |

| A3P | −2.83%（7/10） | +0.57%（2/10） |

**机制不声称已识别**：非接收车受益与「单车道不能超车 → 后车被机械压速」相容，
但本轮没有任何设计能把「移动瓶颈削峰」与别的机制分开。多车道（可超车/切入）下会怎样**未测**。

### 5.3 双锚首波分解：**不给结论**

按 A0 逐车 T_phys 固定锚：窗内 126.0 / 68 / 9 / 6.5，窗外 77.5 / 120.0 / 95.5 / 89.0 段。
按各臂自身首次低于 10 m/s 的锚：窗内 126.0 / 102.0 / 79.0 / 73.5，窗外 77.5 / 98.5 / 24.0 / 20.5 段。
**两个锚给出不同分解，且自身锚随干预而变、固定锚把晚到的入队事件分到窗外。
「首波/队内」归类在本设计中不可识别，不能写进结论。**

### 5.4 两条不利事实（并列报）

1. **最小净距局部恶化**：A0 最坏 0.8487 m（seed 2），**A2 seed 3 压到 0.6693 m**。
   A2P/A3P 最坏仍为 0.8487 m（与 A0 相同，因为几乎没介入）。
2. **延误非无代价**：A2 配对差中位 −29.93、A3 −41.28 车·秒（约 −0.17% / −0.23%），
   但 A2 有 3/10、**A3L 有 4/10（最大 +177.72）** 种子延误上升。
   报「延误不增」必须带这句。

### 5.5 零提前量臂的机制（必读）

A2P/A3P 的 `cap_bind` 合计仅 2,190 / 5,779 帧，是早报臂的 1.1% / 1.3%。
原因：`v_cap = 0.7·v` 在波到达时通常**高于** HDM 自身的急刹速度，规则不构成约束。

**因此 A2P/A3P 的「零效应」同时说明两件事**：
① 到波才发消息，来不及产生额外收益；② 这条 0.7 倍限速规则在迟到时根本不会触发。
**不能据此说「信息本身没用」**——它说明的是「这条规则的价值完全依赖提前量」。

## 七、这次**没证明什么**（置顶）

1. **信息、动作、执行器三者仍未分离。** 零提前量对照拆掉了「提前量」，但接收车是
   **零延迟、零噪声自动限速**，未控车承受 `T′=1.0 s` 反应延迟 + OU 噪声。
   「用确定性执行器替代有延迟的 HDM 减速」这一份混杂原封不动。
2. **跨事件方差未估计**：10 种子共用同一确定性源事件。
3. **机制归类不可识别**（§5.3、§5.2）。
4. **单车道、不能超车**；多车道大概率衰减、低中密度可能反转，**未测**。
5. **延误非无代价**；**最小净距局部恶化**（§5.4）。
6. **零提前量臂的「零效应」与「规则不触发」不可分**（§5.5）。
7. **不能说剂量-反应**：600 s 窗下 A2/A3 原始中位倒挂，配对仅 7/10。
8. DRAC 是冲突风险代理量，不是事故率。
9. b_max=9.0、T′=1.0、0.70 + 1.0 m/s² 均为**预先指定的设计值**，不是标定结果。
10. 源事件永久保持（头车永不恢复），不代表真实事件「有生有灭」。
