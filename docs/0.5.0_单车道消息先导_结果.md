## 五、混杂检查（不是"排除"，两项未排除）

### 5.1 暴露时长：辅助归一，**未排除**

低速（`v<10 m/s`）车·秒归一后：A1 +1.85%、A2 **−35.40%**、A3 **−42.98%**（均 10/10）。
**只说明"换这个分母后仍见下降"**——控速本身改变分母，分子也不限定在低速期。
GPT 明确：不作主指标，**不能声称已排除暴露解释**。

### 5.2 接收车 vs 非接收车（**口径已更正**）

按全文统一配对差口径复算：

| 臂 | 接收车 | 非接收车 |
|---|---|---|
| A2 | **−65.4%（10/10）** | **−31.9%（10/10）** |
| A3 | **−47.3%（10/10）** | **−41.6%（9/10）** |

v1 原写 A2 −64.6%/−40.0%、A3 −56.2%/−40.2%，**为口径混用 + 种子数错报**，已更正。

**机制更正（关键）**：非接收车受益**不是"信息外溢"**。单车道无法超车，
接收车 40.85 s 被降到 15.5 m/s 后，夹在中间的未接收车被迫跟着降速——这是**移动瓶颈的机械压速**。
当 3.0 m/s 阻塞波传来，A0 是 `22.1 → 3.0`（Δv≈19.1 m/s）；A2/A3 已被拆成
`22.1 → 15.5`（限幅 1.0 m/s²，远低于 3.4 阈）与 `15.5 → 3.0`（Δv≈12.5 m/s），冲击能量大幅缩减。
**这相当于把常见的 VSL/移动瓶颈削峰现象换了个场景**，不是"远端信息带来区域收益"。
多车道下后车可超车/切入，这个外溢会怎样**未测**。

### 5.3 是否被推出窗口：只能说"累计差未被抹掉"

600 s 延长窗：A2 **−40.29%**、A3 **−48.06%**（均 10/10）；
400–600 s 区间 A2 中位 +0.5 段、A3 中位 0.0 段，**但两臂都出现过单种子比 A0 多 7 段**。
→ 不写"无反弹"，只写"延长到 600 s 未抹掉累计差"。

### 5.4 单点：A1 判"全窗未达门"，不作机制解释

A1 全窗 −4.79%（9/10），未达 5% 门槛。**不写"单车被吸收"**（机制解释，本轮无证据）。
补充（审计指出）：若用逐种子相对差的中位数，A1 为 −6.32%，会跨过 5% 线——
**A1 的"未达门"贴边缘，且依赖聚合算子定义，必须披露。**

### 5.5 两条 v1 漏记的不利事实

1. **最小净距局部恶化**：A0 十种子最坏 **0.8487 m**（seed 2），**A2 seed 3 压到 0.6687 m**，
   更逼近接触。事件段数下降掩盖了这一局部恶化。
2. **延误并非普遍不增**：A1 5/10、A2 3/10（最大 +46.1）、A3 2/10（最大 +44.3）种子上升。

## 九、这次没证明什么（置顶）

1. **无法分离「信息」与「动作」**，且比 v1 说的更严重：接收车是**零延迟、零噪声自动限速**，
   未控车承受 `T′=1.0 s` 反应延迟 + OU 噪声。受益可能部分来自
   "用确定性执行器替代了有延迟的 HDM 减速"。三个因素 100% 捆绑。
2. **不能答"没有延误代价"**：头车永久 3.0 m/s 把所有车末位置钉死，掩盖了永久限速的延误。
3. **非接收车受益机制是单车道机械压速**，多车道（可超车/切入）是否保留**未测**。
4. **零跨源事件方差**：10 种子共用同一确定性源事件，10/10 同向只说明对**这一个**极端阻塞事件稳健。
5. DRAC 是冲突风险代理量，不是事故率。
6. 单车道、无换道；b_max 与 T′ 固定；0.70 + 1.0 m/s² 是设计假设非标定。
