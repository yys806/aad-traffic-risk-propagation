## 〇、一句话

先把**命题和尺子**定死（P0、P1），再把**物理扰动真能传到目标区**这件事做出来（P2），
然后才有资格谈「信息有没有价值」（P3、P4），最后做稳健性与成文（P5、P6）。

**顺序不许颠倒。** 前面不扎实就回退重做，不许带着上一阶段的问题往下走。

## 二、每个阶段的细则

### P0 命题与判据冻结

**要解决什么**：现在那句「能否独立改变区域总体风险」问得太弱——任何作用到执行器上的干预都能「独立改变」风险。
必须换成一个**只有在信息有价值时才会被证实**的命题。

**产出**
1. 一页预注册文件：命题、判据（至少五条）、主指标与次指标、代价指标、对照臂定义、止损线。
2. 开题报告。

**过关标准**：导师认可；预注册文件进仓库；此后任何修改都要登记。

**必须写进命题的五条判据**（方向，具体措辞 P0 时定稿）
1. 危险真实存在：不发消息且有源事件时，目标区风险显著高于无源事件。
2. 效应：有源且发消息的风险低于有源不发消息，置信区间不跨零，且不确定性要**跨源事件**算，不能只跨种子。
3. 是信息不是动作：在通行代价对齐的前提下，真消息同时优于「虚警（无危险也发）」「错时（动作对、时机错）」「常开」「只用本地感知」四个对照。
4. 归因：生命周期链路显示消息进入决策，且控制器开关造成动作差异。
5. 时间优先：风险可识别变化的上界早于物理到达的下界，物理到达取自实测而非假设。

**不许做什么**：不许在 P0 里跑实验；不许用「先跑跑看」代替命题。

---

### P1 测量与代码纠偏

**要解决什么**：现在全项目有三把尺子（瞬时 TTC、刹车式 TTC、DRAC），账本里的数字互相矛盾，
而且已知至少三处硬错（见附录 A）。不修完，后面所有结果都不可引用。

**产出**
1. 一个统一的风险与聚合模块，默认 1105 原式，其余口径只作敏感性。
2. 并列物理量：急刹次数、秒级 TTC 变化、通行代价（通行量、平均车速、累计里程）。
3. 测量区比处理区向上下游各外延一段。
4. 账本（结论表）改由输出文件自动生成，不再手抄。
5. 现有三臂在**原式**下重算一次，作为历史对照，不追求结论，只求账实相符。

**过关标准**
- 新旧数字逐项能对上，或差异有登记。
- 代码里只有一个风险函数被主流程调用；其余口径必须显式传参才能启用。
- 结论表里每个数字都能追到某个输出文件的具体字段。

**止损线**：重算之后如果历史上所有「正向结论」全部消失——这是**预期结果**，如实记录，不许为了保住旧结论调口径。

**不许做什么**：不许在 P1 里换场景、加新臂、扩种子。P1 只做纠偏和收口。

---

### P2 连通场景与物理基线

**要解决什么**：在物理相连的路网里，源事件的扰动到底能不能传到目标区、多久传到。
这是 H4 的分母（T_P 与 F0），也是 1105 挂了很久的四条未完成项（独立验证 V、合格传播路径、参数冻结、F0）。

**关键设计**
- 路网：源在上游、目标在下游，**真实连接**。
- 源事件：用 1105 定义的 B 类受控扰动（安全、可控），时刻、位置、强度**每次随机抽取**。
- 测量：按 1105 的 Cohort 定义测目标区是否出现持续速度下降，得到到达时间。
- 敏感性维度：源到目标的距离、交通密度、扰动强度。

**产出**
1. 有源（S1C0）与无源（S0C0）的区域风险对比。
2. 不同距离与密度下的到达时间曲线，即 F0 的雏形。
3. 合格传播链清单（至少能追到指定源事件）。
4. 独立验证 V：一批标定、另一批验证。

**过关标准**
- 至少一组距离与密度下，S1C0 的风险显著高于 S0C0。
- 到达时间在独立批次上可重复。
- 合格物理路径至少 1 条。

**止损线**（必须提前写死，不许事后放宽）
任何配置下扰动都传不到目标区 → H4 的前提在本仿真中不成立，转为报告这个负结果，
并重新评估是否改用更强的扰动形态（排队、瓶颈）或更长车队。**不许改成「隔离场景凑合证」。**

---

### P3 干预与对照锁定

**要解决什么**：把「信息」定义成目标车本地推不出来的东西，并用一组对照把「信息的作用」和「动作的作用」分开。

**五个臂**（缺一不可）
| 臂 | 内容 | 排除什么 |
|---|---|---|
| 真消息 | 带源事件真实信息的消息 | — |
| 虚警 | 无危险时也发同等强度消息 | 排除「只要有动作就有效」 |
| 错时 | 动作相同但施加时机错误 | 排除「动作对了就行，时机不重要」 |
| 常开 | 同等动作一直施加 | 排除「一直压着也行」 |
| 本地参考 | 只用本地感知做响应 | 排除「不用远端消息也能做到」 |

**产出**：协议锁定文件；小规模试跑给出跨源事件方差与所需样本量。

**过关标准**：协议进入锁定态；样本量定死；五个臂的通行代价差在预设容差内。
