# 下一步该做什么：结论与依据

日期：2026-11-16 晚。两份外部独立意见（Codex / Claude）＋一项实测裁决。

## 一、结论

**下一步：在两条互不相连的路网上，跑 Stage I 的「资格两臂」实验（scr=1，opn 分叉）。**

不是先改连通场景，不是先冻 F0，不是先换跟驰模型。

## 二、为什么不是先冻 F0（论证要点）

论文 `main.tex` 第 313–319 行明确写着：

> 在物理隔离场景下，不存在任何合格的 source→target 物理传播链，
> 此时定义 `t_phy-resp = +∞`。**这是设计的结构性质，不是观测值。**

所以 **Results 第一节（隔离条件下的效应）根本不需要 F0**。
F0 只卡第二、三节（连通条件、时间先后）。

## 三、为什么现有 Task8 数据不能直接冻成 F0（两份意见一致）

现有场景：源车 s0 在 x = 2800 m，目标区域定义 1600–3080 m。**源车在目标区域内部。**

后果：按论文自己的定义，目标区首次物理响应就是源车的直接后车（+0.40 s），
`F0 ≈ 0.4 s`。把它冻结，等于冻结一个与「信息先行」主张矛盾的数。

因此 Task8 数据保留为**传播动力学诊断**（它确实证明了扰动逐车传播、剂量单调、
约 420 m 内衰减殆尽），但不能作为论文主 F0。

## 四、实测裁决：隔离设计在技术上成立

两份意见的分歧点是「先在隔离条件下跑，还是先改空间分离」。
关键问题：两条互不相连的路，会不会通过共享随机数隐式耦合？

脚本 `code/scripts/test_isolation_rng_coupling.py`，
两条无连接 edge、同一 seed、σ=0.5，源路额外加一辆急刹车辆：

| 指标 | 结果 |
|---|---|
| 目标路比较样本数 | 27,770 |
| 位置完全相同 | 27,770（100.0000%） |
| 速度完全相同 | 27,770（100.0000%） |
| 最大位置差 | 0 m |

**PASS。** 两条不相连的路在 SUMO 里确实因果独立，不需要额外改随机数。

这条同时解决了「源车在目标区内」的问题：隔离场景下源区与目标区本来就是两条边，
结构上不重叠。

## 五、为什么这个动作同时满足两份意见

- Claude 主张：Results 第一节不需要 F0，隔离场景本身就是最简单的空间分离。
- Codex 主张：必须先修复「源与目标分离」这个识别前提。

**隔离场景同时满足两者**：两条互不相连的 edge 既是空间分离（Codex），
又不需要 F0（Claude 的结构性 +∞）。而第二阶段（连通场景）才需要 F0，
那要等距离→到达曲线定了 B 区位置。

## 六、执行顺序

1. **隔离两臂**（scr=1，opn=0 / opn=1 分叉）→ Results 第一节
2. 并行：用 Task8 数据算「距离 → 物理到达」曲线，定连通场景 B 区位置
3. 连通场景建好后再冻 F0 与 T_prephy
4. Protocol Lock
5. 连通四格

## 七、必须记住的两个限制

1. **19.8 秒不是「信息先行窗口」**。它只是 MAX 剂量、high 密度下扰动传播到第 28 辆车
   的时间。真正的窗口是「B 区近端物理到达时间 − 信息响应时间」，由 B 区放哪决定。
2. **已有区域风险数（0.0973 / 0.0763 等）的名单包含源车本身和紧邻后车**，
   测的主要是源车附近的直接影响。写进论文前必须按不含源车的区域重算。
