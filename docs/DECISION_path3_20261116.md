# 决策：采用路径三，不走路二和路一

日期：2026-11-16。决策依据：`docs/EXPERIMENT_eidm_calibration_20261116.md`、`docs/EXPERIMENT_path3_20261116.md`。

## 一、研究者定的回退顺序

2026-11-16 原话："先做路三，路三如果不行的话，就做路二，路二要是再不行，就做路一。"

- **路三**：不追求复现近冲突，把风险定义成连续量
- **路二**：换 Gipps 跟驰模型
- **路一**：改 SUMO 源码，把 `EST_REAC_THRESHOLD` 调小后重编译

## 二、结论：路三成功，路二与路一不启动

路三的核心指标全部达标：

1. 区域风险从 9.32e-5 恢复到 0.876，脱离地板
2. 通道打开的效应方向由 **+0.0134（升高）** 翻转为 **−0.0099（下降）**，符合理论预期
3. 信息内容效应由 **精确为零** 变为 **−0.0057**，且四种子符号一致
4. 剂量对齐后内容效应仍为 **−0.0055**，不是剂量假象

## 三、路三为什么能成（三条改动，互不替代）

| 改动 | 解决什么问题 |
|---|---|
| 风险口径改为前车急刹 TTC | 旧口径只在接近时才有值，稳定跟驰时恒为零，风险被稀释到地板 |
| 响应改为拉大车头时距 | 统一限速不拉开车距，车队内反而压缩车距，这是上一轮效应方向相反的原因 |
| 消息内容进入决策（档位×深度×有效期） | 内容不进决策，安慰剂与真消息必然逐位相同，信息效应恒为零 |

三条缺一不可。只改风险口径不响应，两臂仍然相同；只改响应不改口径，差异淹没在噪声里；不改内容分级，信息效应还是零。

## 四、代价与限制（必须在论文里写明）

1. **风险不是"真实近冲突"**，是"假如前车以 4.5 m/s² 急刹会怎样"。这是反事实量，不是观测到的事件。论文里必须讲清这一点，不能说成"预测了事故"。
2. **前车减速度取 4.5 m/s² 未经实测标定**，是车辆类型的自身参数。
3. **SUMO 的 EIDM 3 米限制仍然存在**，只是不再是拦路虎。换模型或改源码都不做。
4. **"拉大车距"作为对预警的响应是合理假设，未经实测标定**。这是整条链最软的一环，文献支持方向（V2I 预警确实改变驾驶行为）但没有定量标定。
5. 仿真种子间方差极小，**不能当作外部效度证据**。

## 五、路二与路一的启动条件（留档，便于以后回退）

若后续出现以下情况，按顺序启用：

- **启用路二（Gipps）**：若审稿人明确质疑"EIDM 参数不适用"，或需要复现真实 TTC 分布作为独立验证
- **启用路一（改源码）**：若审稿人要求"仿真必须能产生真实量级的近冲突事件"

启动路一的前置条件：需要 MSVC + CMake 编译环境，且在论文中显著声明修改了仿真器内核。
