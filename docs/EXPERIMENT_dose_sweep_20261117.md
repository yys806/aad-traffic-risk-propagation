# 剂量扫描：内容分级的优势随剂量增大而消失并反转

日期：2026-11-17。状态：`ENGINEERING_PILOT`，每档 2 个种子。

## 一、设计

每档按同一比例缩放内容分级的峰值剂量与 sham 的统一剂量，**保证每档仍是等剂量对照**（内容 vs 无内容）。只有剂量在变。

| 档 | 峰值剂量 | sham 剂量 |
|---|---|---|
| 1 | 0.10 s | 0.036 s |
| 2 | 0.30 s | 0.107 s |
| 3 | 0.70 s | 0.250 s |
| 4 | 1.20 s | 0.430 s |
| 5 | 2.00 s | 0.717 s |

## 二、结果

| 峰值剂量 | 总效应 Δ(opn1−opn0) | 内容无关 Δ(sham−opn0) | **信息内容 Δ(opn1−sham)** | 相对 sham |
|---|---|---|---|---|
| 0.10 s | −0.000576 | −0.000405 | **−0.000172** | **−0.02%** |
| 0.30 s | −0.001307 | −0.001056 | **−0.000251** | **−0.03%** |
| 0.70 s | −0.001841 | −0.001894 | **+0.000053** | **+0.01%** |
| 1.20 s | −0.001936 | −0.002426 | **+0.000490** | **+0.06%** |
| 2.00 s | −0.001902 | −0.002721 | **+0.000819** | **+0.09%** |

## 三、三条清楚的规律

### 规律一：总效应随剂量增大而增强，然后饱和

| 剂量 | 总效应 |
|---|---|
| 0.10 | −0.00058 |
| 0.30 | −0.00131 |
| 0.70 | −0.00184 |
| 1.20 | −0.00194 |
| 2.00 | −0.00190 |

从 0.10 到 1.20 单调增强（降风险从 0.06% 到 0.19%），**1.20 之后饱和**（2.00 反而略回升）。

**这是好消息**：响应确实有效，且存在饱和点，说明剂量不需要无限加大。

### 规律二：内容无关效应随剂量单调增强

| 剂量 | 内容无关效应 |
|---|---|
| 0.10 | −0.000405 |
| 0.30 | −0.001056 |
| 0.70 | −0.001894 |
| 1.20 | −0.002426 |
| 2.00 | −0.002721 |

**严格单调**。剂量越大，统一拉大时距降风险越多。这条最干净、最可信。

### 规律三：内容分级的相对优势随剂量增大而消失并反转

| 剂量 | 信息内容效应 |
|---|---|
| 0.10 | **−0.000172（内容略优）** |
| 0.30 | **−0.000251（内容略优）** |
| 0.70 | +0.000053（打平） |
| 1.20 | +0.000490（内容更差） |
| 2.00 | +0.000819（内容更差） |

**小剂量时内容分级略占优，剂量超过约 0.5 秒后转为劣势，且劣势随剂量扩大。**

## 四、为什么

这与上一轮查清的机制一致：

**内容分级只调节时距增量，不调节速度。** 而速度降幅是风险的主导因素。

- 小剂量时，时距的精细分配还有点用（把有限的时距增量放到最需要的地方）
- 大剂量时，sham 的统一减速把整体车速压得很低，这个"整体降速"的收益远大于"时距精细分配"的收益
- opn1 按深度分级，中心车时距大、边缘车小，减速不均匀，平均车速反而更高 → 风险更高

**所以内容分级的劣势不是它"做错了"，是它作用的维度（时距分布）不是主导维度（速度）。**

## 五、这一轮的结论

| 结论 | 强度 | 数字 |
|---|---|---|
| 响应能降风险，且随剂量增强后饱和 | **强** | 0.10→1.20 单调，饱和在 1.20 |
| 内容无关的响应最干净 | **强** | 严格单调，−0.0004 → −0.0027 |
| 内容分级只在极小剂量（<0.5 s）有微弱优势 | 弱 | −0.02% ~ −0.03%，量级太小 |
| 内容分级在大剂量下明显更差 | 中 | +0.06% ~ +0.09% |

## 六、这对论文意味着什么

**当前的响应实现无法支撑"消息内容起作用"这个主张。**

原因很明确：内容只进入了时距这一个维度，而决定风险的是速度。要让内容真正起作用，必须让消息内容影响**减速度或目标速度**，而不只是时距。

这不是调参能解决的，是设计问题。三个可选方向（需研究者定）：

1. **内容决定减速强度**：高风险消息让车辆降速更多，低风险少降
2. **内容决定减速范围**：高风险只影响中心区车辆（精准），低风险影响全区域
3. **内容决定持续时间**：高风险消息让车辆保持减速更久

这三条都能让"内容"进入速度这个主导维度。

## 七、局限

1. 每档只有 2 个种子，趋势清楚但统计量不足
2. 只有单场景、单密度、80 秒
3. 剂量 2.00 时 tcap 3.0 秒可能被撞到（0.6 + 1.2×1.667 ≈ 2.6，接近上限）
4. 内容分级的 depth 下限 0.2、validity 下限 0.1 是随手设的，没标定
