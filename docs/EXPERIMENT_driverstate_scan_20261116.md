# 实验记录：driverstate 感知误差扫描（2026-11-16）

> 目的：验证 SUMO 内置的驾驶员感知误差设备能否在现有场景里产生合格的风险事件。
> 性质：探索性。不是正式 P2 测量，不产生科学结论。

## 1. 为什么要做

现有 B00/Task8 场景里 Formal A（自然源事件）= 0。仓库 2026-10-21 的诊断结论是：仿真车流整齐、同速、司机完美，相对速度接近 0，TTC 算不出小值。

本轮假设：**缺的是「驾驶员会犯错」这一机制**。SUMO 有内置的 `driverstate` 设备，在感知层注入误差（车距/速度差看错）+ 随注意力下降拉长反应时间。

详见 `docs/SOURCE_EVENT_VIABILITY_20261116.md`。

## 2. 设计

- 场景：完全复用 `run_p2_task7_parameter_experiment.py::one` 的参数（网络 `p2_task8_20261102_v1/config/network.net.xml`、high 密度 64 车 × 15 m 间距、初始 10 m/s、Krauss、tau=0.6、sigma=0.25、maxSpeed=10、禁换道、0.05 s 步长、50 s）。
- 唯一改动：vType 增加 driverstate 参数。
  - `device.driverstate.probability = 1`
  - `device.driverstate.initialAwareness = 扫描变量`
  - `headwayErrorCoefficient = 0.75`、`speedDifferenceErrorCoefficient = 0.15`
  - `maximalReactionTime = 1.5`
- 对照：`initialAwareness = 1.0` 且**不装设备**（完全正常模型）。
- 扫描：1.0 / 0.5 / 0.3 / 0.2 / 0.1，每档 2 个 seed（20261116、20261117）。

## 3. 测量

- 每 0.05 s 记录全部车辆速度、与前车间距、前车速度（TraCI `getLeader`）。
- 真 TTC = 间距 / (自车速度 − 前车速度)，仅当自车更快。
- 报告：最小 TTC、各阈值下样本数、最小间距、速度标准差、碰撞次数。
- P2 阈值参考：TTC < 2.0 s、持续 ≥ 0.2 s、最大观测间隔 ≤ 0.11 s。

## 4. 脚本与产物

- 脚本：`code/scripts/scan_driverstate_awareness.py`
- 输出：`code/outputs/analysis/driverstate_scan_20261116_v2/`（初版在 `..._20261116/`）

## 5. 结果

10 次运行全部完成，无失败、无碰撞。真 TTC = 间距 / (自车速度 − 前车速度)。

| 注意力 | 种子 | 最小 TTC (s) | 最小车距 (m) | TTC<5 s 样本 | 速度标准差 |
|---|---|---|---|---|---|
| 1.0（不装设备对照） | 116 | 252.6 | 7.45 | 0 | 0.0093 |
| 0.5 | 116 | 9.57 | 5.53 | 0 | 0.113 |
| 0.3 | 116 | 7.67 | 5.84 | 0 | 0.071 |
| 0.3 | 117 | 5.96 | 4.36 | 0 | 0.085 |
| 0.2 | 116 | 7.54 | 5.55 | 0 | 0.072 |
| 0.2 | 117 | 5.08 | 4.20 | 0 | 0.112 |
| 0.1 | 116 | 3.88 | 4.78 | 11 | 0.141 |
| 0.1 | 117 | 4.61 | 3.79 | 25 | 0.182 |

**结论**：
1. **机制成立，剂量—响应单调**。注意力从 1.0 降到 0.1，最小 TTC 从 252 s 掉到 3.9–4.6 s，速度标准差从 0.009 涨到 0.18（约 20 倍）。
2. **还没达到合格源事件水平**。P2 要求 TTC < 2.0 s 且持续 ≥ 0.2 s；当前最好一档最小 TTC 3.88 s，低于 5 s 的样本只占 0.03–0.08%。
3. **未出现碰撞**，说明安全机制尚未被逼到极限。
4. **交通状态**：速度标准差上升但绝对水平未见异常；密度未在本次输出中统计，需下一轮补。

**一个关键信号**：SUMO 日志反复警告「actionStepLength 0.7 s 已大于 tau 0.6 s，这可能导致碰撞」。这正是想要的物理状态——驾驶员反应比其期望安全时距还慢。现实里走神就是这个效果。该警告说明继续加大反应时间还有空间。

## 6. 这次没证明什么

- 没有产生任何 Formal P2 合格事件（TTC 未进入 2 s）。
- 没有证明加了感知误差后交通状态仍在现实区间（密度未测）。
- 没有证明参数可标定到 NGSIM 的 17–23 件/车小时。
- `minAwareness` 默认 0.1，本次已到该下限；更低需要改这个参数，未验证。
- 单场景（high 密度、单车道、50 s），不能外推到其他密度或路网。
