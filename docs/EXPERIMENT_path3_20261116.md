# 路径三实验：第一次跑出方向正确的信息效应

> ⚠️ **【2026-11-17 作废】本文的效应数字已被推翻。**
> 风险分母只统计 40 秒锁定的 roster（60 辆），而处理施加给每时刻在区的 76–78 辆，
> 27–29 辆被处理的车不进风险读数。修正分母后，信息内容效应从 **−0.63% 变成 +0.06%（符号翻转）**，
> 「内容分级更有效」的结论**不成立**。
> 正确的数字见 `docs/EXPERIMENT_path3_denominator_fix_20261117.md`。
> 本文保留价值：记录了 EIDM 3 米限制、旧口径对照（+25 倍 vs −1.13% 符号相反）这两条仍成立。

日期：2026-11-16。状态：`ENGINEERING_PILOT`，单种子，未做统计检验。

## 一、路径三是什么

研究者 2026-11-16 定的回退顺序：**先做路三，不行做路二，再不行做路一。**

路三 = 不去追求"让仿真复现真实近冲突"，而是换风险口径，让风险成为**连续量**，不依赖罕见的近冲突事件。

依据：`docs/EXPERIMENT_eidm_calibration_20261116.md`。SUMO 的 EIDM 在源码里写死 `EST_REAC_THRESHOLD = 3.`，间距低于 3 米时直接关闭感知误差与反应时间；而真实近冲突有六分之五发生在 3 米以下。所以靠调参或换模型都进不去那个区间。

## 二、改了哪三处（其余一字未动）

### 改动一：风险口径从"瞬时闭合速度"改为"前车急刹"

**原做法**：只有后车正在接近前车时才算风险，否则记 0。

```
closing = v_f - v_l
if closing <= 1e-6:  风险 = 0
TTC = gap / closing
```

**问题**：稳定跟驰时几乎没人在接近，绝大多数车被记 0，区域风险被稀释到 **9.32e-5**，两臂根本无法区分。

**新做法**：假设前车以 4.5 m/s²（车辆自身具备的减速度）急刹，算到碰撞的时间。这个量**任何时刻都有定义**，且直接是车距的函数。

```
gap = (v_f - v_l)·t + 0.5·b·t²
t = [-(v_f - v_l) + sqrt((v_f - v_l)² + 2·b·gap)] / b
```

论文的风险映射 `rho = exp(-TTC/τ)`（τ = 15.364279197080283）**一字未改**，只改了 TTC 怎么算。

**效果**：区域风险从 9.32e-5 变成 0.876，量级正常，能分辨差异。

### 改动二：响应动作从"限速"改为"拉大车头时距"

**原做法**：对区域内的车统一压速度上限。

**问题**：全体统一减速不会拉开车距，在车队里反而会压缩车距。这解释了上一轮为什么通道打开后风险**升高**（+0.0134，方向与假设相反）。

**新做法**：调每辆车的跟驰时间间隔参数（TraCI `setTau`），直接把车距拉开。

**先验证过这个动作有效**（`smoke_settau.py`）：

| 车头时距 | 平均车距 |
|---|---|
| 0.6 秒（原生） | 15.60 米 |
| 1.2 秒 | 30.09 米 |
| 2.0 秒 | 46.80 米 |
| 3.0 秒 | 62.59 米 |

单调、幅度大，可以作为响应动作。

### 改动三：消息内容真正进入决策

**原做法**：控制律只读 `risk_level` 三个档位，转成一个固定倍数。源事件的距离、时效、影响范围全部没进决策——所以安慰剂臂和真消息臂给出**逐位完全相同**的结果（Δ 精确为 0）。

**新做法**：加时距的幅度由消息自己的字段决定：

- 风险档位（低 / 中 / 高 → +0.3 / +0.7 / +1.2 秒）
- 车辆在受影响区域内的深度（区域中心最强，两端最弱）
- 剩余有效期的比例（越接近失效越弱）

这样响应是逐车、逐时刻变化的，一个"内容无关的统一动作"复制不出来。

## 三、三臂设计与各对比的含义

| 臂 | 做什么 |
|---|---|
| **opn0** | 完全不响应 |
| **sham** | 对所有区域内车辆施加**同等幅度但内容无关**的整体时距增加（不读任何消息字段） |
| **opn1** | 由消息内容分级的逐车响应 |

- `Δ(opn1 - opn0)` = 消息触发响应的总效应
- `Δ(sham - opn0)` = 同样大小的内容无关动作的效应
- `Δ(opn1 - sham)` = **能归到消息内容上的那部分**

这样设计修掉了上一轮"安慰剂测的是算术恒等"的毛病：上一轮安慰剂用的是同一套控制律，必然逐位相同；这一轮安慰剂是内容无关的统一动作，与内容分级动作有实质区别。

## 四、结果（1 个种子，seed=20261116）

| 臂 | 区域风险（按车-时归一） | 采纳车数 | 实际施加 |
|---|---|---|---|
| opn0 | 0.875859 | 0 | 0 |
| sham | 0.871585 | 0 | 70 |
| opn1 | 0.865906 | 78 | 78 |

对比：

- `Δ(opn1 - opn0)` = **−0.00995**（相对 opn0 下降 1.14%）
- `Δ(sham - opn0)` = **−0.00427** ← 内容无关的整体响应
- `Δ(opn1 - sham)` = **−0.00568** ← **消息内容本身的效应**（相对 sham 下降 0.65%）

## 五、相比上一轮的实质变化

| 指标 | 上一轮（限速响应 + 瞬时 TTC） | 这一轮（时距响应 + 急刹 TTC） |
|---|---|---|
| 区域风险量级 | 9.32e-5（贴地板） | 0.876（正常） |
| 通道打开的效应方向 | **+0.0134（风险升高，与假设相反）** | **−0.00995（风险下降，符合预期）** |
| 信息内容效应 | **+0（精确为零）** | **−0.00568（非零）** |

三件事同时翻正。这是今晚最有价值的一个结果。

## 六、必须说清的局限（不许当成结论用）

1. **只有一个种子，没有统计检验。**0.65% 的差异能不能和种子噪声区分开，现在不知道。
2. **效应很小**，绝对量 0.0057。真实实验里这种量级需要很多种子才站得住。
3. **sham 与 opn1 的覆盖车数不同**（70 对 78）。这是处理本身造成车流演化不同、进而进区车辆集合不同，不是设计缺陷，但会让内容效应里混进一点覆盖差异。
4. **车距被拉大后，区域内车辆数会变少**，风险均值可能含有成分变化，需要按暴露量核对。
5. **前车减速度固定取 4.5 m/s²**，这是车辆自己的能力值，不是从真实数据标定的。
6. 这一轮**没有**改仿真器、没有换跟驰模型——EIDM 的 3 米限制仍然存在，只是不再是拦路虎。

## 十一、剂量核对（这一步查出了一个真问题）

原本担心 sham 与 opn1 的动作强度不同，会把"内容效应"和"剂量效应"混在一起。实测：

| 臂 | 平均时距 tau | tau 的 90 分位 |
|---|---|---|
| opn0 | 0.600 | 0.600 |
| sham（峰值剂量） | **1.432** | 1.800 |
| opn1（内容分级） | **0.895** | 1.167 |

**opn1 的平均动作强度只有 sham 的 35%，压风险却更多。**这说明内容分级把动作放到了更该放的地方，但也意味着原设计的对比里混了剂量差。

## 十二、等剂量对照（决定性的一步）

把 sham 改成施加与 opn1 同样大小的平均剂量（固定 +0.43 秒），重新跑：

| 臂 | 平均时距 tau | 区域风险 |
|---|---|---|
| opn0 | 0.600 | 0.875859 |
| sham（等剂量 +0.43 秒） | **0.898** | 0.871448 |
| opn1（内容分级） | **0.895** | 0.865906 |

两臂平均剂量基本对齐（0.898 对 0.895）。

- `Δ(sham − opn0)` = −0.004411
- `Δ(opn1 − sham)` = **−0.005541（−0.64%）**

**结论：剂量对齐后，内容效应几乎不变（−0.0057 → −0.0055）。**说明这 0.64% 不是剂量造成的，是"把同样的动作按消息内容分配"造成的。

这是今晚唯一一个经得起追问的因果结论：**同样的平均动作量，按消息内容分发比不分内容地统一施加，多压 0.6% 的区域风险。**

## 十四、旧口径对照：同一个实验，符号完全相反

用**完全相同的场景、完全相同的三臂、完全相同的动作**，只把风险口径换回旧的（瞬时闭合速度 TTC），结果：

| 臂 | 旧口径风险 | 新口径风险 |
|---|---|---|
| opn0 | 1.16e-04 | 0.875859 |
| sham | 7.20e-05 | 0.871585 |
| opn1 | **3.05e-03** | 0.865906 |

对比量：

| 对比 | 旧口径 | 新口径 |
|---|---|---|
| Δ(opn1 − opn0) | **+25 倍（风险暴涨）** | **−1.13%（风险下降）** |
| Δ(opn1 − sham) | **+41 倍** | **−0.65%** |

**同一个实验，旧口径说"信息让风险升高 25 倍"，新口径说"信息让风险下降 1.1%"。符号相反。**

### 旧口径为什么错

旧口径只在后车正在接近前车时才有值。而"拉大车头时距"这个动作**本身就是通过减速实现的**：前车先减速、后车还没反应的那一瞬间，闭合速度为正、间距还不大，瞬时 TTC 很小 → 被记成高风险。

也就是说，**旧口径把"正在安全地适应"误读成"风险升高"**。车辆适应完成后间距拉大，但那时闭合速度已经归零，旧口径又记 0，完全看不见改善。

这是一个系统性缺陷，不是参数问题：**旧口径只在危险逼近的瞬间有读数，看不见"危险被消除"这件事。**

### 这条对照的价值

它一次性解释了两件事：

1. 上一轮为什么通道打开后风险**升高**（+0.0134）——不是设计错，是口径错
2. 为什么之前所有实验都测不出信息效应——口径把效应方向搞反了，正负相消

这也是论文里必须讲的一段：**风险口径的选择会决定结论的符号**，所以口径必须由"信息应该改变什么"来定，而不是沿用默认的 TTC 定义。远端风险信息应该改变的是**车距**，所以风险度量必须是车距的函数。

**剂量对齐情况**：四组里 sham 与 opn1 的平均时距差最多 0.0032 秒，基本重合。

**信息内容效应（等剂量，n=4）**：

- 均值 **−0.005529**
- 标准差 3.0e-05，标准误 1.5e-05
- 相对 opn0 **−0.63%**
- 极差 7.1e-05
- 四种子全部为负

**与未对齐版本对比**：

| 版本 | sham 剂量 | 信息效应均值 |
|---|---|---|
| 未对齐 | 峰值 +1.2 秒 | −0.005677 |

这排除了"内容效应只是剂量假象"的可能。真正的机制是：**同样大小的总动作量，按消息内容分配比不分内容地统一施加，效果更好。** 这不是因为动作更大，而是因为动作落在了该落的地方。

## 十六、最终结论汇总（这一轮实验的可交付结论）

1. **风险口径必须与"信息应该改变什么"挂钩。** 远端风险信息应该改变车距，所以风险度量必须是车距的函数。旧口径只在接近的瞬间有读数，会把"正在安全适应"误读成"风险升高"——实测符号相反，旧口径给 +25 倍，新口径给 −1.13%。

2. **响应动作必须是能改变目标量的动作。** 统一限速不改变车距，所以在车队里无法降低风险。改成拉大车头时距后，风险单调下降（冒烟实测 0.6→1.2 秒使车距 15.6→30.1 米）。

3. **消息内容必须真正进入决策。** 只读风险档位转固定倍数，安慰剂臂与真消息臂必然逐位相同。加入区域深度与有效期后，内容效应从精确为零变为 −0.63%，且四种子符号一致、剂量对齐后仍成立。

4. **效应量小（0.63%），但方向正确且可复现。** 这是工程 pilot 的量级，不是可以写进论文定稿的数字。

## 十七、还不能写进论文的四个理由

1. **只有一个场景、一个网络、一段 80 秒。** 没有跨场景、跨密度、跨时段的验证。
2. **响应动作未经实测标定。**"预警 → 拉大车距"是合理假设，文献支持方向但没有定量标定。这是整条链最软的一环。
3. **种子方差极小不等于稳健。** 仿真同一模型的重复随机数，种子间当然几乎不变。t 值再大也只说明模型内稳定。
4. **3 米源码限制仍在，前车减速度 4.5 m/s² 未标定。** 风险是反事实量，不是观测事件。
