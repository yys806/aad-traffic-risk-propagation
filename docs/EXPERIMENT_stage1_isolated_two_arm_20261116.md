# 隔离两臂实验（T1）——首轮结果

日期：2026-11-16 晚。状态：`ENGINEERING_PILOT`，非正式实验，非 Protocol Locked。

## 一、目的（登记于 `D:\hermes-yan\projects\AAD\AAD-实验推进任务表.md` T1）

拿到物理隔离条件下的两臂对照：开/关信息通道，目标区风险是否不同。这是论文 Results 第一节需要的第一组数据。

## 二、设计

| 项 | 值 |
|---|---|
| 路网 | 两条互不相连的边，各 6000 m。`src`（源路）与 `tgt`（目标路） |
| 隔离验证 | `test_isolation_rng_coupling.py`：同一 seed、σ=0.5，源路加急刹车，目标路 27,770 个采样点位置与速度 100% 相同，最大差 0 m |
| 源事件 | 源车 S0 在 40 s 出发，400 m 处停 12 s。确认时刻 = 速度相对初值下降 >1 m/s 的**实测**时刻 |
| 目标区 | 3000–4000 m（1000 m），路网中段 |
| 车流 | 从 5900 m 起每 15 m 一辆填满上游，`speedDev=0.12`（异质期望速度） |
| 两臂 | 同一 seed，只差 `opn`。opn=0 永不发消息；opn=1 源确认后逐车生成/校验/采用 |
| 名单 | 预热 40 s 后锁定，**分母固定**：离开区域的车仍占位、风险记 0 |
| 步长/时长 | 0.05 s，80 s |
| 种子 | 20261116 |

## 三、结果

| 指标 | opn=0（无消息） | opn=1（有消息） |
|---|---|---|
| 锁定名单车数 | 60 | 60 |
| 源事件时刻 | 52.20 s | 52.20 s |
| 消息采纳 | 0 | **76 辆**（名单外车辆也进区后被采纳） |
| 平均区域风险 | 9.33×10⁻⁵ | **4.29×10⁻⁴** |
| 最大瞬时风险 | 1.42×10⁻³ | 9.77×10⁻³ |
| 区内时间占比 | 0.698 | 0.745 |
| 区内平均速度 | 15.25 m/s | 11.26 m/s |

**消息臂风险是有消息前的 4.6 倍，方向与论文预期相反**（论文假设信息应当降低区域风险）。

## 四、机制判断

**这不是 bug，是可解释的力学结果**：控制器把车速上限压到参考速度的 0.5–0.9 倍，车辆在规定时刻集中减速。减速不同步 → 队内出现闭合速度 → 局部 TTC 风险上升。

**但绝对量级极小**（10⁻⁴ 量级）。原因：Krauss 后车在 15 m/s、15 m 间距下始终维持安全距离，闭合速度接近零。**风险本身几乎没有，也就无所谓"被降低"。**

## 五、与论文的偏离（R05 要求记录）

1. **区域风险分母**：论文要求四格间 `N` 固定。我实现了固定名单、离开区域记 0 风险。**这是照论文做的**，但论文没有说明名单什么时候锁。我选了预热结束后第一帧，属自定。
2. **源事件确认判据**：论文只说"实际开始减速"。我用"速度相对初值下降 >1 m/s"，是自定阈值，未经冻结。
3. **风险聚合**：论文用区间上下界。我只算了点估计（区间版本的名单完整性条件当前不满足）。
4. **消息受众**：论文的四格设计里消息按实验条件发放。我做成"所有进入目标区的车都发"，包括名单外车辆。

## 六、这次没证明什么

1. **没证明消息能降低区域风险。** 相反，这一轮显示它升高了。
2. **没证明消息效应是真的。** 绝对风险 10⁻⁴ 量级，两臂差异可能全部来自"车辆集中减速"这一机械原因，与消息内容无关。要排除这个，需要一个安慰剂对照（发同样的速度限制，但不携带源事件信息），未做。
3. **名单只有 60 辆、1 个种子。** 统计上不成立。
4. **区内时间占比两臂不同**（0.698 对 0.745）。论文第 230 行明确警告：消息让车变慢、停留更久，本身就能抬高区域风险。**这一条在当前结果里没有被排除。**

## 七、下一步判据

按任务表 T1 的止损线：
- 两臂风险差可测（4.6 倍），**未触发"信号太弱"止损**。
- 但**方向错误且量级极小**，说明设计层面有问题，不是统计问题。

要解决必须做两件事：
1. **安慰剂对照**：发同样强度的速度限制、但不携带源事件信息。若风险同样上升，说明现在的效应全是减速造成的，与信息无关。
2. **让目标区本身有可降的风险**：Krauss 稳态下风险近乎为零，没有下降空间。要么引入更密的交通、要么换更真实的跟驰模型。
