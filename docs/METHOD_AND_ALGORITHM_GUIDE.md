# AAD 方法与算法指南

## 解决什么问题

判断远端风险消息是否通过控制器采用而改变车辆动作和区域风险，并且这种变化是否早于普通物理传播。

## 直觉

必须先有可信的风险尺子和消息账本，才有资格比较“有消息”和“无消息”。

## 为什么需要

前车错配、轨迹噪声、不可观测通信字段或脱离现实的仿真都会制造无法解释的差异。

## 具体怎么做

阶段 0.1验证四格和五表；0.2用NGSIM审计跟驰风险；0.3用pNEUMA给出城市运动学分布；0.4冻结SPMD证据边界；0.5检查仿真覆盖；0.6锁定公式、容差和样本量。

## 数学表示

净间距 `g = SpaceHeadway - vehicle_length`；闭合速度 `Δv = v_follower - v_leader`。仅当 `g > 0` 且 `Δv > 0` 时，`TTC = g / Δv`，`DRAC = (Δv)^2 / (2g)`。

## 变量

`g`单位为米，`Δv`单位为米每秒，TTC单位为秒，DRAC单位为米每二次方秒。缺失、不可适用和无效必须与有效值分开。

## 代码实现

风险校准见 `code/src/riskprop/ngsim_risk_calibration.py`；通信边界见 `communication_observability.py`；覆盖度见 `simulation_real_coverage.py`；协议准入见 `protocol_lock.py`。

## 实验影响

阶段 0只决定测量、适用域和准入。协议锁前禁止运行阶段 1.1，任何校准结果都不能写成核心效应。
