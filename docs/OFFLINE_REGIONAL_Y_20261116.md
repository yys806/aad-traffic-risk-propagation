# 离线探索：用既有 B 源运行数据算区域风险 Y（2026-11-16）

> 性质：**EXPLORATORY / PILOT-ONLY**。区域、窗口、名单均为临时口径，不是 P4 正式输出，不能用于任何科学结论。
> 任务书：`docs/plans/2026-11-16-offline-regional-y.md`

## 一、做了什么

用 P2 Task8 已跑完的 268 个 B 源 SUMO 运行（`code/outputs/calibration/p2_task8_20261102_v1/raw/<run>/trajectory.npz`，
每 run 65 辆车 × 1000 步 @ 20 Hz），离线计算区域风险 Y。零新增 SUMO。

脚本：
- `code/scripts/offline_regional_y_exploratory.py`（计算）

输出：`code/outputs/analysis/offline_regional_y_20261116/`（`regional_y_by_run.csv`、`summary.json`）

## 二、口径（临时）

- 区域：全部车辆（单车道，`lane` 全为 0）
- 窗口：5–45 s，避开启动瞬态与末端边界
- 名单：窗口内有前车的车辆
- 风险：`rho = exp(-TTC / tau)`，`tau = 15.364279197080283`（2026-10-12 批准值）
- `TTC = gap / (v_self - v_leader)`，仅当自车更快且 gap > 0
- 无前车 → not applicable（不计入均值，单独计数）
- 有前车但不接近 → rho = 0（点识别）
- 输入无效 → [0, 1] 区间，不插值

## 四、发现

1. **区域 Y 的计算通路是通的。** 268 个 run 里 267 个都能算出点识别的 Y，上下界相同，没有出现"因输入无效而只能给区间"的情况。这说明全车面板数据足以支撑区域风险计算，之前说的"无合格输入"确实只是没有按规则生成的 run，不是数据拿不到。

2. **值域很窄，而且很低。** 最大 0.028，最小接近 0。按 `rho = exp(-TTC/15.36)` 反推，Y = 0.028 对应平均 TTC 约 55 秒。这意味着在这套仿真里，车辆之间的接近程度普遍很宽松。
   **这是一个需要正视的问题**：如果正式实验的区域 Y 也只有这个量级，那么"消息让风险下降"的可测量空间就非常小，很容易被噪声淹没。

3. **同配置内的离散度极小（标准差 0.00002–0.00011）。** 同一密度同一剂量下 8–32 个 run 的 Y 几乎完全相同。这不像是独立重复，更像共用同一随机流或几乎是确定性重复。**如果要拿它估配对方差，会严重低估真实方差。**

4. **N0/N1 恰为 0，A0/MAX 为 0.028，LOCAL4 反而最低（0.0033）。** 这个模式需要解释：为什么局部扰动比无扰动风险还低、而 MAX 与 A0 完全一样。可能的原因是这些剂量标签对应的实际扰动强度与命名不同，或者扰动位置与区域边界的关系不同。**在解释清楚之前，不能把这组数当成剂量—响应关系。**

5. **一个 run 名单为空**（`S1_medium_MAX_01`），按红线单列，未剔除、未补跑。

### 发现

1. **剂量—响应关系成立，而且是单调的**：MAX(10×12) ≈ LONG(8×12) > LOCAL8(8×1) > LOCAL4(4×1) = 0。扰动越强，区域风险越高。
2. **自然源与最强注入几乎完全一致**：A0 = 0.2477，MAX = 0.2479（差 0.0002）。这说明 MAX 的注入强度确实复现了自然源事件，注入规程在强度上是可信的。
3. **阴性对照干净**：N0/N1 精确为 0，LOCAL4 也为 0，说明小扰动传不到 cohort，指标没有虚高。
4. **只有 high 密度有信号**：low 与 medium 下全部为 0，包括自然源 A0 和最强注入 MAX。cohort 那 4 辆车的间距在前两种密度下从未进入接近状态。
5. **区间宽度为零**（上下界相同），说明窗口内没有输入无效的时刻。

### 这批数据给出的直接设计结论

- **正式实验必须用 high 密度**，low/medium 下注定测出零效应。
- **区域与名单用仓库已有定义**（1600–3080 m、第 14–17 号车），不要再自创。
- **剂量标签有真实含义**，之前"模式讲不通"的疑点已解释：LOCAL4 是最弱扰动（4 m/s×1 s），传不到 cohort，所以是 0 而非异常。
