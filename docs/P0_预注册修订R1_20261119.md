## 二、修订理由（与结果好坏无关）

> 研究要判断的是**固定需求与观察范围下的低 TTC 总暴露是否减少**，
> 而不是**实际占用时间中的暴露占比**。**占用本身会被干预改变。**

这条理由在两种情形下都成立：

- 若绝对量显示暴露下降 → 结论是"总暴露减少"
- 若绝对量显示暴露上升 → 结论同样是"总暴露上升"

而原比例口径在两种情形下都可能给出误导：任何让车在区内停留更久的干预都会抬高分母、稀释比例；
一个真正减少危险车·秒总量的干预，可能因为同时降低了通行量而在比例上显示为"变差"。

**注意：这不意味着原比例口径是错的。** 它回答的是另一个有效问题——"占用该区的车·秒里有多少处于危险状态"。
所以它保留为次要终点，而不是删除。

## 三、主终点的完整定义（锁定，不许事后改）

### 3.1 主终点

> **Y_a = 在固定区域 R、固定观察窗 W 内，臂 a 累计的「瞬时 TTC < 2.0 s」车·秒。**

锁定要素：

| 要素 | 定义 |
|---|---|
| 区域 R | x ∈ [3950, 4050] m（合流点上游 2 km 处，±50 m 测量带），**事前锁定，不因结果调整** |
| 观察窗 W | 源事件 t0 之后 660 s（与 P2/P3 冻结配置一致） |
| 瞬时 TTC | 净距 g ÷ 闭合速度 Δv；**g 为保险杠净距**（位置差 − 车长 5 m）；Δv = max(v后 − v前, 0) |
| 计入条件 | Δv > 0 且 g > 0.5 m（g ≤ 0.5 m 视为重叠/数值假象，单列核查，**不得用 g ≤ 0 制造高暴露**） |
| 无闭合（Δv ≤ 0） | TTC 无定义 = **缺测**，不计入分子，**也不得当作零暴露**；须单独报告占比 |
| 时间分辨率 | 0.05 s 步长；车·秒 = 帧数 × 0.05 |

### 3.2 次要终点（照常报告，不作确证）

1. **原 D2 比例**：Y_a ÷ 区域总车·秒（同一 R、同一 W）。同时报分子与分母。
2. 区域平均风险（1105 原式 ρ = exp(−TTC/τ)，按区内车·时加权）。
3. 近冲突事件计数（P2 判据：TTC<2 s、持续 >0.2 s、观测间隔 ≤0.11 s）。
4. 最大所需减速度 D = Δv²/(2g) 及其 D>2 车·秒（**机制诊断，不是主终点**）。

### 3.3 标准化的可选分母（若需要跨场景比较）

> **每 100 辆计划需求的低 TTC 车·秒 = 100 · Y_a / N_plan**

N_plan = 按**事前锁定**的入口、路线、发车时段定义的需求清单车辆数，各配对臂共用。

🔴 **计划车辆即使因回堵未插入、未进入目标区、未到达下游，也不从分母删除。**
这个量是"每单位计划需求的区域暴露负担"，**不是"进入车辆的风险"**。

⚠️ GPT 明确限定：**固定分母只能防"多停一会儿稀释比例"，不能防"少让车进来减少分子"。**
后者必须由 3.4 的通行与服务量判定处理。

### 3.4 代价与副作用（原 D3 不变，另加服务量界值）

主代价仍是**总延误（车·秒）**：实际行程时间 − 自由流行程时间，按窗口内车辆累计，相对同一评估车队的共同参考行程时间。

等效带须**完全落入预锁定区间**才算"等代价"，**不以"差异不显著"或事后筛运行代替**。

🔴 **新增：服务量不可接受下降的界值。**
即便延误等效，也**不能单靠延误一条排除"压低服务量换取低暴露"**。
必须同时核算五项：

| 项 | 说明 |
|---|---|
| 未插入数 | 计划需求里因回堵未能入网的车 |
| 目标区进入数 | 实际进入 R 的车 |
| 下游通过数 | 越过 x = 6000 m 的车 |
| 窗末仍在排队/未完成数 | 观测窗结束时未完成行程的车 |
| 总延误 | 含计划发车后尚未入网的等待 |

**不得拿当前 607/321 反推一个刚好能过的界值。** 界值须有独立的运营容忍依据；该依据目前**未核实**。

## 四、判定规则（与主终点配套）

| 判据 | 内容 |
|---|---|
| **判据 1：危险真实存在** | S1C0 的 Y 显著高于 S0C0；报**绝对车·秒差 + 95% 区间**，要求方向符合预期且区间不跨零 |
| **判据 2：增量存在（核心）** | 总延误等效检验通过的前提下，S1C1 的 Y 显著低于**本地臂**；同时报原比例口径作次要 |
| **判据 3：时机依赖与饱和** | 错时臂效应显著小于真消息臂；剂量曲线呈饱和形态 |
| **判据 4：全知上限** | 报告真消息臂效应相当于全知臂效应的百分比 |
| **判据 5：跨模型存活** | 换 IDM/EIDM 后符号一致、合并区间不跨零 |

**若 Y 下降但 D3 或服务量要求未过 → 只能写「观察到暴露下降，未证实是等代价改善」。**
