## 一、场景与配置（冻结值）

| 项 | 值 |
|---|---|
| 路网 | 一条 15 000 m 单车道直边，两端死胡同，无换道、无信号 |
| 源位置 | x = 6 000 m（**下游**） |
| 测站 | x = 5 500 / 5 000 / 4 500 / 4 000（距源 0.5 / 1.0 / 1.5 / 2.0 km，都在**上游**） |
| 测量带 | ±50 m |
| 车头间距 | 20 m（密，约 49 辆/km）／30 m（疏，约 33 辆/km） |
| 车速 | Krauss 平衡速度 = (车头距 − 车长 5 − minGap 2.5) / tau 0.6，上限 30 m/s |
| 跟驰 | Krauss，accel 2.6、decel 4.5、tau 0.6、minGap 2.5、speedDev 0.12、**sigma 0** |
| 预热 | 120 s，之后取离 x=6000 最近的车为源车 |
| 扰动 | 6 s 平滑降到 3 m/s（强）或 8 m/s（弱），**全程保持到观测窗结束** |
| 观测窗 | t0 之后 690 s |
| 种子 | 20261119、20261120 |

**两个关键设计约束（都是踩坑换来的）：**

1. **源车必须全程在网。** 之前三版（9 km + 保持 120 s；9 km + 300 s；15 km + 300 s）都因源车减速结束后
   恢复全速、开出道路尽头而使远站结果失效。**测传播不需要事件结束**；消散问题留给 P5。
2. **补给车不能参与跨臂配对。** 事件把上游堵住后，入口补车的插入时刻在两臂不同步，同一个编号
   已不是同一辆车，会凭空造出大量假见证（实测 892 个「见证」里只有 401 个可追溯）。

## 二、到达判据（主判据：固定空间速度场）

> U(站 s, 时刻 t) = 时空窗 (t−2 s, t] 内、位置窗 B_s 中所有车行驶的距离之和 ÷ 停留的车秒之和
> **到达** = U_不干预 − U_事件 ≥ 5 m/s，且连续 3 s
> **可判定** = 两臂各至少 2 车秒有效暴露；不足则标 NA，**不算「未到达」**

选择理由：同 ID 配对法只能用在「两臂从 t=0 就在路上的同一批车」，而车辆一直前进，
t0 后约 162 s 原本在 2 km 站的车就开走了，站里换成不可配对的补给车。
速度场法比较同一地段同一时刻的交通状态，不需要两臂出现同一辆车。

**辅助判据（保留，用于归因）**：同 ID 配对速度差 ≥5 m/s 持续 1 s 为「该车见证」，
测站 gate = 10 s 内有 3 个不同 ID 见证。它只覆盖配对车范围，不能用来判定远站「未到达」。

## 四、可以写的结论

1. **传播到 2 km 成立**：4 种配置（2 档车距 × 2 档强度）× 2 次运行，每个配置的 4 站全部检出到达。
2. **波速随车距变疏、扰动变弱而下降**，最慢约 7 m/s，最快约 16 m/s。
3. **时序上不支持入口反馈解释**：入口区（x<500 m）**首次**出现 ≥5 m/s 差异在 376.0 s；2.0 km 站**确认到达**在 127.0 s（20 m 强）。两者判据不同，不写成「早 258 s」。
   🔴 **限定**：这只排除了「入口补给车被影响后倒灌」这一种解释，**不等于排除了所有边界效应**。
4. **减速带连续**：时空图上从源车到上游无断裂（`spacetime_hw20_strong_s20261119.png`）。
5. **已检出见证的归因比例 100%**：20 m 车距 176 辆、30 m 车距 81 辆，全部可沿跟驰链追到源车。
   这是**已检出见证的归因比例**，不是检测灵敏度。

> **判据区分（防止混用）**：2.0 km 站「首次出现 ≥5 m/s 差异」= 118.0 s；「确认到达（≥5 m/s 连续 3 s）」= 127.0 s。
> **一切对外表述只用后者（127.0）**；118.0 仅作为诊断中间量，不进汇报。

## 五、不能写的结论（限制）

1. **「8 个种子完全一致」不能当稳健性。** 应表述为**确定性基准轨迹**：该配置下种子没有改变有效输入。
   要研究概率性质，需要显式抽样速度偏好、初始相位等。
2. **2 个种子不够估尾部。** 若要靠「零到达」把上限压到 10% 以下，需至少 29 个独立运行。
3. **速度场过阈 ≠ 归因确认。** 时空图是定性核验；定量归因只在配对车范围内成立。
4. **没有做边界对照**（延长道路两端）与**假事件对照**。
5. **只测了两种强度、两种密度**，没有扫渗透率、通信时延、跟驰模型。
