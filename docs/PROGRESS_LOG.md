# 第四部分：这周到底得到了什么（一句话各一条）

**真正站得住的：**
1. 统一响应能降风险，但代价是 23% 通行量 —— 这个交易不划算
2. 按消息内容分级分配动作，在两个通道上都没有增益
3. 风险指标的分辨能力很弱（AUC 0.56–0.67），只用车距几乎打平
4. τ 与分辨能力无关，只是显示刻度
5. 仿真的近冲突造不出来，根因是安全车速约束
6. 当前场景的 TTC 退化成间距的平方根，风险值是常数

**真正否掉的：**
1. 事件率 17.2（假象）
2. 内容分级降风险 0.63%（符号错）
3. 车距优势 1.84 倍（算错）
4. A0 是自然源（是诱饵）
5. 内容分级制造速度梯度（被推翻）
6. 真实 vs 仿真差 19 倍（是 6 倍）

**真正没解决的：**
1105 标注的十条未解决项，本周一条都没解决。其中「完整区域风险」从「算不出来」变成「算得出来但算的是合成人口」。
