# Stage 0.2 连续风险时间尺度合理性验证

日期：2026-10-11。该任务是已批准 `rho=exp(-TTC/tau)` 的描述性诊断，不重新优化 tau、不改变 P2 或生产 pipeline。

## Observation

四源时间加权 TTC 中位数沿用决策核定结果，`tau=15.364279 s`。在 tau 下时间加权平均 rho 为：Lankershim 0.4390；US-101 07:50–08:05 0.3375；08:05–08:20 0.3529；08:20–08:35 0.3833。tau/2 下分别为 0.2892、0.1841、0.1952、0.2206；2tau 下分别为 0.5824、0.5037、0.5224、0.5513。

在 tau 下，rho>0.9 的闭合暴露比例为 Lankershim 2.30%，US-101 三窗口为 0.62%、0.75%、0.85%；因此大量长 TTC 状态并未获得接近 1 的权重。rho>0.5 的暴露比例分别为 48.11%、31.31%、33.11%、38.07%。

TTC 分箱显示，tau 下 `<2 s` 暴露比例仅 1.01%–4.30%，但风险贡献比例为 2.74%–8.92%；`2–5 s` 暴露比例 7.93%–21.04%，贡献 18.44%–38.33%；`5–10 s` 暴露比例 19.95%–22.82%，贡献 29.74%–36.88%；`≥10 s` 暴露比例 53.86%–71.11%，贡献 23.01%–42.41%。完整分源、分尺度数值见 `rho_exposure_composition.csv`。

排除 TTC<0.5 s、DRAC>10 m/s² 或净间距<1 m 的探索性标记后，tau 下平均 rho 变化约 0.0008–0.0025，标记闭合暴露比例为 0.13%–1.11%。原始观测仍被保留。

P2 事件与可靠闭合边成员在四源均完全重叠；这说明事件定义与可靠闭合测量链连接一致，不构成独立事故真值。

## Interpretation

1. 当前 tau 没有让大量 `≥10 s` TTC 状态获得高风险权重。长 TTC 暴露量很大，但其条件 rho 较低；在 Lankershim，`≥10 s` 因暴露量大仍贡献 23.0%，US-101 三窗口贡献 36.5%–42.4%。
2. 风险负担由暴露时间和条件强度共同决定。短 TTC 的条件 rho 约 0.91，贡献效率高；长 TTC 的条件 rho 约 0.19–0.22，但暴露时间占比高，因此累计贡献不能忽略。
3. tau/2、tau、2tau 改变绝对风险水平，但来源排序基本保持：Lankershim 最高，US-101 07:50–08:05 最低，其他两个 US-101 窗口居中。该排序是描述性来源差异，不是道路类型因果结论。
4. 极端值对本轮主要聚合均值的影响较小，但尾部统计仍会改变，尤其不能据此删除极端观测。

## Unverified

- 现有校准源没有固定目标区域、固定目标车辆集合和统一评价窗口，因此本轮没有计算正式目标区域 burden。
- 没有独立事故、近失或物理几何真值，不能证明 rho 是事故风险概率或最优危险评分。
- 100 ms NGSIM 与 200 ms SUMO 的采样语义仍不可直接等价。
- P2 事件与高 rho 的重叠不能被解释为事件预测准确性。
- 逐帧观测存在轨迹内相关性，当前结果是暴露描述，不是独立样本显著性检验。

## Recommendation

保留 `tau=15.364279 s` 作为当前描述性时间尺度候选，并同时报告 tau/2、2tau 和来源异质性。不要把它写成事故最优参数，也不要用本轮结果修改风险函数或 P2 规则。下一步若要形成正式区域 burden，应先实现固定车辆/区域/窗口、状态贡献上下界和四格区间 DID，再进行独立验证。
