### 最重要的五个真实案例发现

1. 24 个预选案例均有新的逐轨迹分析和新图册，保留 Lankershim 原始行 31,245；23/24 同时由三套规则触发，1 个为 P3/P2 触发而 P1 未触发。
2. 三套规则都触发的案例中，确认时刻按实际观测帧推进：P1 相对 onset 通常晚 0.3 s，P2 晚 0.2 s，P3 晚 0.1 s；这不是使用未来帧的提前确认。
3. P1→P2 与 P2→P3 的成员图包含边界变化和一对多组件；因此阈值放宽同时带来新增风险过程与原过程延长/连接。
4. 极端压力标记覆盖范围随规则变化：union 标记事件为 P1 699、P2 789、P3 866；这些是重叠诊断，不是删除后的正式事件数。
5. 200-ms 隔帧结果未被当作采样稳健性证据；由于正式提取器要求 100-ms 连续性，公平采样比较状态为 `Unresolved`。

### 影响选择的主要证据与缺口

成员级对应、实际确认时刻和案例图支持对规则代价进行透明比较；但没有独立事故/近失真值、完整几何真值或可公平的降采样验证。因此目前不能科学地宣称 P1、P2 或 P3 具有唯一最优性，也不能把 P2 的“中间”位置当作推荐理由。P2 可作为条件性工程候选，正式选择仍需研究者裁决。

## 4. Q1–Q7 直接回答

**Q1。** P1 相对 P2 排除了 2,707 个无成员重叠的 P2 事件，且 P1 采用更低 TTC 和更长持续跨度；从成员图可确定这些过程不满足 P1 的联合条件，但其物理意义需人工/外部真值判断。

**Q2。** P3 相对 P2 增加 3,978 个事件总量；其中 4,238 个 P3 事件相对 P2 无成员重叠这一数字不等于“新增事件数”，因为分裂/合并和规则边界会改变成员图。P3 的中位事件时长 0.5 s，P2 为 0.5 s；因此不能仅凭总数断言新增事件全部是短暂或温和过程。

**Q3。** 三规则共有过程的确认延迟由实际观测验证为 P1 0.3 s、P2 0.2 s、P3 0.1 s；具体案例的绝对时间见 `event_confirmation_audit.csv` 与 `case_analysis_24.csv`。

**Q4。** P3 的较宽 TTC 条件覆盖更多近阈值状态，且 union 极端标记事件最多（866）；P1 的极端 TTC/DRAC 严格性更高但确认更晚。采样变化影响目前 `Unresolved`，不能据此排序。

**Q5。** 24 个案例提供了计算、时间和运动学一致性证据；没有独立几何或事故真值，不能明确支持/反驳某规则的真实危险识别准确率。Lankershim 行 31,245 保留且未被自动判错。

**Q6。** P1 的代价是漏掉较宽松阈值或较短确认跨度下的过程，并延迟确认；P3 的代价是更高事件负担、更多近阈值成员和潜在噪声敏感性；P2 处于两者之间但不自动获得科学优先权。

**Q7。** 若暂时优先考虑 P2，现有工程证据足以把它作为条件性候选，尚不足以作为最终科学规则。缺口包括独立安全真值、几何真实性、语义等价的采样敏感性、以及研究者对进入/退出/合并/暴露分母的决定。

## 8. 采样、确认与限制

正式连续性语义需要 100 ms 相邻时间/帧条件。旧的 200 ms 隔帧零事件结果不具备公平比较语义；本任务输出 `sampling_sensitivity_fair.csv` 并标记 `Unresolved`，没有把零事件作为稳健性结论。确认时间由成员实际 `time_s` 取值验证，所有输出事件的确认时刻都落在其观测成员范围内。

## 9. 候选规则决策矩阵（Proposal）

- **P1 strict：** 更严格、确认慢、事件负担小；可能遗漏早期或较温和接近过程；需要独立真值支持。
- **P2 middle：** 事件规模和确认延迟居中，工程上易于管理；仍受阈值选择、几何真实性和采样证据不足限制。
- **P3 sensitive：** 更早确认、覆盖更广；引入更多近阈值过程和更高噪声/误报风险；需要额外验证其消息触发成本。
