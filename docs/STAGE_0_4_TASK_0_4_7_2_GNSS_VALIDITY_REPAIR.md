## 2. 室内/室外有效 GNSS 覆盖

- **室内（indoor_1/2）：无有效 GNSS**——全部 tx 时间戳超出 GNSS 窗口（正确拒绝，非钳制）。
- **室外（outdoor_1/2）：tx 窗口 100% 被 GNSS 覆盖**（5,742–6,101/5,742–6,101）。GNSS 质量：单调、去重后 962,995 行、中位采样 10 ms、最大间隙 1.03 s（>50 ms 间隙处按策略拒绝插值）。

## 3. 三台设备轨迹是否独立、可信？室外真实距离？

**不独立（决定性 Fact）**：t1、t2、t3 的 GNSS 轨迹**逐点完全相同**（962,995/962,995 精确匹配；同一范围、同一 103 m 路径）——**它们是同一物理轨迹的复制品，不是三个独立设备的轨迹**。GNSS 含 23% 相邻重复坐标（静止段）。RSU 为静态单点（距轨迹 124–2,839 m）。

- **室外设备间（t1/t2/t3）距离 = 不可识别**：所有对 d≡0 m（同一轨迹），**非车辆重合、非计算错误**——是轨迹复制。
- **与 RSU 的距离**：RSU 静态，轨迹随时间变化（124→2,839 m），但 RSU 为单点、非连续在线证据，**距离—RSU 通信关系同样不可识别**（无独立 RSU 在线/定位精度证据）。

## 4. 距离—通信关系是否具有可识别性？

**不可识别（阻断证据充分）**：
1. 设备间轨迹相同 → 设备间距离无动态范围（恒 0）；
2. RSU 静态单点，无独立在线/定位证据；
3. 室内无 GNSS；
4. 插值≠时钟同步（跨设备时钟仍 Unverified）。

**结论：SEE-V2X 的距离相关通信参数（距离×PDR/时延）不可识别。** 不强行拟合、不外推。
