## 5. 三类判定表与可执行伪代码（Proposal）

D4的区间加B原则已批准；下列精度操作和“不满足/证据不足”的细分尚需审批。对差值theta_sim−theta_real给95%区间I=[L,U]，独立误差界B，J=[L−B,U+B]、A=[−delta,delta]。非对称/率比/单侧尺度须先批准。

```text
evaluate(metric, approved_contract):
    if required measurement/input contract is demonstrably violated:
        return 不满足(该契约); scientific estimate remains 不可评价
    if any required approval, definition, B/delta/h basis, common support,
       independent-validation role or required sample support is missing:
        return 证据不足(reason)
    compute I with the pre-approved dependency/CI method; J = [L-B, U+B]
    if precision requirement fails or I is unavailable: return 证据不足
    if J is fully within A: return 满足
    if J and A are disjoint: return 不满足(model_discrepancy)
    return 证据不足(boundary_overlap)

conjunction(required metrics × windows × declared conditions):
    if any required component is 不满足: return 不满足(with component/reason)
    if any required component is 证据不足: return 证据不足
    return 满足(eligible for researcher acceptance review, not automatic Gate change)
```

精度候选为h_obs=(U−L)/2≤h，B单报；非对称CI、联合区间与多重性由R1审批。辅助不参与合取；CI重叠、差异不显著、ED小、5seed同符号都不是等效。源码冲突使指标失去资格时，不用受污染数值裁定模型失败。
