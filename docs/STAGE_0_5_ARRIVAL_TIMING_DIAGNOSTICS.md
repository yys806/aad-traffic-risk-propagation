# Stage 0.5 边界到达时序与车辆交互动态诊断（AAD-0.5-ARRIVAL-TIMING）

日期：2026-10-21。结果 `RES-STAGE-0.5-ARRIVAL-TIMING-V1`。基线 `origin/main` = `3eb1246`。
机器证据：`evidence/results/RES-STAGE-0.5-ARRIVAL-TIMING-V1/`；本地胶囊：`code/outputs/formal/calibration/stage_0_5_boundary_timing_v1/`。

**一句话结论**：到达时间结构**不是**交互相容缺口的充分解释，而且主线部分**根本无法施加**。
把真实边界到达序列还原后，(1) 主线入口是一个排队受限的边界，声明的出发时刻被入队过程完全抹平——两臂声明的主线到达间隔 CV 为 0.25 与 0.86（0750）/ 0.20 与 0.91（0805），但**实现后**分别为 0.820 与 0.831 / 0.788 与 0.851，两臂几乎相同，平均入队延迟 25–30 s（0750）与 4.5–5.6 s（0805）；(2) 匝道到达时刻**能够**施加（实现后 CV 1.397/1.412 对 0.006/0.008，延迟 0.05–0.45 s），因此本轮实际成立的是一个**仅匝道到达时序**的对照；(3) 在该对照下，速度离散度**一致地朝真实值方向上升**（0750：1.17→1.42，5/5；0805：1.78→3.55，5/5，真实 3.64/3.99），但净拉开份额**反向恶化**（0.481 对 0.486；0.359 对 0.471，真实 0.530/0.537），局部 P2 率在两窗口**方向相反**（−0.23 与 +0.80），低速波结构**没有被恢复**（`propagating_structure` 计数：0750 U 4/5、E 3/5；0805 两臂均 0/5）。

因此：**H1 = Partially Supported**（方向性成立，但因果归因只能落在匝道这一条流上）；**H2 = Not Supported**；**H3 = Supported**（旧诊断确实因度量定义而失效，新诊断在真实与仿真之间具备判别力）。Stage 0.5 仍被交互相容层阻断。

## 2. 阶段 B：低速波诊断修正（Observation）

### 2.1 为什么旧指标必须退役

`jam_waves` 的绝对 10 m/s 阈值在状态匹配配置（平均 9.7 m/s）上不具判别力：慢单元份额在该配置为 0.84–1.00，而真实为 0.185/0.338，其差别主要来自"平均速度是否低于阈值"，而不是波动。本轮保留该量作为历史描述，并明确登记其局限。

### 2.2 新诊断与其判别力

- 主定义 `temporal_position`：单元格速度 ≤ 同位置自身时间分布的 α = 0.15 分位；无绝对阈值、无外部参考速度。
- 网格 50 m × 10 s，8 邻接。传播由相邻位置互相关滞后独立裁决；连通域质心斜率为伴随描述量。
- 置换零模型保留每个位置的异常次数、打乱时间位置；超越率 ≤ 0.05 才认为结构超出随机。

## 3. 阶段 C/D：配对对照结果（Observation）

### 3.1 到达保真度：本轮的关键发现

## 6. Stage 0.5 判定

- **仍被交互相容层阻断**。四项必要条件的现状与上一轮相同，本轮没有改变任何一项的结论等级：测量可信 Met；状态有支持 Partially Met；交互相容 **Not Met**；独立证据 Met（仅状态层）。

## 7. 下一步建议（Proposal，需另行授权）

按证据强度排序，只保留两项：

**P1（最强证据支持）——入口/汇入是生成过程的主控环节。**
本轮证明主线到达结构被入口排队完全吸收，且上一轮证明供给的**形式**决定相对运动。两者合并指向同一候选：**汇入/车道缩减区域的横向交互与合流冲突**才是离散度与风险事件的上游来源，而不是单车纵向上游到达时刻。
- 要检验的假设：把测量区放在**活跃汇入/车道缩减的下游**（而非上游排队尾），在匹配有效能力下能否同时给出真实的速度离散、净拉开份额与 P2 率量级。
- 判伪条件：匹配能力下仍无法同时满足平均状态与交互判据（与本轮车道缩减结果一致），则否定该方向。
- 额外授权：新的网络/供给编码（含把入口改为非受限上游边界、把排队置于网络内部可观测段），需要研究者批准场景范围；本轮禁止自行开启。

**P2（较弱）——入口排队应当显式建模，而不是被 SUMO 的待插入池吸收。**
本轮发现 `never_inserted` 达 13%（0750），意味着"边界需求"实际未被施加。若把上游排队段纳入网络（可观测、可存储），则到达时序与需求才真正可施加。
- 要检验的假设：显式上游存储段能把声明到达结构保留到网络内，从而使到达时序成为一个可施加的自变量。
- 判伪条件：加入上游段后实现 CV 与声明 CV 仍不相关。
- 额外授权：网络延长（新几何版本），需要研究者批准。

两项都不在本轮自行执行。
