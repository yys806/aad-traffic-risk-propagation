## 4. 推荐测量候选、公式与分母

令s_e、c_e、b_e分别为原核心事件的观测开始、首次确认、观测结束；W=[a,b)。推荐主候选：

`N_onset(R,W) = Σ confirmed_original_events I(s_e∈W) I(follower_front(s_e)∈R)`。

辅助一只改变空间归属为确认位置；辅助二要求s_e至c_e的**所有观测成员**在R。为隔离空间政策差别，推荐这两个辅助主表仍使用同一开始时间窗s_e∈W；另报告按c_e∈W的确认时间敏感性。不能在不同表中悄悄混用时间归属。本轮五个诊断窗口没有跨时间窗开始/确认边界的已确认事件，所以两种确认时间选择数值恰同，不代表普遍等价。

共同候选局部分母：

`E_R,W = Σ h × I(original_P2_evaluable_link) × I(both_follower_endpoints∈R) × I(full_link⊂W)`，`h=0.1s`；

`λ_R,W = N_R,W / (E_R,W/3600)`，单位events / P2-evaluable following vehicle-hour。

original_P2_evaluable_link严格继承同后车incarnation、同可靠前车、100ms/原索引连续、无身份/观测中断，且两端状态均在{valid,not_applicable}。非闭合但可靠跟驰仍贡献分母；无观测前车、invalid/missing及不可靠链接不补成零风险。不能使用局部车辆时间14680.35s替代可评价跟驰时间，也不能仅累计有风险片段或能在域内停留0.2s的车辆时间来重定义分母。

## 8. 科学容差、误差和准入候选

每层分开记录：(a)真实来源内采样波动，(b)两真实窗口差异，(c)测量/质量及共同系统误差，(d)独立seed和状态支持不确定性，(e)研究者允许的模型偏差δ。前四项不能自动决定(e)。共同处理偏差可能使双方看起来接近；相关性未知时不能假定误差抵消。

候选标量规则：令Δ=sim−real；事先选择置信水平/多重性方案，构造Δ的相关性适当区间，再加入独立有依据的测量系统误差集合B。只有 **整个区间⊕B落在研究者批准的[-δ,+δ]内**，且支持/质量层满足时，才可认为该项满足候选误差判据。无δ、无B依据或区间过宽，不输出科学通过。均值、尾部分位、率分别有单位；不得用“不显著/CI重叠”宣称等效。

分布指标可预先选定分位差联合区间/经验CDF或一维Wasserstein，并披露状态/质量支持；不在看到模拟结果后换成更容易过的指标。Energy Distance仅辅助；0.90/0.95工程默认值不升格。现有real-real上界继续Not Identifiable，两个相关校准窗口不能识别道路总体可接受距离。

真实簇CI（全来源约±15%）只表达封存统计不确定性；本轮局部开始率轨迹簇敏感性为21.153、区间[16.822,25.756]，2000次、统计seed20261020。该区间联合重采样N和E，376个后车簇，不使用逐行iid；但同一交通互动/共同供给/时间依赖和独立seed/模型偏差不在其覆盖内，不能作为正式率CI或科学δ。零事件时经验bootstrap的零宽区间不作零风险证明。若用Poisson/负二项等区间，须预先审查其到达/过散假设，不能按希望的精度选模型。

统计置信区间、覆盖总体观测比例的统计容忍区间，本身也不是同一种对象；本项目更不能将其中任意一种直接解释为允许的模拟模型偏差。[NIST/SEMATECH](https://itl.nist.gov/div898/handbook/prc/section2/prc263.htm)

不通过应分为：Measurement Failure（身份/时钟/定义/SHA或数值冲突，停相关流程）；Evidence Insufficient（支持不齐/精度不足/误差不可识别，补证据或限范围）；Model Discrepancy（在已批准且精度足够的共同支持上超出margin）；Awaiting Researcher Decision（口径、margin、目标或窗口未批）。候选函数即使满足方法条件也不会改项目Gate。
