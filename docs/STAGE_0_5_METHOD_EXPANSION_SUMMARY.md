# Stage 0.5 方法扩展综合报告（AAD-0.5-METHOD-EXPANSION）

日期：2026-10-20。结果 `RES-STAGE-0.5-METHOD-EXPANSION-V1`。

**一句话结论**：SUMO–Krauss 复现不了 US-101 拥堵，**主要不是"参数没调好"**。真实车辆跟得比任何被冻结的跟驰模型允许的更近；把期望时距 `tau` 调大（宏观反推建议的方向）会让误差**单调变大**；把静止间距 `minGap` 调小、或去掉抖动 `sigma` 才会改善；而在**不同模型结构之间**（Krauss / IDM / Newell）误差水平相近，说明剩余差距不是靠换模型能一步解决的。因此本任务给出的是 **Level 2（有效部分成果）+ Level 3（明确的不可识别结论）**，不是 Level 1。

本报告不使用"模型效果改善"之类的笼统说法；每条结论都标注证据类别。

## 3. 通俗解释：为什么"把 tau 调大"必然失败

SUMO 的 Krauss 在平衡态要让后车保持约 `v·tau + minGap` 的净间距。观测到的真实车辆对，其间距水平**低于**这个式子；也就是说真实驾驶员跟得更近。于是：

- **把 `tau` 调大** → 模型要求的间距更大 → 与真实差距更大 → 误差单调变大（+18.3 → +40.7 → +72.5 pp）。
- **把 `minGap` 调小** → 模型要求的间距更小 → 与真实更接近 → 误差变小（−7.3 pp）。
- **把 `sigma` 关掉** → 不再随机减速 → 间距更小 → 误差变小（−6.3 pp）。

之前从**密度**反推出来的"有效 `tau`≈1.53–1.63 s"并没有错，但它是**拥堵区宏观平衡的等效量**，不是驾驶员的期望时距。用它去改微观参数，方向正好相反。

**不同模型结构**（Krauss、IDM、Newell 原型）在同一个名义时距下给出相近误差（47.6 / 50.9 / 53.1%），且都随 `tau` 增大而变差 → 剩余差距更像是"间距水平的分布（异质性）"问题，而不是"选错了模型"。

## 4. 数据与工具能否支持进一步研究（Level 3：明确的不可识别）

**可以检验（有数据支持）**：`tau` 的方向与量级；`minGap` 的方向；`sigma` 的确定性部分；Krauss/IDM/Newell 之间的结构差异；局部与长期误差的分层。

**当前无法识别（`Unidentifiable`）**：
1. **真实自由流速度**从未实测；所有"相对速度"参考只能取自窗口本身或工程设定 27.78 m/s（后者不是实测值）。
2. **真实静止间距（`minGap` 的物理值）**：只有"减小会改善"的方向信息，没有绝对量。
3. **观测之外的交通状态**：样本没有完整排队循环，无法校准"需求历史 / 下游容量"。
4. **异质参数**：用同一条轨迹构造它自己的参数再评价它自身，是循环拟合；按车辆对划分构造/评价集需要比 12 对更多的样本（本任务判为 `Blocked`）。
5. **FHWA 四条可接受性准则**：需要同一交通条件的多日样本来算 `σ(t)` 与 BDAE 阈值，本项目只有两个不同条件的 15 分钟窗口 → `Blocked`。
