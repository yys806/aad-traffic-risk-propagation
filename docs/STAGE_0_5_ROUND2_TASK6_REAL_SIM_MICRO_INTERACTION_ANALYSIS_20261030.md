## Executive Summary

**Observation：差异首先在联合交互条件，而不只是间距大小。** Round2 源区 gap 第5分位为 3.370 m，低于两个真实窗口的 4.916/4.392 m，仍没有可靠 `0<TTC<2s` 状态。真实源区正闭合速度中位数为 0.869/0.680 m/s，B00/候选为 0.430/0.490；gap—正闭合速度 Spearman 相关为 0.095/0.124 对 0.527/0.480。仿真中较大的闭合速度更集中于较大的间距，小间距与较大闭合速度的共同出现受到明显限制。

**Observation：换道相关交互在部分事件附近更常见，但不足以单独解释源区差异。** ±2 s 内，真实源区有 27/167、33/159 个事件观察到后车换道、后车前车更换或 onset 前车换道；对应非风险对照为 2/165、5/149。这是观察关联，尚未识别因果贡献。即使要求两个角色均有完整上下文，仍有 122、114 个事件没有观察到这些转换。SUMO 本身也存在这类交互：源区近阈值片段的 3/4、2/3 有新前车车道进入签名。不能宣称仿真完全缺少换道，也不能把目标区唯一事件当成源区传播。

**Interpretation：** 现有证据更支持“低速下相对速度波动和 gap—closing 联合组织尚未再现”，削弱“只需更小 minGap”“仅持续时间阻断”“所有真实事件均由切入形成”的解释。安全速度约束、动态响应、扰动输入与测量质量仍不能被唯一分离。这是描述性差异分析，不是正式 Model Discrepancy 或 simulator equivalence 裁决。

**Proposal：** 保留当前源区作为有实际事件支持的研究对象供研究者审阅；首先做有限、预先列样的独立物理质量核验，再决定是否值得单独授权一个固定前车输入的动态响应判别实验。本任务不推荐新的参数或跟驰模型，不需要为完成当前描述性问题新增仿真。
