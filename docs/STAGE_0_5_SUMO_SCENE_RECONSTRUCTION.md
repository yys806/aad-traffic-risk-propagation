## 5. 结果解读（Derived）

1. **结构 + 观测边界需求不产生拥堵。** RC1 用真实 5 车道 + 匝道 + 辅助车道的拓扑和真实边界需求，仍落在自由流分支，且 `q = 1,811 veh/h/lane` **高于**观测拥堵流量 1,647。因此「此前失败是因为 3 车道、没有匝道」这一解释**不成立**。
2. **注入真实拥堵状态不保持。** RC2 从观测拥堵状态（前 30 s 16.7 m/s / 34.1 veh/km/lane）出发，180 s 内完全回到自由流。因此「此前自由流只是空网初始化的假象」这一解释**不成立**：即使初始状态正确，**在观测需求下 SUMO 也不维持该状态**。
3. **条件下游供给可以进入拥堵分支，但落点与目标不符。** RC3 用 3 车道下游（解析容量 ≈ 观测流量）得到 6.76 m/s / 61.35 veh/km/lane，**比目标更深**，且其流量（1,492）**低于**观测拥堵流量（1,647）。说明 SUMO 产生的拥堵是「瓶颈前的排队/停走」，不是真实观测到的**均匀同步流**。
4. **真实状态在 SUMO 的两支之间。** 自由流支流量 1,818 > 真实 1,647 > 停走支流量 1,492。真实观测的 `(k=43.5, v=10.5)` 既不是 SUMO 的自由流平衡点，也不是 SUMO 排队状态的点。

## 7. 拥堵分支诊断：为什么同一流量只在自由流支可达

`scene_vs_real_congested_branch.json`。

Krauss 平衡态（σ = 0）满足 `v · tau + L + minGap = 间距`。用冻结参数 `tau = 1.0 s`、`minGap = 2.5 m`、`L = 4.4196 m`：

| 量 | 0750–0805 | 0805–0820 |
|---|---:|---:|
| 观测密度 [veh/km/lane] | 43.544 | 50.505 |
| 观测间距 `1000/k` [m] | 22.97 | 19.80 |
| **冻结参数下的平衡速度** [m/s] | **16.05** | **12.88** |
| 观测速度 [m/s] | 10.51 | 7.92 |
| 由**密度**反推的有效 tau [s] | **1.527** | **1.628** |
| 由**观测净间距**反推的有效 tau [s] | **1.552** | **1.627** |
| 两个估计之差 [s] | 0.025 | 0.001 |

**Derived**：在冻结参数下，观测密度对应的平衡速度（16.05 / 12.88 m/s）显著高于观测速度（10.51 / 7.92 m/s）。**观测阻塞分支不在冻结模型的平衡分支上。**

**Derived + Observation（两条独立路径一致）**：观测密度给出有效时间间隔 1.527 / 1.628 s，观测净间距（18.81 / 15.38 m）给出 1.552 / 1.627 s，**两个互相独立的观测统计在两个窗口内都一致地指向约 1.5–1.6 s**，而冻结值为 1.0 s。

**Hypothesis（需要研究者决定 + 受控探针）**：观测到的真实拥堵态对应的有效车头时距大于 SUMO 默认值，这是「同一流量只能在自由流支可达」的定量原因。**本任务不做参数搜索**：`tau`/`minGap` 是行为模型参数，任何调整都必须先经研究者批准，并用分层、可解释、带独立证据的方案（本诊断已提供两条独立证据），且必须先验证它对自由流容量与其它已验证量的影响。

**注意**：该诊断只使用冻结参数与观测统计的解析推导，**不是一次容量标定实验**；`requires_controlled_probe = true`。

## 9. 场景的适用范围与未解决问题

**可以支持**

- 该拓扑与边界需求下，自由流分支可达且断面流量可复现。
- 在观测需求下，注入的拥堵状态不保持。
- 声明的条件下游容量限制可以把场景推入拥堵分支。

**不能支持**

- 不能声称已复现真实 US-101 拥堵（状态支持未达成）。
- 不能声称下游瓶颈的位置、容量或其真实机制。
- 不能给出任何现实的 P2 率比较或覆盖结论。
- 不能给出科学容差 δ、精度 h 或评价窗结论。

**未解决**

1. 真实拥堵的形成过程（队列生成事件）不在观测覆盖内：需要**条件性的需求历史假设**，或扩展网络到下游真实瓶颈（无证据）。
2. 是否存在一个既不过疏也不过密的供给设置能把状态锚定在 `(43.5, 10.5)`：本批未搜索，且预声明停止规则禁止在同一批内搜索。
3. 行为模型参数（时间间隔 / 最小间距）与观测拥堵分支的定量匹配：需要受控平衡态探针，属研究者决定。
