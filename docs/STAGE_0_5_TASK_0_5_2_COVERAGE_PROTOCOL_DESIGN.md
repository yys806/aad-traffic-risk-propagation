## 3. 分场景指标协议矩阵

下表是 **Proposal**。`核心验收` 表示未来若研究者批准，该指标在对应场景中属于不可被其他指标补偿的必要条件；不表示当前已经存在数值阈值。

### 3.1 US-101 高速公路主线

| 层级 | 指标 | 建议角色 | 共同测量语义 | 科研理由与限制 |
|---|---|---|---|---|
| 基础运动学 | 速度分布（均值、P05/P50/P95、低速比例） | 核心验收 | 0.1 s NGSIM state 语义；SUMO 必须按同一评价窗口和单位汇总 | 速度影响流态和减速波，但接近速度不代表跟驰机制正确 |
| 基础运动学 | 纵向加速度分布及极端比例 | 核心验收 | m/s²、保留有效/不可评价状态分层 | 直接影响减速波和风险形成；尾部差异不能被速度均值抵消 |
| 基础运动学 | 低速/近停止状态占比 | 辅助诊断，必要时升格 | 预先定义速度区间，不能把缺失当停车 | 反映交通状态，但受需求和窗口影响，不能单独代表道路真实性 |
| 跟驰交互 | 净间距分布 | 核心验收 | 仅可靠前车、正净间距、共同单位；按场景/窗口独立报告 | 直接影响 TTC 机会和物理扰动传播；需保留不可评价原因 |
| 跟驰交互 | 闭合速度分布及符号 | 核心验收 | 继承 Stage 0.2 的闭合方向和 0.1 s 语义 | 闭合速度与间距共同决定 TTC；不能只比较绝对值 |
| 跟驰交互 | leader 匹配、可靠跟驰资格、可靠暴露时间 | 核心质量门槛 | 继承身份、时钟、连续性和可靠状态规则 | 这是风险指标可评价性的前置条件，不是可由运动学距离补偿的指标 |
| 风险可观测性 | TTC 有效比例、missing/invalid/not_applicable 比例和原因 | 核心质量门槛 | 不改变 Stage 0.2 状态语义；`not_applicable` 不等于零风险 | SUMO 若有效率或不可评价结构异常，TTC 分布不可解释 |
| 正式风险 | P2 数量、P2 可评价跟驰暴露、P2 事件率 | 核心验收 | 完整事件表和完整 P2 可评价暴露；不得由抽样重算 | 是 AAD 风险基线的直接约束；事件率不是事故概率，分母不可改写 |
| 正式风险 | 事件持续时间、`ttc_min_s`、`drac_max_mps2` | 辅助诊断/敏感性 | P2 规则不变，DRAC 不替代 TTC 触发 | 用于解释严重程度和尾部差异；不应掩盖 P2 数量/暴露失败 |
| 多维汇总 | Energy Distance | 辅助诊断 | 场景内、预定义指标集合、校准 scaler | 可概括多维差异，但不能解释为机制真实性或自动阈值 |
| 类别支持 | stratum coverage | 辅助质量诊断 | 需同时报告每层样本量和暴露，不只报告类别出现 | 当前实现只检验类别集合交集，不能证明每层充分支持 |

US-101 主线的候选必要条件应至少覆盖速度、加速度、净间距/闭合速度、风险可观测性和 P2 暴露/事件率五层。任何一层失败都不能被另一层的综合分数抵消。

### 3.2 Lankershim 独立城市道路辅助线

Lankershim 可以复用上述指标类别，但每个指标单独报告、单独拟合描述性范围，不进入 US-101 的 pooled scaler、总体分布或主 Gate。建议输出 `Auxiliary / Independent Urban Risk Evidence`，包括速度、加速度、净间距、闭合速度、TTC 状态、P2 暴露和 P2 事件率，但不把其较高事件率直接解释为城市总体风险。

Lankershim 的合并 CSV、未知 source period、身份/诊断时钟限制和较高不可评价比例，使其适合发现城市跟驰参考是否明显失真，不适合提供 US-101 主线的正式 real-real 上界。是否将其升级为独立正式 Gate，需要另行批准。

### 3.3 pNEUMA 城市混合交通运动学补充线

| 指标 | 建议角色 | 说明 |
|---|---|---|
| 速度分布及低速比例 | 城市运动学核心 | 报告全体时间加权与车辆等权，并按原始车型分层 |
| 纵向加速度分布 | 城市运动学核心 | 报告时间加权、车辆等权和极端观测敏感性 |
| 原始车型组成 | 核心支持度指标 | 保留 Car、Motorcycle、Taxi、Medium Vehicle、Bus、Heavy Vehicle；不映射 SUMO `vType` |
| 分车型速度/加速度 | 辅助诊断 | 仅在轨迹数和可靠暴露足够的车型上解释；Heavy Vehicle=2 轨迹不设总体验收阈值 |
| 时间加权—车辆等权差异 | 核心解释指标 | 用于揭示长轨迹和车辆异质性，不作为两者谁“正确”的选择 |
| TTC、DRAC、前车、P2、风险事件 | 当前不可比较 | canonical pNEUMA 没有这些职责和共同测量语义，禁止恢复 |

pNEUMA 只支持单文件、单站点/窗口的城市混合交通运动学适用域。内部车辆/轨迹分组可产生不确定性诊断，但不能成为独立城市道路验证。

## 4. 校准与独立验证隔离候选

### 4.1 US-101

**Observation：** 三个窗口相邻且同站点；R2 的车辆 ID 在窗口间大量重叠（例如窗口对重叠约 1,376–1,524 个 ID），但没有证据证明字符串相同就是同一物理车辆，也没有跨窗口完整轨迹连续性证明。因此窗口时间独立不等于道路环境独立，也不能宣称已经消除所有泄漏。

**方案 A：完整窗口固定隔离。** 预先指定一个完整窗口只作验证，其余两个窗口只作校准；推荐候选是用前两个窗口校准、最后一个窗口做时间顺序验证，以检验有限的向后时间外推。验证窗口在调参前封存，查看一次后不得反复调参。优点是隔离单位清晰、保持完整跟驰结构；代价是只有两个校准窗口、验证仍来自同一站点和道路。

**方案 B：留一窗口交叉诊断。** 对三个窗口分别执行一次“两个校准、一个验证”，预先固定三轮，不根据最优结果选择窗口。优点是显示时间状态敏感性；代价是同一真实来源被多次用于开发判断，不能当作三次独立正式验证，也会增加调参诱惑。

**推荐：** 方案 A 作为未来主验证候选，方案 B 只作预先声明的稳定性诊断。精确窗口、是否接受同站点时间外推和调参停止规则必须由研究者批准。

车辆/轨迹内部划分可以作为方案 A 校准窗口内的敏感性，但不能替代完整窗口验证；在跨窗口身份未证实前，不得以 vehicle ID 去重后声称实现了物理车辆隔离。

### 4.2 Lankershim

当前只有一个合并 CSV，source period 仍为 unknown。可以在完整车辆/轨迹簇上做一次预先固定的内部描述性分组，估计不确定性；不能把相邻片段拆成两个独立道路来源，不能产生可信的 real-real 正式上界。正式职责建议保持辅助报告，研究者可另行决定是否设置“辅助场景必须无明显失真”的非主 Gate 条件。

### 4.3 pNEUMA

单文件内部车辆/轨迹簇重采样可用于误差条和时间加权—车辆等权敏感性；不能称为独立外部验证。没有独立城市道路或独立时间文件前，pNEUMA 的外部验证状态应为 `Evidence Insufficient`。

### 4.4 未来锁定规则

1. 校准只读取预先声明的 calibration 窗口/车辆簇和完整 pNEUMA 运动学摘要。
2. 验证数据在校准参数和候选阈值登记后才解封查看；查看后不得回改参数并继续使用同一验证结果作为确认性证据。
3. 每个验证输出记录协议版本、输入哈希、seed、参数版本和查看时间。
4. 失败只能进入预先定义的失败或新协议版本流程，不能通过换指标、换窗口或改变测量规则修复。
5. 这些内部分区与项目原有 locked holdout 完全不同；本任务不解锁任何 holdout。

## 5. Energy Distance、real-real 与 stratum coverage 审计

### 5.1 当前实现事实

`evaluate_simulation_coverage()` 当前要求至少两个 real groups，将所有真实组拼接后用 `fit_robust_scaler()` 拟合 pooled median/IQR scaler；用同一 scaler 计算所有 real-real 两两 Energy Distance，按 `real_real_quantile` 取上界，再把 pooled real 与 simulation 比较。`stratum coverage` 只计算真实类别集合与仿真类别集合的交集比例。默认 `0.90` 和 `0.95` 是函数默认值，不是科学批准阈值。

### 5.2 为什么不能直接作为正式容差

- R2 的四个 NGSIM 组不是四个可交换 iid 真实来源；US-101 窗口相邻且 ID 重叠，Lankershim 环境不同，pNEUMA 没有第二个独立来源。
- 行级状态高度时间相关，同一车辆/轨迹不是独立抽样单位；两两距离把长轨迹和高采样密度重复计权。
- pooled scaler 受来源组成、车型、交通状态和样本量影响，导致距离同时反映场景混杂和模型偏差。
- real-real pair 数量少且有效独立组不足；分位数不能从“可计算”自动变成自然变异上界。
- 当前 stratum coverage 只检验类别出现，不检验每层暴露、样本量、分布或风险资格是否充分。
- 有界哈希样本不是时间权重样本；用它形成 real-real 阈值会把计算预算和抽样规则混入科学容差。

### 5.3 最小化改进候选

建议不替换现有函数，而在 0.5.2 协议层约束其用途：

1. 按 US-101、Lankershim、pNEUMA 职责分别计算，不跨环境 pooled。
2. scaler 只由预先声明的 calibration real 数据拟合；验证数据不参与 scaler 或阈值。
3. Energy Distance 只作为多维辅助诊断，同时报告每个核心指标的可解释统计和质量状态。
4. 若 real groups 没有独立来源资格，输出 real-real 距离作为描述性差异，并标记 `Not Identifiable`，不生成科学上界。
5. 若未来获得足够独立组，优先以车辆/轨迹簇为重采样单位，报告 cluster bootstrap 或预注册的块级不确定性，而不是把行数当作独立样本量。
6. stratum 指标至少同时报告每层状态数、车辆/轨迹数、可靠暴露、有效/不可评价比例和车型覆盖；集合 coverage 只能作为辅助检查。

## 6. 科学容差候选与验收语义

### 6.1 容差依据

当前没有足够证据给出正式数值容差。可用于形成候选容差的依据及其适用性如下：

| 指标层 | 可用依据 | 当前状态 |
|---|---|---|
| 速度、加速度 | calibration 窗口内车辆/轨迹簇 bootstrap、窗口间实际差异、单位明确的分位数/分布距离 | 可形成条件性候选；不能直接从 pooled 行分布定值 |
| 净间距、闭合速度 | 可靠跟驰车辆/轨迹簇统计、窗口内状态差异、符号和单位检查 | 可形成条件性候选；需先固定 leader/资格语义 |
| TTC 有效率和不可评价比例 | Stage 0.2 状态语义、来源内质量比例和暴露结构 | 可作为必要质量门槛候选；阈值尚未有独立依据 |
| P2 数量/事件率 | 完整 P2 事件、P2 可评价暴露、车辆/轨迹簇块级不确定性 | 指标科研必要性高，但三窗口不足以识别稳健 real-real 上界 |
| pNEUMA 分车型指标 | 车型内轨迹数、可靠暴露和时间/车辆等权差异 | Car/Motorcycle/Taxi 可做描述性候选；Heavy Vehicle=2 不可定总体容差 |
| Energy Distance | 独立 real groups 和预先声明 scaler 的条件下 | 当前仅描述性/辅助；不具备正式上界资格 |

任何数值候选都必须同时写明：测量时间分辨率、统计单位、质量资格、适用场景、校准/验证用途和 AAD 风险敏感性。不能根据未来 SUMO 结果倒推容差。

### 6.2 分层验收原则

建议未来采用“必要条件集合”，不使用可互相补偿的单一综合分数：

- **基础运动学层**：速度和纵向加速度必须在适用域内；
- **跟驰交互层**：净间距、闭合速度、leader/可靠资格和暴露结构必须可比较；
- **风险可观测性层**：TTC 有效/不可评价状态比例和原因不能明显失真；
- **正式风险层**：P2 事件、P2 可评价暴露和事件率必须按原规则比较；
- **场景支持层**：车辆/轨迹/车型和每层可靠暴露足以支撑该指标解释。

一项必要风险层失败时，速度层通过不能覆盖它。辅助指标只能解释失败原因，不能提升 Gate。

### 6.3 候选状态语义

以下是协议候选语义，不是当前注册表机器状态：

- `Pass Candidate`：所有预先声明的核心层均可比较且满足研究者批准容差，辅助指标无阻断性质量问题；
- `Fail`：存在共同测量语义且证据足够的核心层失败；
- `Incomparable`：指标、来源或仿真输出没有共同测量语义；
- `Evidence Insufficient`：样本独立性、暴露、质量或容差依据不足，不能判定通过/失败；
- `Blocked`：必要工程前置条件尚未完成，例如没有 SUMO 样本或没有批准的协议。

当前 R2 仅提供真实参考，不能产生上述任何 Stage 0.5 最终状态。

## 7. 对 AAD 后续因果研究的充分性

Stage 0.5 的必要性来自基线偏差可能伪装成信息效应：

1. 净间距和闭合速度错误会改变 TTC/P2 风险机会，直接影响远端风险状态的基线。
2. 加速度和跟驰响应错误会改变减速波传播速度和幅度，可能把普通物理传播误解释为风险消息作用。
3. P2 基础事件率错误会改变后续效应的可检测性和方差，影响样本量与尾部比较。
4. 需求、密度和低速状态错误会改变扰动传播环境，不能只用单车运动学距离补偿。
5. 质量状态比例错误会让“风险减少”只是不可评价观测增加。

因此，US-101 的净间距/闭合速度/TTC 资格/P2 暴露与事件率比单纯速度相似更接近 AAD 的科学必要条件。pNEUMA 对车型混合和城市运动学有补充价值，但不能证明高速公路风险机制或远端传播。Stage 0.5 仍不能替代后续对物理传播、信息到达、采用、响应和因果识别的 Stage I/II 验证。

## 8. Stage 0.5.3 最低工程输入契约候选

以下是构建无消息 SUMO 场景前的 **Proposal**，不冻结时间步、车型映射或需求参数：

| 契约项 | 最低要求 | 事实/风险 |
|---|---|---|
| 场景身份 | `scenario_id`、职责标签、来源/窗口、适用域 | 防止 US-101、Lankershim、pNEUMA 混合 |
| 道路/需求 | 网络版本、车道/连接、需求窗口、密度/流量分层 | Stage 0.1 双走廊物理断开，只能复用工程封存能力，不能直接当覆盖网络 |

| 时间 | state time、simulation step、评价窗口、暖机窗口 | Stage 0.1 为 0.2 s，NGSIM 正式语义为 0.1 s，不能直接等价 |

| 运行控制 | seed、warm-up/evaluation window、需求/车型/行为参数版本 | 保证校准和验证可追溯、不可事后挑 seed |
| 封存 | config、provenance、manifest、SHA256SUMS、失败日志 | 失败和不可比较必须可复核 |

**时间方案候选：** 0.1 s state 输出最接近 NGSIM 正式语义，但计算和存储成本较高；更细 SUMO internal step 后按预先固定规则聚合可保留数值稳定性，但增加实现复杂度；0.2 s 只适合 Stage 0.1 工程 smoke，不能直接承担 NGSIM 风险比较。精确方案需研究者批准。

## 10. 结论与下一任务

**Observation：** R2 足以支持分场景指标设计和风险质量约束，但不能支持 pooled real-real 科学上界或正式数值容差。

**Interpretation：** US-101 是唯一当前可承担 Stage 0.5 主风险线的来源组合，但三个窗口只能支持有限的同道路时间外推；Lankershim 和 pNEUMA 应保持职责隔离。Energy Distance 适合辅助发现多维差异，不能替代可解释的风险层必要条件。

**Proposal：** 研究者先批准第 9 节六项协议选择，再进入 0.5.3。下一项 Codex 任务建议为“按批准协议建立 SUMO 无消息场景输入/输出骨架与验证隔离配置”，仍需在实际运行前单独批准，不自动运行 SUMO。
