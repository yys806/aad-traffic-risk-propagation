## C：观测、资格和替代解释

Observation：9.4s首次内部低速；9.75s首次pending及独立入口空间阻塞；10.35s首次至少2车空间队列；11.3s上游扩展；11.7s入口邻近。最久组件49.65s，耦合入口+下游锚定持续0s。末端63实际进入、6驶出、57在场、87外部pending，全网守恒0；局部33入/21出，局部车辆时间572.65veh-s。

不能说“先形成合格内部队列再出现pending”：实际pending早于2车队列资格；低速、队列资格、入口到达和外部积压是不同事件。入口组件虽有独立几何阻塞，仍未连接下游锚定组件。60s反例中同path入口组件前端65.499m、下游组件车尾约79.85393m，净距约14.35m>10m；不能任意桥接。Evidence Insufficient不等于Queue Absent。

Interpretation：候选队列合同可识别道路内密集低速、入口邻近和入口外未服务需求，但当前合同不能独立确认整条入口—下游连续回溢。跨junction存在实际空间间隙，坐标可比较不等于车辆已连接。

Hypothesis：junction通行/保留空间等可能参与车群分裂；本轮没有识别其独立因果贡献，也不能据此认定信号是唯一原因。Proposal：下一计划可把局部跟驰状态作为职责，保留入口回溢EI并排除其结论；若研究目标必须完整回溢，则另设计空间/因果证据，不事后调整10m。
