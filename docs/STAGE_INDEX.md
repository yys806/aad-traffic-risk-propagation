## stage_0_2 — NGSIM 跟驰风险审计

当前主任务。审计前车关系、净间距、闭合速度、TTC、DRAC和风险事件，并整理现实参考范围。

## stage_0_3 — pNEUMA 城市运动学校准

只整理速度、纵向加速度和车型分布；不再推断前车，不计算 TTC/DRAC，不进行人工前车复核。
