# AAD-S0.5-TASK18 Primary 与 Supplementary 结果

Primary 矩阵 60/60 PASS，A/B 实际轨迹配对 30/30 PASS。Supplementary 矩阵 40/40 PASS，A/B 实际轨迹配对 20/20 PASS。

六组同 seed 复验全部轨迹哈希一致、最大 Follower 速度差为 0。Primary+Supplementary 的 20 个 candidate/tau/arm 组均观察到 5 个不同轨迹哈希，说明 sigma=0.5 的随机重复实际生效。

这些结果支持执行器可重复、A/B 可配对和原生跟驰链路可审计；Task9 仍是固定 Leader 条件下的局部跟驰响应实验，不直接支持 AAD 核心因果结论。
