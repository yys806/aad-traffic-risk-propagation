# 潜在核心科学贡献（Proposal）

本文件不冻结研究方向；它把文献审计后仍可能成立的贡献写成可检验条件。

## C1：双传播竞争的事件级机制

定义独立的 information arrival time 与 physical arrival time，并在同一源事件、同一目标 cohort、同一时间轴上比较。最小证据：消息日志包含生成/发送/送达/验证/采用；物理路径有独立 time-indexed witness；目标动作在预注册窗口内发生；placebo/延迟消息不能复现同一效应。

## C2：采用与动作的可观测中介链

把“收到消息”“控制器采用”“速度/加速度/间距变化”分开。每一级都允许失败并保留失败记录。只要采用率、采用延迟或动作中介不可观测，就只能报告 message availability 或 intent-to-treat，不能宣称 mechanism effect。

## C3：干扰感知的区域风险效应

预先定义车辆邻域、消息暴露映射和物理暴露映射，报告 direct、spillover/indirect 和 total effect。若不能实现随机干预，则至少需要明确准实验假设、可观测混杂、positivity、时间顺序和敏感性边界。

## C4：时空作用边界

估计通信和物理条件下的效应边界：延迟、丢包、渗透率、交通状态、道路结构和距离。边界结果应允许非单调性与无效区域，不能把固定阈值写成普适定律。

## 证据优先级

1. 独立现实轨迹/视频或可审计真实通信日志；
2. 预注册干预与干扰感知 estimand；
3. 独立物理传播基准；
4. 多场景/多状态外部验证；
5. 仿真只用于机制分解和可控敏感性，不替代现实因果证据。

如果 C1–C3 中任一不可观测，建议把论文主张收窄为工程可行性、局部响应或测量框架；如果 C4 不能跨状态复现，则不宣称普适作用边界。
