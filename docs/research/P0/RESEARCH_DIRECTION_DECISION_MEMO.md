# P0 Task 1 研究方向决策备忘录

状态：`Proposal / Awaiting Researcher Decision`。本备忘录不改变阶段顺序、Gate、风险指标或正式实验授权。

## 推荐优先级

### Priority 1：双传播事件级因果机制

把研究问题收窄为：在独立物理到达基准存在时，远端消息是否通过可审计的采用—动作链改变目标车辆及区域风险？这是最能区分 AAD 与已知 V2X/BLOS/非局部工作的方向。

### Priority 2：干扰感知的区域 estimand

采用 network exposure mapping，把消息暴露与物理邻接暴露分开，报告 direct/indirect/total effect。若无法实现随机化，必须先明确可识别范围和敏感性分析。

### Priority 3：作用边界与失败边界

研究通信时延、丢包、渗透率、交通状态、道路结构下的非单调边界。这个方向只有在 Priority 1 的机制成立后才有科学意义。

## 需要研究者决定的问题

1. 是否把“类超距作用”改写成中性术语，例如“信息介导的早期风险效应”，并将“超距”保留为历史动机？
2. 是否接受把没有独立物理 witness 的结果降级为工程/机制候选，而不作为科学主效应？
3. 是否愿意为消息采用、物理到达和区域 outcome 引入新的可观测数据源或实验设计？
4. 若现实证据无法闭合，是否将主贡献改为“可审计的不可识别性与失效边界”？
5. 下一 Task 是否优先做“可识别性与数据契约审计”，而不是继续扩大文献数量或启动 SUMO 正式实验？

## 建议的 P0 Task 2

`P0 Task 2：双传播因果链的可识别性与证据契约审计`。

输入是本 Task 的最近邻矩阵、现有 Stage 0.5 证据和研究者对上面五个问题的决定。输出应是：变量/时间戳字典、消息—物理双链 DAG、interference exposure mapping、最小可识别 estimand、必需现实证据、失败时收窄方案。未完成前不启动新的正式 SUMO/Stage 1.1 实验。
