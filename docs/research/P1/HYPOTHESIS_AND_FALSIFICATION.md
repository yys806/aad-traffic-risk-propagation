# AAD P1 科学假设与证伪规则

日期：2026-11-01
状态：**P1_HYPOTHESES_PROPOSED**。H1–H4 是待检验假设，不代表已有科学结论。

## 1. 共同判定规则

风险结果越低越好。令 \(\delta\) 表示研究者未来确定的 SESOI；当前不填入数值。每项假设都区分四类出口：

1. **支持**：预定估计对象、测量质量和识别条件满足，结果方向/区间达到预设科学标准；
2. **削弱或否定**：识别条件满足，结果与假设方向冲突，或在有足够精度时支持效应小于 \(\delta\)；
3. **测量/处理链失败**：消息、动作、区域或物理 witness 不可观测，不能把失败写成零效应；
4. **Unknown / 证据不足**：识别区间跨越关键方向、时间区间重叠、干扰或缺失未解决。

统计不显著本身不等于假设不存在；必须结合效应区间、SESOI、观测质量和失败原因判断。

## 2. H1：Information Intervention Effect

### 数学表达

Source-present 两臂对象为

\[
\tau_{\mathrm{ITT}}^{S=1}
=E[Y_{\mathcal T}(1,1)-Y_{\mathcal T}(1,0)].
\]

四格版本为

\[
\tau_{SC}
=\{E[Y(1,1)-Y(1,0)]\}
-\{E[Y(0,1)-Y(0,0)]\}.
\]

若风险越低越好，方向性候选为 \(\tau_{\mathrm{ITT}}^{S=1}<-\delta\) 或 \(\tau_{SC}<-\delta\)；两者的主次关系尚未批准。

### 物理含义

在可比处理前条件和完整网络分配下，启用信息策略是否改变固定目标 cohort/region/window 的区域风险负担。它是 assignment-level 效应，包含送达失败、采用失败、安全覆盖和网络 spillover。

### 对应可观测量

- 随机化/外生分配及正概率；
- 源事件资格和处理前平衡；
- 固定 \(C,R,W\) 的 Formal rho/P2 区域结果；
- 事件/session 级聚类、缺失区间和泄漏记录；
- 四格时保存四个 cell，source-present 两臂时保存两组全部运行。

### 识别条件

分配机制可审计；处理前可比；区域 cohort/window 不由处理后结果选择；干扰域、exposure mapping 或整场 policy 定义明确；测量缺失和安全中止按 assignment 保留。

### 支持、证伪与不可判断

- 支持：在预定对象和条件下，效应区间支持方向并达到 \(\delta\)；
- 削弱/否定：在足够精度和可接受干扰下，效应区间集中在 \([-\delta,\delta]\) 或方向相反；
- 失败：没有可用区域结果、处理分配失效或大量未知贡献；
- Unknown：干扰域外泄漏、区域覆盖或缺失边界使效应区间仍宽。

## 3. H2：Controller Adoption Mechanism

### 数学表达

描述性链路要求

\[
P(A=1\mid D=1,V=1)>0,
\]

并且在一个被随机化的 adoption encouragement 或有效 IV \(Z_A\) 下，存在可识别的命令/动作差异，例如

\[
\tau_U^{A}
=E[U\mid Z_A=1]-E[U\mid Z_A=0],
\]

或在满足 IV 条件的 complier 总体中定义 \(E[U(1)-U(0)\mid C]\)。如果没有额外随机化，\(P(A=1)\) 和 adopted/not-adopted 的观察差异只是链路审计量，不是自然中介效应。

### 物理含义

有效送达并通过验证的消息是否被控制器实际读入、选择并转成控制决策；采用不等于动作改变。

### 对应可观测量

消息端点和 message_id；送达、验证和新鲜度；控制器 decision/receipt、拒绝理由、命令版本；实际执行输入、覆盖/接管和车辆状态。

### 识别条件

采用状态的定义在处理前写明；鼓励或 IV 具有正支持、相关性、排除限制和稳定版本；日志对所有 assignment arm 可用；安全覆盖保留而不是被删除。

### 支持、证伪与不可判断

- 支持：正交/随机鼓励下，采用和命令/实际动作有可重复、可归因的变化；
- 削弱/否定：送达和验证充分但采用率接近零，或有效采用下命令与实际输入无差异；
- 处理链失败：消息端点或控制器日志断裂；
- Unknown：只有 acknowledgement、按钮、凝视或动作代理，不能证明采用；中介混杂或 IV 条件未证实。

## 4. H3：Action–Risk Mechanism

### 数学表达

需要一个预先定义且有识别支持的动作干预/鼓励对象，例如

\[
\tau_{Y\leftarrow U}
=E[Y_{\mathcal T}(U=u_1)-Y_{\mathcal T}(U=u_0)]
\]

或在采用被有效鼓励且满足中介识别条件时的 interventional indirect effect。观察到 \(U\) 改变与 \(Y\) 同时改变，不能单独替代该对象。

### 物理含义

消息介导的实际车辆动作是否通过车辆交互和物理状态传播改变目标区域风险，而非只改变一个孤立车辆的轨迹。

### 对应可观测量

- 实际动作 \(U\) 的速度、加速度、车道和执行器反馈；
- 物理交互边 \(E_P(t)\) 和邻车状态；
- 固定区域 \(R\) 中所有预列车辆的 Formal rho/P2 贡献；
- 处理前条件、消息链和安全覆盖；
- 区域结果的时间曲线和固定窗口聚合。

### 识别条件

动作变化有可辩护的外生来源或随机鼓励；动作后的物理 exposure 和混杂可测或由设计控制；区域 cohort/window 不因动作而事后改变；干扰域有定义。

### 支持、证伪与不可判断

- 支持：动作对象和区域风险对象均可识别，且动作变化导致预定风险效应；
- 削弱/否定：在有效动作干预下区域风险效应区间支持小于 \(\delta\) 或方向相反；
- 处理链失败：有 command 但无实际执行/区域覆盖；
- Unknown：仅个体动作、未采用车辆对照或同一后处理状态，无法识别 action-mediated effect。

## 5. H4：Pre-Physical Information Effect

### 数学表达

事件级目标条件为

\[
T_R<T_P,
\]

不确定性判定为

\[
T_R^{upper}<T_P^{lower}.
\]

总体层面可检验的替代对象是早期窗口风险效应和无消息物理到达分布：

\[
\tau_R(h,t)=E[Y(h,1,t)-Y(h,0,t)],
\qquad
F_0(t\mid h)=P\{T_P(0)\le t\mid h\}.
\]

预定 horizon \(H\) 内，若 \(F_0(H)\) 的上界低于 \(\eta\)，同时 \(\tau_R(h,t)\) 在早期窗口有支持证据，结论只能是总体层面的 early-window effect。

### 物理含义

在独立、可信、时间化的物理基准下，信息介导的区域风险效应可能在普通物理状态满足预定义到达条件前出现。它不是消息生成、第一次风险下降或目标车未采用的时间。

### 对应可观测量

- 事件级消息生命周期和实际动作；
- 固定区域风险曲线、同时置信带和持续性；
- 独立路侧/物理路径 witness、来源/目标连接和时钟校准；
- randomized no-message events 的 \(F_0(t\mid h)\)；
- 区间删失、右删失和测量误差。

### 识别条件

风险 onset 规则在观察前确定；物理状态函数 \(\phi\)、阈值、持续性和路径资格由 P2–P5 决定；无消息基准有随机化和可比性；时间误差量化；总体效应与到达分布分别估计。

### 支持、证伪与不可判断

- 支持：在同一总体定义、独立 witness 和预注册不确定性下，满足 \(T_R^{upper}<T_P^{lower}\) 或相应总体 early-window 条件；
- 削弱/否定：物理到达下界不晚于风险效应上界，或风险效应在早期窗口小于 \(\delta\)；
- 测量失败：没有独立物理 witness、时钟/身份断裂或风险曲线不可测；
- Unknown：时间区间重叠、跨世界 \(T_P(0)\) 未识别、删失/干扰未解决。

## 6. 失败分类不混淆

| 观察结果 | 应写成 | 不应写成 |
|---|---|---|
| 置信区间跨零且样本/测量充分 | 效应未被精确支持，结合 SESOI 判断 | 假设已被证伪 |
| 区间集中在科学无意义范围 | 证据支持效应小于 SESOI | 单纯“不显著” |
| adoption 日志缺失 | 处理链/机制不可识别 | 没有采用 |
| 物理 witness 缺失 | 时间优先性 Unknown | 没有物理传播 |
| 消息送达但无动作差异 | H2 被削弱或动作链无效 | H3/H4 自动失败 |
| 动作变化但区域风险无效应 | H3 被削弱 | 消息一定无效 |
| 区域效应存在但与物理时间重叠 | H1 可能支持、H4 Unknown/否定 | 已证明提前于物理 |

## 7. 适用对象边界

自动/可审计控制器可直接记录 adoption、command 和 execution，但它是否是首版正式研究对象仍待 D8 决定。人类驾驶者的 acknowledgement、按钮、凝视或自报不能自动当作心理采用；若研究人类，必须把代理变量和真实动作分开，并记录伦理、学习和退出机制。无论对象是哪一种，H1–H4 都不能由 SUMO fixture 或 Task9/19 局部响应直接确认。
