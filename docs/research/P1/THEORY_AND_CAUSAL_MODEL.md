# AAD P1 理论模型与联合动态系统

日期：2026-11-01
状态：**P1_TASK2_REFINED_MODEL**。D1–D10 的研究方向已经由研究者确认；平台、场景、阈值、精度和样本量等操作参数仍为 Awaiting Researcher Decision。

## 1. 建模范围和符号约定

以事件或运行 \(e\) 为最小跨链记录单位，以车辆/系统实体 \(i\in V_e\) 和离散时间 \(t\) 表示动态。连续时间版本可把递推写成微分或跳变系统；本文件不要求改变现有采样实现。

处理前变量用 \(H_e\) 表示，包括初始交通状态、道路拓扑、车辆特征、控制器版本、通信条件和计划的源事件资格。当前优先在 SUMO 中建立模型内的信息传播—自动控制器—物理状态—区域风险链；现实封闭场、实车和现实路侧资源不是当前前置条件，SUMO 结果不能直接称为现实交通因果证据。

为避免把配置、实际执行和记录混在一起，使用三层变量：\(Z_S\) 是源事件条件的场景/实验分配，\(S^*\) 是实际源事件状态及 Formal P2 资格；\(Z_C\) 是通信策略分配，\(C^*\) 是实际策略执行状态。真实送达、验证、采用、命令和动作写成 \(D^*,V^*,A^*,U^{cmd,*},U^*\)，日志、Observer、轨迹和风险计算所得记录使用波浪号。首版是 source-present 两臂通信策略 ITT，最终仍保留四格 S0C0/S0C1/S1C0/S1C1 和 \(\tau_{SC}\)；首版通信单跳直达、不转发，研究对象是自动控制器。

现有 formal_design.py 中的 source_present 和 channel_enabled 校验配置 cell，不自动证明实际 Formal P2 发生或通信策略成功执行。本任务只明确该语义边界，不修改正式接口。

## 1.1 Source Event 的两条路线

Formal P2 是 A 路线的优先源事件定义。B 路线允许安全受控扰动的仿真机制研究，但 B 不重新标记为 Formal P2，也不继承 A 的现实适用性主张。不得降低 Formal P2 阈值或制造危险交通扰动来增加事件数。

## 2. 双传播网络

### 2.1 Physical Interaction Network

\[
G_P(t)=(V,E_P(t)),
\]

其中 \(V\) 包含车辆和必要的道路/信号/边界实体；\(E_P(t)\) 包含道路连接、同车道跟驰、换道冲突、邻近交互和其他会把物理状态从一个实体传到另一个实体的关系。边可以有方向、距离、交互类型和有效时间。

### 2.2 Information Propagation Network

\[
G_I(t)=(V,E_I(t)),
\]

其中 \(E_I(t)\) 是通信链路或消息可达关系，记录发送端、接收端、链路状态、延迟、丢失/重复和策略路由。信息网络可以与物理网络共享节点，也可以包含路侧或云端实体。

两张网络的关键约束是：

1. 共享节点不表示边相同；\(E_P(t)\) 与 \(E_I(t)\) 的拓扑、时延和失效机制分别记录。
2. 物理相邻不推出通信可达；通信可达不推出物理相互作用。
3. 信息可达只表示消息有可能被接收，不表示已送达、已验证或已采用。
4. 采用不推出控制命令改变；命令改变不推出执行后的实际动作改变。
5. 实际动作改变不推出目标区域风险改变；风险改变也不推出它早于物理传播。

### 2.3 网络耦合

网络通过状态和策略耦合而不是通过合并成一张图耦合：物理状态影响消息生成资格、通信遮挡和控制器输入；通信状态影响控制器可用信息；控制器命令改变物理状态和未来 \(E_P(t)\)；物理状态也可以改变未来通信拓扑 \(E_I(t)\)。这些反馈均以不同时间步表示，避免在静态图中画有向环。

## 3. 联合动态系统

真实交通状态写成

\[
x^*_{t+1}=F_P\bigl(x^*_t,u^*_t,G_P^*(t),\xi_t;H_e,S^*,C^*\bigr),
\]

其中 \(x^*_t\) 至少包含位置、速度、加速度、车道、车辆身份和物理相邻关系；\(u^*_t\) 是实际施加到车辆/系统的控制输入；\(\xi_t\) 表示控制器执行、背景流和外生扰动。

真实信息状态写成

\[
m^*_{t+1}=F_I\bigl(m^*_t,x^*_t,G_I^*(t),C^*,\eta_t;H_e,S^*\bigr),
\]

其中 \(m^*_t\) 是每个消息的生命周期、来源、目标、内容版本、链路状态、验证状态和过期状态；\(\eta_t\) 表示通信和记录不确定性。首版只允许 Source→Target 直接链路（single-hop），不引入消息转发。

自动控制器对车辆 \(i\) 的决策分为采用、决策、命令和执行四层：

\[
A^*_{i,t}=\pi_A(x^*_{i,t},m^*_{i,t},q_{i,t};\theta_i),
\]

\[
D^*_{i,t}=\pi_D(x^*_{i,t},m^*_{i,t},A^*_{i,t},q_{i,t};\theta_i),
\]

\[
U^{cmd,*}_{i,t}=g_i(D^*_{i,t},x^*_{i,t},m^*_{i,t}),\qquad
U^*_{i,t}=\mathcal E_i(U^{cmd,*}_{i,t},b_{i,t},\omega_{i,t}).
\]

\(A^*\) 是控制器是否实际采用消息，\(D^*\) 是控制决策，\(U^{cmd,*}\) 是命令，\(U^*\) 是考虑安全覆盖、执行器限制和故障后的实际输入。当前研究对象是自动控制器，不引入人类驾驶者心理采用。

区域风险保持现有 Formal measurement 语义：

\[
R^*_{\mathcal T}(t)=\mathcal R\bigl(x^*_{\mathcal T}(t),M^*_{\mathcal T}(t)\bigr),
\]

其中 \(\mathcal T=(C,R,W)\) 由固定目标车辆集合 \(C\)、道路区域 \(R\) 和观察窗口 \(W\) 构成，具体数值未冻结。对可靠、有效且为正闭合 TTC 的观测，现有实现使用

\[
\rho(t)=\exp\left(-\frac{TTC(t)}{\tau_s}\right),
\]

并保留 Formal P2 的 TTC < 2.0 s、持续 0.2 s、最大观测间隔 0.11 s 和未知贡献 [0,1] 语义。这里的 \(\tau_s\)、P2 和风险阈值均为既有正式定义，本任务不修改。

对事件 \(e\)，固定窗口风险结果可写成

\[
Y^*_e(a)=\frac{1}{|C_e|}\sum_{i\in C_e}\frac{1}{|W_e|}
\int_{W_e} b_{ie}(t;a)\,dt,
\]

其中 \(b^*_{ie}(t;a)\) 是现有贡献边界/点值语义；若观测不可靠，保留区间而不是补零。若 \(C_e\) 或区域支持不足，\(Y^*_e\) 无定义或返回识别区间，不能把未知当成零风险。

## 3.1 真实过程到观测过程的测量模型

对物理状态，一个一般测量模型为

\[
\widetilde X_t=h_X\bigl(X^*_t,Q^X_t,\varepsilon^X_t\bigr),
\]

其中 \(Q^X_t\) 是身份连续性、遮挡、采样、坐标标定和时钟质量，\(\varepsilon^X_t\) 是测量误差。消息、控制器和风险记录同样写成

\[
\widetilde L_t=h_L\bigl(L^*_t,Q^L_t,\varepsilon^L_t\bigr).
\]

观测记录必须保留 record_id、外键、clock_id、时间单位、quality_status、missing_reason、派生版本和来源哈希。缺失、无效、不可观测、不适用和未知不合并。

### SUMO Observer 与现实独立 witness

当前 SUMO 路线使用只读 Observer：Observer 从仿真状态读取 \(X^*_t\)、\(R^*_t\) 或物理到达候选，生成 \(\widetilde X_t\)、\(\widetilde R_t\) 和质量记录；它不生成消息、不转发、不参与 Adoption、不修改 \(U^*\) 或 \(x^*\)。Observer 的记录质量影响模型内 \(T_P\) 的可信度，但不等同现实路侧传感器的独立性。

未来现实路线的路侧摄像机/雷达属于另一类物理 witness。其独立性、时空标定、身份匹配和缺失机制必须单独证明，不能用 SUMO Observer 的只读性质替代。

若某个测量输入实际进入控制器决策，它是系统输入的一部分，不再被标作独立 Observer 误差。

## 4. 消息生命周期状态机

一条真实消息 \(j\) 的状态可写成

\[
Z_j^*(t)\in\{\text{planned},\text{generated},\text{sent},\text{delivered},
\text{verified},\text{adopted},\text{rejected},\text{dropped},\text{expired}\}.
\]

允许的主链是

\[
\text{planned}\to G^*\to S^*_{msg}\to D^*\to V^*\to A^*,
\]

并允许在每一阶段失败、重复、过期或被覆盖。首版只允许 Source→Target 直接链路，不引入消息转发。每个状态必须有 event_id/message_id/run_id/vehicle_id/source_id 等稳定关联键、时间戳、版本和质量状态。delivered 需要端点接收证据；verified 需要来源/目标/新鲜度/完整性检查；adopted 需要控制器实际读入并选择消息的证据。消息内容进入 \(m^*_{i,t}\) 后仍可能被控制器拒绝或被安全策略覆盖。

## 5. 行为因果链与观测来源

| 链路阶段 | 理论变量 | 典型观测 | 不能从该阶段单独推出 |
|---|---|---|---|
| 源事件 | \(S^*,T_E\) | 源状态、Formal P2/受控扰动记录、源键 | 目标区已有物理影响 |
| 生成/发送 | \(G^*_j,T_G,T_S\) | 消息版本、端点、发送回执 | 目标端收到 |
| 送达 | \(D^*_j,T_D\) | 接收回执、链路日志 | 控制器验证或采用 |
| 验证 | \(V^*_j,T_V\) | 来源、目标、新鲜度、完整性状态 | 决策改变 |
| 采用 | \(A^*_{ij},T_A\) | 控制器 decision/receipt、拒绝理由 | 实际命令执行 |
| 命令 | \(U^{cmd,*}_{i,t},T_C\) | 控制命令日志、版本、覆盖标记 | 车辆状态已改变 |
| 实际动作 | \(U^*_{i,t},T_U\) | 速度/加速度/车道/执行器反馈 | 区域风险已改变 |
| 区域风险 | \(R^*_\mathcal T,T_R\) | Formal rho/P2 固定窗口结果及区间 | 早于物理到达 |
| 普通物理到达 | \(T_P\) | 独立、时间化、带路径依据的 witness | 同一事件的处理反事实已观测 |

当前 stage_i_mechanism.py 的联合时间轴只在提供独立 physical_arrival_time_s 时比较；没有该证据时返回 Unknown，不从事件排序、距离或速度反推物理到达。其 first_action_change_time_s 是配对轨迹的动作差异时间，不是 \(T_R\) 或 \(T_P\)。

## 6. 时间变量与删失

对每个事件保留如下时间（不存在或不可识别时写 Unknown、区间或删失）：

| 符号 | 含义和观测来源 |
|---|---|
| \(T_G\) | 生成确认；消息服务/控制端日志 |
| \(T_S\) | 发送调用或发送完成；通信端点日志 |
| \(T_D\) | 接收端确认；不能用发送时间代替 |
| \(T_V\) | 验证完成；来源/目标/新鲜度/完整性记录 |
| \(T_A\) | 控制器采用决定；决策日志 |
| \(T_C\) | 控制命令改变；控制命令序列 |
| \(T_U\) | 可归因的实际动作变化；与无消息/基线路径的预定持续性比较 |
| \(T_R\) | 区域风险因果效应 onset；由预定时间曲线/同时置信带/持续性规则判定，不是第一次下降观测 |
| \(T_P\) | 普通物理影响到达；独立 witness 的状态阈值、持续性、路径和时钟证据 |

观测缺口导致区间删失、左/右删失或 Unknown。持续性确认时刻不能倒写成原始 onset；未观测到不等于永不到达。

这些时间是不同的事件定义：\(T_G\neq T_D\)、\(T_D\neq T_A\)、\(T_A\neq T_U\)、\(T_U\neq T_R\)。时间先后可以支持事件排序审计，但不能单独推出其中任何一个因果箭头。

## 7. 物理与信息的耦合边界

物理传播链是 Source Event → Vehicle Interaction → Physical State Propagation → Target Region；信息传播链是 Source Event → Generation → Transmission → Delivery → Verification → Adoption → Action Change → Regional Risk。两者共享源事件和车辆状态，但至少要记录：

- 消息策略不会改变消息组以外的源事件定义；
- 物理交互可以影响未来消息质量和 adoption，但不能把物理邻接当作 delivery；
- 信息介导的动作改变可以提前影响目标区，但其风险后果仍须用固定区域结果识别；
- 普通物理到达基准必须独立于消息决策链，且不能以未采用车辆替代 no-message 反事实；
- 模型内共同随机数只用于精度/机制分析，不构成现实世界同一事件的反事实证明。

## 8. 可证伪的出口

本模型允许 H1–H4 分别失败：没有策略 ITT、没有 adoption 后动作差异、动作不改变风险、或风险效应与物理到达区间重叠，均不应被合并成一个“实验失败”。缺少日志、物理 witness 或区域覆盖时，结论应标为 Unknown / 不可识别，不标为“没有效应”。
