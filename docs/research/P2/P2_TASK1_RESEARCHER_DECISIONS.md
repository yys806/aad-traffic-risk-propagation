# P2 Task1 研究者决策与待定事项

日期：2026-11-02
状态：P2 Task1 操作化建议完成；以下新增参数均为 Awaiting Researcher Decision

## 1. 已确认方向

本任务沿用 P1 Task2 已确认的方向：

- SUMO 优先，结论限定模型内；
- Formal P2 是源事件 A 路线优先定义；
- 安全受控扰动是独立 B 机制路线；
- 目标 cohort、region、window 预先固定；
- SUMO Observer 只读，不参与消息和控制；
- 首版只主张总体时间优先性；
- no-message 运行分布与消息处理组轨迹分开；
- 不修改 Formal P2、Formal rho、D1/B witness 或 Gate。

## 2. 本任务形成的 Proposal

| 编号 | Proposal | 推荐理由 | 不采用的后果 |
|---|---|---|---|
| P2-T1-P1 | A 路线继续使用版本化 Formal P2；候选事件必须有首次合格观测、实际确认时间、身份、质量和退出原因 | 复用已有正式定义，避免为增加 SUMO 事件而降阈值 | 源事件资格无法与现有结果和后续消息时间对齐 |
| P2-T1-P2 | B 路线使用独立 source_type 和扰动分配/实际执行记录 | 保留安全机制研究价值，同时不混淆自然风险代理 | B 机制结果不能与 Formal P2 或现实源事件主张区分 |
| P2-T1-P3 | 物理路径采用 Potential / Observed / Qualified 三层状态，并以 time-respecting path 组织边 | 区分空间可能性、局部观测和可用于物理归因的证据 | 道路连通或同车轨迹可能被误写成物理传播 |
| P2-T1-P4 | \(T_P\) 首选相对基线的持续速度状态；净间距/密度作辅助；Formal rho/P2 不直接定义 \(T_P\) | 与区域风险终点保持一定测量独立性，SUMO 可观测且可扩展到现实 | 使用风险本身定义到达会产生循环解释；单一局部 gap 不能代表区域前沿 |
| P2-T1-P5 | 物理到达必须同时满足状态函数、合格路径、时间顺序、身份/质量和时钟条件 | 防止目标区偶然变化被归因于源事件 | 只能报告状态变化或路径未知，不能报告合格 \(T_P\) |
| P2-T1-P6 | Observer 记录真实模型状态的只读视图，最小字段覆盖运行、身份、时间、状态、物理边、到达、质量和版本 | 形成可复核的 P2 证据契约，不修改生产接口 | 后续无法区分仿真状态缺失、测量缺失和路径缺失 |
| P2-T1-P7 | 普通物理参考优先使用 \(Z_C=0,Z_S=1\) 的无消息运行分布 \(F_0\) | 与 P1 总体时间优先性 estimand 一致 | 将消息处理组物理轨迹当成 no-message 反事实 |

## 3. Awaiting Researcher Decision 的关键事项

| 事项 | 当前可选方案 | 当前推荐 | 不作决定的后果 |
|---|---|---|---|
| Formal P2 的 SUMO 场景 | 现有场景、未来新场景、暂不追求源事件 | 保持现有定义并先审计场景能力，不为命中率改阈值 | 源 P2 数量可能为零，但零结果必须保留 |
| B 扰动类型 | 安全减速、状态跳变、外生轨迹输入或其他模型机制 | 由后续任务按安全和可追溯性选择 | B 路线只能停留在一般机制定义 |
| \(t_E\) 科学时间锚点 | 首次合格观测、实际确认、计划扰动、实际扰动 | A 路线候选为实际确认；B 路线候选为实际扰动，均需记录其他时间 | \(T_P\)、消息生成和时间比较无法统一 |
| 物理状态函数 \(\phi\) | 速度、净间距、密度、组合状态 | 先以相对基线速度变化作主候选，其他作辅助 | 无法形成非循环的物理到达定义 |
| \(\theta_P,h_P,q_P\) | 参数化阈值/持续性/最大缺口 | 由后续独立校准或研究者预注册 | \(T_P\) 只保留候选区间或 Unknown |
| 路径准入 | 仅拓扑、局部相邻、time-respecting observed、Qualified witness | Qualified witness 作为可支持物理归因的标准 | 只能报告 potential/observed path |
| 多源事件归属 | 最近源、最早源、联合源、Unknown | 先保留多源并标记 Unknown，不强行归属 | 竞争源会污染路径和到达时间 |
| 缺口和删失 | Unknown、区间删失、右删失 | 按缺口位置和观测截止分别记录 | 可能把缺测错误写成未到达 |
| 时钟和误差容限 | 仿真时间、统一设备时钟、外部同步 | SUMO 先保留仿真时钟和 step；现实扩展另定同步 | 不能直接支持现实 \(T_P\) 比较 |
| Target Region 与 cohort | 固定车辆集合/道路边界/相对窗口 | 遵守 D4 原则，数值留给后续 P2/P4 | 到达和风险结果不可比较 |

## 4. 目前已知的证据限制

- 现有 B00/Round2 SUMO 源 P2 为零，不得通过降阈值解决；
- NGSIM、MiTra 和 SPMD 不能拼成同一事件的独立物理 witness；
- Task9/Task19 只提供局部 Follower 响应；
- Task20 合成 mechanism fixture 只支持接口和状态机检查；
- Observer 的只读性不等于 no-message 反事实；
- \(F_0\) 需要 source-present、no-message 的运行分布和适用域记录。

这些限制不阻止 P2 Task2 继续做离线定义和接口设计，但阻止把当前文档写成物理 Gate 通过。
