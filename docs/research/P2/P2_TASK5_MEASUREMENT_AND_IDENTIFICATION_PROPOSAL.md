# P2 Task5 — 物理到达测量与时间优先性识别方案

2026-11-02。Status: Proposal / Awaiting Researcher Decision。统一事实源为[科研定义v0.3](../definitions/README.md)，本文件是方案比较、推导与数据契约，不产生第二套定义。Agreed仅沿用Task4 A–D；以下实施细则尚未冻结。

## 1. 独立判断与三种方案

| 方案 | 所问问题 | 优点 | 代价 / 科学后果 | 推荐 |
|---|---|---|---|---|
| Micro、Macro、cohort分别报告 | 实际交互链到区？区域算子状态改变？固定车辆群持续下降？ | 量纲、支持、资格和Unknown可逐项审计 | 不能直接给一个最早物理影响时间 | 当前首选；三个时间族 |
| 双层联合判定 | 两类证据是否同时相容，或任一类检出？ | 可预设交叉核查 | AND推迟到达，OR变为任一检出；缺测不能当阴性；不是原对象的无损融合 | 可作相容性表，暂不定义二值arrival |
| 有限机制复合对象 | 已穷尽某有限机制范围内第一到达？ | 如覆盖和延迟界成立，可对应较强物理主张 | 需机制清单、联合覆盖、各层时间映射、源归属；当前没有必要证据 | 未来候选，不在本轮批准 |

推荐时间族与逐层参考分布见CORE细则J、DEF-TIME-004。cohort是补充状态层，不是第三种独立物理传播机制。Macro涵盖区域内可观测交通，风险可以针对预定固定cohort；二者不必是同一车辆列表，但必须明确相同资格总体、区域和时间支持。源特异micro与any-source macro不能不加说明混称同一物理量。

Task3 B域区域中间车先响应、指定cohort无报警，已足以反驳“cohort阴性就没有区域物理影响”的一般推理；不足以校准任何新阈值，也未形成独立source→cohort Qualified路径。微观阳性/宏观阴性可因局部弱响应与聚合稀释；反向不一致可因其他源、缺链、范围外路径或身份丢失。冲突须保留，不投票表决。两层阳性不自动因果；两层阴性仅是已验证检测能力内未检出。

## 2. Macro：Edie型同域量为首候选

具体公式、裁切与单位在CORE细则K/DEF-PHY-009。每个同向车道使用道路弧长区间与过去窗口；记录车距D、车时V、时空面积A，再计算q=D/A、k=V/A、u=D/V。部分进入/离开、窗内部分穿越均按域内实际片段计入；不要求完整穿越，不用新车补cohort。跨lane先分层，合并量按lane长度时间归一，不能冒充总断面流量。

| 测量 | 有效支持 | 可回答的问题 | 不适用情况 |
|---|---|---|---|
| Edie型D/V/A | 同lane-space-time、覆盖完整或抽样机制可辩护 | 有限区域在该时间窗的状态 | 不明车辆总量、长缺口、未知包含概率时不能外推全交通 |
| 瞬时空间普查 | 同时钟、完整空间车辆清单及运动学速度 | snapshot密度、车辆等权空间均速 | 不同时间混采；单张静态图不能直接给速度 |
| 点检测time-mean | 固定断面经过车辆 | 断面流/点采样均速 | 不能与异时异域k拼为q=ku |
| 固定cohort等车权signed decline | 预选成员和有效基线 | 原cohort状态变化，减轻组成变化 | 不代表全区域所有物理到达 |
| Median/quantile/exceedance | 同一明确车辆总体 | 稳健性、尾部和影响面辅助 | 各自是另一估计对象，不能按显著性替换主指标 |

Hall官方章区分不同空间均速、部分穿越及广义测量；Edie原文未合法取得，因此不标原文精读。q=ku在本构造中为同域恒等式，三者不是三份独立证据。V=0时速度undefined而非零。未知抽样不能凭“可见车辆平均速度”宣称全交通速度；HT总量需已知包含概率，其比值仍非有限样本无偏。

Macro首次跨阈窗口的末端只是可用索引；算子onset、窗口支持、持续确认和原始车级响应分别记录。阈值/聚合可晚于最早物理响应，不能减一个窗口就恢复真实起点。此限制直接影响可排除的物理范围，不能用更平滑、更晚的到达提高时间优先性。

## 3. Micro：沿用W1–W9，而非重写标准

流水线：真实车辆身份和坐标 → 真实leader/follower及lane段 → 源/响应变化点候选 → 区间与clock → W1–W9逐项审核 → 同实体/同响应段多跳连接 → 首合格终端响应及source归属。

Zhang正式版提供CUSUM候选、候选集合PELT、分段轨迹和物理过滤/BFS图；其无向连通分量不核验真实leader，不足以单独通过W1–W9。可复用成熟候选检测，不照搬其经验阈值。离线双侧拟合必须记录look-ahead与可用时间，不伪称在线确认。严格区间顺序重叠时保留Unknown，不能中点排序；换道、leader替换、身份断裂分段。中间车的入边响应与出边作用必须连接同一已审计事件，不能拼接不同制动。

多源竞争保留全部可行解释：信号、汇入、需求、其他车制动、边界控制、通信动作；最短图路径不决定源因果归属。没有Qualified链但覆盖不足时，潜在物理到达仍Unknown，不能以缺证代无到达。宏观波前是辅助结构证据，不能补齐缺失的实体关系。

## 4. Qpre两臂与四格：不同估计对象

| 对象 | 目标总体 / 条件 | 可识别内容 | 额外条件 / 不能推出 |
|---|---|---|---|
| τQ(t) | source-present、通信前Q(1)=1 | 合格源事件内ZC分配的ITT | Q完全在ZC前；无泄漏、正概率、干扰簇与结果质量；不外推全部源事件 |
| F0,ℓ^Q | 同资格、同H权重、同区域时间、ZC=0 | 各层无消息物理到达分布或其界 | no-message仍有普通物理传播；Unknown不能删 |
| τSC | 源分配前共同总体、四格政策/结果明确 | 源×通信交互 | 需要四格支持及可辩护ZS分配；并非τQ |
| Q(1) principal-stratum四格 | 反事实有源时会合格的人群 | 定义上可写，数据一般不识别 | ZS=0的Q(1)不可见；需额外假设/界，随机ZS不自动解决 |
| 源前共同opportunity四格 | 四臂均可定义的预选路段/时段/场景 | 可为未来共同资格提供支持 | 新资格对象/clock需研究者决定，本轮不改矩阵 |

同源前总体和相同H权重下，τSC=pτQ+(1−p)τ非Q−τS0是全期望恒等式；p=P{Q(1)=1}。该式不是识别证明。若非Q没有通信支持或S0政策未定义，缺项仍不可估，不能补0、事后加权或用同seed补齐。对ZC是前变量的Qpre，对ZS可能是后变量。跨ZS调整已受源影响背景会改变因果对象。

下图仅说明时间顺序；箭头不是已识别效应，Q用于ZC前资格，不用于事后筛样。

~~~mermaid

 H0[源前H0] --> S[ZS与源过程]
 H0 --> Q[盲法源确认与Qpre]
 S --> Q
 Q --> C[资格内随机ZC]
~~~

ZC箭头表示设计顺序/分配机会，非由Q混杂随机政策；概率、随机表和生成时刻须审计。处理后实际送达、验证、采用、动作、Witness或四运行匹配不是主ITT纳入条件。失败和缺失保留原assignment。源确认前已发生传播也保留，不能事后删以制造早窗。

最小独立单位是实际随机化run/道路时间簇或matched block。同seed四格不是四个独立重复，车辆和帧不是n。优先盲预列一个index source；若每簇多事件，必须明确cluster-weighted或event-weighted目标并按实际设计分析。不能让处理改变后续事件数后再池化成iid。

## 5. 时间与删失：允许集合先于估计器

推荐tE为物理source onset允许区间；确认仅负责事件资格/消息资格。该具体映射仍待研究者批准，Formal持续规则不变。相对arrival时间需包含[LA−US,UA−LS]并传播clock；风险曲线也用全部允许对齐的包络。首次观察、首次持续确认和计划扰动时间均不自动等于真实物理起点。

可恢复的速度状态可能在长缺口发生并恢复；最后阴性不抹去此前事件。每单位每层存允许集合S，含区间并集及∞，分类exact/left/interval/right/Unknown；晚期未完成持续段不能机械right-censor。竞争源/归属失败不是独立删失。完整first-event历史和非信息性inspection不成立时，不使用一般Turnbull/KM点估计替代识别。

CORE细则N–P给出可执行保守流程：S→逐单位a≤1{T≤t}≤b→CDF识别界→符合实际iid/SRS条件的Hoeffding联合上界。Unknown贡献[0,1]，信息性缺失不需被假设为随机，但会令界无信息。n0=0时CDF Unknown，不除零。检验族包含全部预定endpoint/时点/H；分层按共同预定权重，不将车辆/帧/簇事件混作n。Turnbull只作满足观察条件后的效率备选，KM只适用于exact+独立右删失。

风险侧按assignment估τQ；有真实有限结果范围及有效测量包络时可用逐臂浓缩+全网格union保守上带。不得任意截断DRAC以凑有界性；若无范围，则此候选不能执行。cluster max-t/设计相容bootstrap为效率候选，需独立覆盖验证。Fisher sharp-null随机化p值不自动成为异质ATE/SESOI带。

沿用P1预定H*、SESOI δ、持续规则和F0上界<η；预算αR+αP+αclock+αmeasure≤α。确定性误差包络不消耗概率，估计包络/漏检界计其失败概率。pointwise CI不等同时带。多层分别检验可联合控错，不等于已融合arrival。无有效检测漏报界时，结论只能针对detector-defined状态，不能扩大为全部真实物理机制。

## 7. 参数路线与停止条件

完整参数表在[统一参数登记](../definitions/PARAMETER_AND_CALIBRATION_REGISTER.md)Task5增量，覆盖baseline model/window、θ/h/q、coverage、recovery、clock、micro质量、macro域窗、η/δ/α/H*。目前无可由交通数据唯一识别的正式数值。V2的2/5/10s和42候选只是探索网格；B无目标cohort阳性，不能由零报警选择最优阈值；Formal TTC/持续规则和Zhang经验参数不迁移。

后续仅在另获实验授权后：冻结测量对象和科学损失 → 既有数据能力审核 → 独立null校准误报 → 已知物理阳性校准漏检/延迟 → 按run/场景划分独立验证 → 采样/噪声/缺失/交通状态敏感性 → 报告可迁移性和Unknown。不能在同批数据调参后称独立验证；本轮只给路线，不产生新运行或Pilot。

当前最终判断：方案具有有限范围物理意义并可保持Formal定义不变；主arrival标量尚无充分依据。识别缺口集中在Formal A与Qualified证据缺失、机制覆盖/漏检界、source-absent资格/四格支持和风险结果范围。没有证据支持NC级核心因果结论已成立；贡献仍是待验证的联合识别设计。
