# 0.0.1 反应时间相位标定：发现 τ 与真实反应时间不相容（2026-11-19）

> 版本号：**0.0.1**（R06 台账第 1 号）
> 目的：测 `actionStepLength`（决策更新间隔）实际产生多大的有效制动延迟，
> 判断能否用它承载真实驾驶员反应时间分布。
> 依据：GPT 第四十八轮 Q2 指定的记录项（前车制动生效 / 后车决策更新 / 后车实际制动起点 / 无刺激对照）。

---

## 一、装置

两车、单车道、初速 30 m/s、初始净距 125 m（对应车头距 130 m）。
前车按 4.5 m/s² 匀减速到停（约 6.67 s），后车 Krauss 跟驰。
`actionStepLength = L`，扫相位 φ ∈ {0.0, 0.2, 0.4, 0.6, 0.8} × L，
即把前车制动起始时刻设为决策边界加相位偏移。
**无刺激对照**：前车不制动，确认后车本来不会减速。

脚本 `code/scripts/p3_audits/two_car_phase_calib.py`
产物 `code/outputs/analysis/P3_phase_calib/phase_calib.json`

## 五、结论

### 5.1 直接结论

**碰撞不是「反应慢导致刹不住」，是「τ < actionStepLength 导致跟驰模型的安全条件失效」。**

这正是 GPT 第四十七轮预先警告的：「尤其检查是否存在 `tau < actionStepLength`：
这本身就可能让跟驰安全条件失效。不要按车型悄悄调高 `tau` 来消除碰撞。」

### 5.2 为什么 τ=0.6 本身就不真实

Krauss 的平衡车头距 ≈ `v·τ + 车长 + minGap`。
- τ=0.6、v=22.8 → **21.2 m → 时距 0.93 s**
- τ=1.5、v=22.8 → **41.7 m → 时距 1.83 s**

NGSIM 实测 80–105 km/h 层时距 p25/p50/p90 = **1.44 / 1.92 / 4.92 s**。

**τ=0.6 对应 0.93 s，低于真实最激进的一成多；τ=1.5 对应 1.83 s，正好落在 p25–p50 之间。**

=> **整个「车头距 100/130 m」的设计，本质上是在给一个不真实的 τ 打补丁。**
τ 一旦改成真实的 1.5，自然车头距就是 52.5 m，不需要人为拉大到 100–130 m。

### 5.3 对 0.0.0 那批结论的影响

| 旧结论 | 现在的状态 |
|---|---|
| 「反应 1.6 s 在物理上必撞，不用再试」 | **作废**。那是 τ=0.6 的建模伪影 |
| 「可用区间：反应时间不超过 1.0 s」 | **作废**。同上 |
| 「168 个事件其实是同一个重复 168 遍」 | 仍成立（均匀车流所致） |
| 「制动需求挤在 4.2–4.3，没有动态范围」 | 仍成立，但需在改正 τ 之后重测 |
| 「仿真族造不出高速险情」 | **仍未被推翻也未被证实**，需在 τ 改正后重跑 |

## 六、这次没证明什么

1. **没证明 τ=1.5 就是对的。** 只证明它让时距落在实测区间内；τ 的取值仍需单独标定。
2. **没证明反应时间异质化能产生差异化暴露。** 这是 0.0.2 的事，本轮没做。
3. **没有标定出「人的反应时间」到 `actionStepLength` 的换算关系。** 测到的 3.0–5.2 s 有效延迟
   是「净距收拢时间」，不是感知—制动延迟。要把人的反应时间映射进去，仍需显式延迟模型。
4. **只有两车、单相位网格、单一净距**，未在车队规模验证。
