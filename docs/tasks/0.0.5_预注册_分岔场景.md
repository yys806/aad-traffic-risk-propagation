## 一、这一号要回答什么

> **在同一个决策规则下，一条及时但不含路线建议的状态消息，
> 在哪些工况能带来可测的实际收益，在哪些工况不能。**

不是「消息让车提前减速」（那是 0.0.4，已被判为同义反复），
而是「消息改变了车辆对下游的预期，从而改变了选路，进而改变了实际通行代价」。

---

## 二、场景

```
              x=0 ─────────── 主路 8000 m ─────────── x=8000
                            │
                   最后可改道点 x=3000
                            │
                            └── 绕行路 ──→ 在 x=7000 汇回主路
```

- 主路 0→8000 m，限速 30 m/s，单车道
- 绕行路从 3000 m 分出、在 7000 m 汇回
- **绕行代价按「额外时间」定，不按全长定**：
  - 主配置 **+50 秒**（= 多 1.5 km，绕行路全长 5.5 km）
  - 预注册三档：**+30 / +50 / +60 秒**
  - 原计划的 +200 秒保留为**高代价压力测试**，不作唯一配置

### 2.1 两个世界

- **堵塞世界**：主路 x=5000 处在 t=T0 起施加**持续 D 秒的通行能力下降或封闭**，
  让队列的形成、回溢、消散由交通模型自己算——**不把队尾钉死在 5000 m**
- **畅通世界**：同一位置同一时刻，什么都不发生

### 2.2 「分岔前观测相同」的正确做法（GPT 纠正）

🔴 **不是**靠一个 `x < 3000` 的开关把下游状态抹掉。
**而是**：可见性按**最后可改道点**定义，由道路几何（弯道/坡顶/有限视距）保证。

- 如果车到岔口才看见队尾、但**仍来得及转弯**，那算有效本地信息
- 如果队尾在决策点之前就已经回溢到可见范围，**不许屏蔽、不许事后删样本**，
  按预注册把它作为「本地已有线索」的工况单独报告

**「观测相同」的定义**：预注册决策窗口内、**无信息干预时**的配对诊断——
同种子下检查可见车流、前车速度、车距等输入是否一致。
**不要求**收到消息、车辆已改道之后的交通状态还相同（那是干预的后果）。

## 三、消息

只携带：**事件编号 / 路段 / 发生时刻 / 状态**。
**绝不含「请走绕行」这类指令。**

🔴 两个消息臂必须使用**与世界状态无关的发送计划**，在堵塞与畅通世界里都按计划发。
否则「收到一条提示」本身就把世界状态泄露了。

---

## 四、决策规则（GPT 第五十三轮定）

**所有臂用同一条规则**，在最后可改道点比较：

```
选绕行  ⟺  Ê[T_主路 | I] − Ê[T_绕行 | I] > 0
```

其中 `I` = 本地观测 + 当前时刻 + 历史先验 + **该臂实际收到的消息**。

**关键**：消息改变的是「预计延误」，**不是路线选择条件本身**。

- 车从岔口到 5000 m 自由流还要约 67 秒，所以「现在堵」≠「我到时还堵」
- 预测只能用**事先冻结的**历史持续时间、通行能力与消散模型
- **绝不允许偷读本次仿真的真实 D 或未来队列**

🔴 **无消息臂禁止写成「一律走主路」**——那是对照臂的特权。
无消息臂同样用先验 + 本地观测算，如果算出来主路更快，那才是「走主路」；
如果先验已足以支持绕行，也应允许它绕。

## 五、四臂

| 臂 | 内容 | 用途 |
|---|---|---|
| 1 无消息 | 只有先验 + 本地观测 | 基准 |
| 2 有内容消息 | 状态消息 | **主比较对象** |
| 3 同时序无内容 | 同一时刻收到提示，但不含下游状态 | 检验「被提醒一下」本身的影响 |
| 4 完美先知（可选） | 从一开始就知道该走哪条 | 上界 |

**主比较用 2 对 3**（状态内容的增量）；1 对 3 检查提示本身的影响。
🔴 有交通相互作用时，**先知臂不能用「逐车事后选最快」冒充可实现的上界**。

## 六、指标（GPT 第五十三轮给的式子）

```
净节省  G = p · S_B − (1 − p) · L_F
```

- `S_B` = 堵塞世界里「无内容臂平均通行时间 − 有内容臂平均通行时间」
- `L_F` = 畅通世界里「有内容臂平均通行时间 − 无内容臂平均通行时间」
- `p` = 堵塞世界权重，无真实堵塞频率时预注册 **p = 0.5** 作为平衡情景，
  **不得解释为运营收益**

**对预先定义的全部车辆计时**，不按「事后是否绕行」「是否赶上队列」筛选。

次指标：排队时间、畅通世界的绕行率及其代价。
🔴 消息准确且准时的话，畅通世界浪费为零完全可能，**不必人为造出损失**。

## 七、预注册门槛（跑之前冻结）

| 项目 | 预注册值 |
|---|---|
| 配对种子 | **60 个独立正式种子**；每个种子跨世界、跨臂复用到达与外生随机量；**以种子为统计单位**，不把同一队列里的车当独立样本 |
| 每臂车辆 | 每种子、每世界、每臂目标 **200 辆预定义计分车辆**；容不下就减计分车辆、增种子，**不许抬流量凑数** |
| 最小有意义效应 | **10 秒/车**的加权净节省；正式跑之前用独立 pilot 的种子级配对方差复核样本量 |
| 验收 | 主指标**双侧 95% 区间下限 > 10 秒** → 验收 |
| 判定「达不到」| **上限 < 10 秒** → 判定该预注册工况下达不到有意义收益，**停止调参** |
| 判定「证据不足」| 区间跨过 10 秒 → 报**证据不足**，不报「无价值」 |
| 扫描的作用 | 只用于**解释边界**，不许用来替换失败的主结果 |

## 八、判据先验：绕行代价区间怎么选（GPT 给的算法）

设「实质差异」= 10 秒，主配置 50 秒档：

- **畅通世界**：主路相对绕行的额外拥堵延误 **< 40 秒** → 绕行至少亏 10 秒
- **堵塞世界**：额外延误 **> 60 秒** → 绕行至少赚 10 秒

必须扣除绕行路自身与汇入口的拥堵，**不能只看主路排队**。
先用独立校准确认预定扫描范围覆盖临界点两侧，然后**冻结参数**；
正式结果报告整条曲线，不只报绕行获胜的格子。

若多车改道改变了汇流拥堵，**以整臂实测通行时间为准**，不把单车临界值当路网结论。

## 九、实现清单（按顺序）

1. 建分岔路网，验证三档自由流通行时间（+30/+50/+60 秒）
2. 在 5000 m 施加持续 D 秒的通行能力下降，验证队列能形成、回溢、消散
3. 实现「最后可改道点」的可见性（由几何保证，不用开关）
4. 实现预测器（冻结的历史先验 + 消散模型）
5. 实现四臂消息与决策规则
6. 用 3 个种子做 pilot，复核方差与样本量
7. 正式跑 60 种子

---

## 十、这一号明确不做的事

- 不做车队级「消息对后车是帮助还是障碍」——那是更后面的号
- 不加通信延迟与丢包（那是另一条敏感性轴，单独开号）
- 不把「收到消息后换道」当主结果
