## 二、🔴 Y 公式我算错了：用了过时的常数

### GPT 抓到的

按我给的数据：
- 原始节省 `T_主 − T_绕 = 298.8 − 221.5 = +77.3 s`
- 延误差 `(298.8−169.8) − (221.5−219.9) = +127.4 s`
- **两者都不是我报的 +133.0 s**

### 根因

`Y = (T_主 − T_绕) + 55.7`，其中 **55.7 是单车道抢道网络下测的绕行代价**（222.4 − 166.7）。

**改成两车道汇合后，绕行自由流变成 219.9、主路 169.8，代价是 50.1 s，不是 55.7。**

### 纠正后

```
Y = 77.3 + 50.1 = 127.4 s
```

**与延误差 `(298.8−169.8)−(221.5−219.9) = 127.4` 逐位一致。**

### 已修

`module3_branch.py` 里把常数改名为 `FREE_PENALTY = 50.1`，并加注释说明「必须用当前路网实测值；
单车道时代是 55.7，用错会让每个 Y 偏 5.6 秒」。

## 五、扩量前必须先过的三项硬门槛（GPT 给）

### 门槛 1：主路支对拍基线

- 在修复版路网下，**逐车**核对决策步、实际路线、到达步
- 主路支应与基线**完全一致**
- 两支在改路指令**之前**的状态也应一致
- ✅ 模块 2 已验证区间的问题已解决（见第三节）

### 门槛 2：实际走法与汇合等待写进日志

- 检查目标车实际经过的边与车道、汇合前后停等、有无传送或异常退出
- **汇合等待要写进每车日志**，不能只看总行程时间
- 注意：双车道修复消除了抢道约束，**结论只适用于修复后的路网**，不能外推到单车道抢道口

### 门槛 3：其他车辆的扰动

- 不能只比总体到达分布
- **按相同车 ID 配对**，报告到达时差的中位数、95 分位、最大绝对差
- 单列「只在一支到达」的车辆
- 对差异最大的几辆回看轨迹
- **若差异在决策前就出现，或来自传送/异常换道 → 暂停扩量**
