## 三、GPT 给的新颖性定位句（可直接进正文/答辩）

> 「信息改变行为」以及「改道反馈可能改变网络表现」**都不是 AAD 的新意**；
> AAD 要检验的是，在以**无该消息时常规物理影响抵达目标区域的时点**为界的**到达前窗口**内，
> 来源可追溯的远端风险消息能否经**可核验的控制器采用与车辆动作**，在**车辆相互影响下**
> 改变该区域的**总体风险**。

**这句话的价值**：把「我们做了信息影响行为」这个站不住的说法，
换成「我们卡的是**到达前窗口 + 可核验采用 + 网络干扰下**这三个条件同时成立」——
而这正是矩阵里 22 篇**没有一篇同时做到**的。

## 四、`AAD threat` 列的写法原则（GPT 定，以后补行一律照此）

1. **先写它拿走了哪条主张，再写它是否覆盖核心问题。**
   句式：「已表明 X；未见估计 Y；需核查 Z。」
2. **按科学问题与所估计的效应分级，不按术语或实现分级。**
   - 同样用延误指标 → **结局口径先例**
   - 已展示信息—动作或动作—网络反馈 → **部分重合**
   - 已可信估计同类到达前窗口内的区域总效应 → **直接威胁**（即使不用 AAD 术语）
3. **用同一把尺子约束 AAD 自己。**
   写「未见」「待核」，不把摘要没写当成论文没做，也不把设计目标写成已识别的结果；
   主结局 `Y` 是延误口径，就写「超额行程时间」，**不要让它被读成碰撞风险**。

> 第 3 条是冲着我以前的毛病来的——我曾把威胁写得过重，自己吓自己。
