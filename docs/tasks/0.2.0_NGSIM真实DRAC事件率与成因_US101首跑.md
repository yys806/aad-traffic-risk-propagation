## 二、口径（GPT 第七十六轮裁决后）

| 项 | 口径 |
|---|---|
| 净距 | `g = (Space_Headway − v_Length_lead) × 0.3048` ← **扣前车车长**，不是后车 |
| 闭合 | `c = (v_ego − v_lead) × 0.3048` |
| DRAC | `c²/(2g)`，仅 `c>0` 且 `g>0` |
| 事件合并 | 同一后车连续超阈，中间允许最多 3 个**有效**低于阈值帧（0.3 s）；无效/缺帧直接断开 |
| 数据版本 | **用 `.txt`**（GPT：US-101 的 CSV 有截断记录）；txt 无表头，按标准 18 列赋名 |
| 列名坑 | US-101 拼作 `Preceeding`（多一个 e），I-80 是 `Preceding` |

**手算验收（GPT 给的对照）**：车头距 50 ft、前车长 30 ft、速度 50/25 ft/s
→ g=6.0960 m、c=7.6200 m/s、DRAC=4.7625 m/s² **全部通过**。
