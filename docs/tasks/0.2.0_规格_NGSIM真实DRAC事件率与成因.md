## 二、为什么必须先做这个

真实世界里这条前提会被三种方式打破：

| # | 打破方式 |
|---|---|
| 1 | 前车减速超过后车对前车的预期 |
| 2 | 切入 / 换前车 |
| 3 | 后车按过时或错误的状态决策 |

**这三种在真实数据里各占多少，决定了仿真该往哪个方向改。** 先数出来，再动模型。

## 三、数据与字段（已核实）

四地点：US-101（Los Angeles）、I-80（Emeryville）、Lankershim、Peachtree。
压缩包结构与字段均已实测：

```
外层 zip → i-80-vehicle-trajectory-data.zip → vehicle-trajectory-data/<时段>/trajectories-*.csv
列：Vehicle_ID, Frame_ID, Total_Frames, Global_Time, Local_X, Local_Y, Global_X, Global_Y,
    v_Length, v_Width, v_Class, v_Vel, v_Acc, Lane_ID, Preceding, Following,
    Space_Headway, Time_Headway
```

- `Preceding` = 官方给的前车 ID（0 表示无前车）→ **不自建配对，沿用官方配对**
- `Space_Headway` = 车头到车头间距（英尺）
- `v_Vel` = 速度（英尺每秒）、`v_Acc` = 加速度（英尺每二次方秒），**均为 NGSIM 官方平滑派生量**
- **一律用 `v_Vel` / `v_Acc`，不用位置差分**（位置量化噪声会毁掉加速度）

## 四、计算口径（跑前冻结）

| 量 | 定义 | 单位换算 |
|---|---|---|
| 净距 `g` | `(Space_Headway − v_Length_ego)` | 英尺 → 米 ×0.3048 |
| 闭合速度 `c` | `v_Vel_ego − v_Vel_lead` | 英尺每秒 → 米每秒 ×0.3048 |
| DRAC | `c² / (2g)`，仅当 `c > 0` 且 `g > 0` | 米每二次方秒 |
| 事件 | 同一后车连续超阈 → **一个**事件（中间允许 ≤0.3 s 回落） | 个 |
| 阈值 | **3.4**，敏感性 3.0 / 4.5 | 米每二次方秒 |
| 暴露 | `Σ v_ego × dt`，dt = 0.1 s | 车·公里；同时报车·秒 |
| 事件率 | 事件数 ÷ 暴露 | 每千车·公里 |

**只统计 `Preceding ≠ 0` 的帧**（有前车的跟驰状态）。

## 五、成因分类（三类，规则预注册）

按事件**首次超阈那一帧**判定：

| 类别 | 判定规则 |
|---|---|
| **切入** | 该帧的 `Preceding` 与 3.0 s 前不同；**且**新前车在 3.0 s 前不在同一 `Lane_ID` |
| **前车强刹** | 前车 ID 未变，**且**前车该帧 `v_Acc ≤ −3.0 m/s²`（换算后） |
| **稳态刹晚** | 以上都不满足（前车 ID 未变、前车减速度不超阈值，后车自己刹晚） |

**优先级**：切入 > 前车强刹 > 稳态。一条事件只归一类，不重复计数。
