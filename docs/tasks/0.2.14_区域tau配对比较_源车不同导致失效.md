## 二、致命问题：三组源车不同

**τ 异质改变了整个车流的速度与车距结构**，导致 `t=600 s 时 mid 上距 bn 入口 ≤200 m 最近者`这条规则选中了不同的车：

| 配置 | 源车 ID |
|---|---|
| 均质 | V0169 |
| 异质（mid 层） | V0172 |
| 异质（hi 层） | V0161 |

**这意味着「只改 τ」这个前提不成立**——源车位置、初速、与前车的关系全都变了。

**GPT 第九十二轮要求「使用匹配的随机种子或重复试验」，我做到了种子匹配，但没做到源车匹配。**

## 四、正确的做法：必须锁定源车

要真正做到「只改 τ」，必须：

1. **先跑均质版，记录源车 ID 与 t0 时刻的完整状态**
2. **在异质版里强制指定同一辆车作为源车**（而不是用「最近者」规则重新选）
3. 如果那辆车在异质版里不存在或位置差太多，则该种子作废、换下一个种子

**这需要改脚本：加一个 `--force-src` 参数。**

## 六、一个必须注意的现象

**均质组峰值 2.313，与 0.2.7 的 2.789 不同。**

原因：0.2.7 用的 `region_stop.py` 与本次 `region_hetero.py` 在**订阅变量上多了 `VAR_ACCELERATION`**，
且本次加了 `v≥5 且 |a|≤1.0` 的合格帧筛选（GPT 第九十一轮要求的口径对齐）。

**加了筛选后，峰值从 2.789 掉到 2.313**——因为峰值那一帧后车加速度可能超过 1.0，被筛掉了。

**这是一个口径副作用，必须记录：为了与 NGSIM 可比而加的筛选，会削掉最激烈的那些帧。**
