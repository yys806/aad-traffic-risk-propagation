## 二、根因：原生 Krauss 的司机「太完美」

### 2.1 现状

我们的仿真里，每辆车每 0.1 秒都能：
- 精确读到前车的速度和位置（**零误差**）
- 立刻做出反应（**零延迟**）
- 永远按时停住（**数学上保证不撞**）

**而 AAD 要证明的是「消息比本地感知多给了什么」。**
**如果本地感知本来就完美、反应本来就零延迟，那消息能多给的当然是零。**

### 2.2 手算验证（本记录核心证据）

纯运动学，不跑仿真。条件：前车 9.0 m/s² 减速 2.0 秒、两车同速 21.378 m/s、
初始净距 36.36 m（区域场景实测值）、后车减速度上限 4.5 m/s²。

| 后车反应延迟 | 峰值 DRAC | 超 3.4 | 最终净距 |
|---|---|---|---|
| **0.0 s（= 原生 Krauss）** | **1.482** | 否 | 44.03 |
| 0.2 s | 1.913 | 否 | 39.76 |
| 0.5 s | 2.706 | 否 | 33.34 |
| **0.8 s** | **3.681** | **是** | 26.93 |
| **1.0 s** | **4.429** | **是** | 22.65 |
| 1.2 s | 撞车（净距耗尽，DRAC 发散） | — | ≤0 |

**关键：不需要让前车刹到停，只要给司机 0.8 秒反应延迟，DRAC 就过 3.4 了。**

对比我们两周的做法：为了让 DRAC 过 3.4，把前车一路刹到 0 并保持（3.33 秒），
才勉强到 3.95——**那是「事故停车」，不是「急刹」。**

### 2.3 为什么 0.8 秒是合理的

文献值（`projects/AAD/literature/P3-视距与DRAC文献调研-20261119.md`）：

| 来源 | 反应时间 |
|---|---|
| Olson & Sivak 1995（95 分位实测） | **1.6 s** |
| AASHTO / 中国规范（设计值） | 2.5 s |
| Markkula（紧迫场景下） | < 1 s |

**0.8 秒落在合理区间内，不是我们编的。**

## 三、同时核实出两个代码 bug（Gemini 抓出，我已逐行核实）

### 3.1 Bug 1（严重）：事件计数器被塞进了「后车没刹车」的筛选里

`region_pair.py` 第 212–227 行：

```
if s_ego >= V_MIN and abs(a_ego) <= ACC_MAX:     ← 只保留后车加速度 ≤1.0 的帧
    ...
    if drac >= DRAC_THR and v_ego != src_id:     ← 在这里数事件
```

**等于规定：只在「后车几乎没踩刹车」的帧里，统计「需要猛踩刹车」的事件。**

**后果：全帧口径下 8/40 臂已超 3.4（最高 4.32），被这个筛选全删光，事件数恒为 0。**

### 3.2 Bug 2：分母塌缩

| 臂 | 车·公里 |
|---|---|
| 无刹车 | 1,324 |
| **刹车** | **252** |

**刹车组车走不动，车·公里缩水 5 倍。** 用它当分母算「每公里风险」，会把「车堵住了」误读成「风险暴涨」。

### 3.3 Claude 另指出两处口径不一致

- **碰撞全程计数**（从 t=0 起），**DRAC 只在 [t0, t0+600) 内计**——两者不是同一批帧
- 三次碰撞最小净距**全是 2.401 m**（车型 minGap=2.5），三个不同种子得到完全相同的正数
  → **更像 SUMO 把「净距小于 minGap」登记成 collision，不是真撞上**

## 四、三家对「尺子」的判断（都否掉了我的说法）

### 4.1 我说「DRAC 只测力度不测时机」——三家都说这个说法不准确

| 模型 | 纠正 |
|---|---|
| **GPT** | 「净距已反映此前距离消耗，DRAC 并不完全忽略过去。它真正缺的是**对未来响应时序的刻画**」 |
| **Claude** | 「DRAC 用的是相对速度，已考虑前车在动。真正盲区是**假设前车匀速 + 后车零反应时间**」 |
| **Gemini** | 「DRAC 不是把前车当静止障碍，而是假设前车**从这一刻起保持匀速**且后车**零反应延迟**」 |

**三家说法一致：DRAC 的盲区是「假设前车匀速 + 后车零反应」，不是「只测力度」。**

### 4.2 我说「1.67 却撞车，证明尺子失灵」——两家都说站不住

**Claude**：
> 「物理上不成立：如果净距真被耗尽，而后车仍比前车快，DRAC 在接触前会趋向无穷。
> 『轻踩、踩晚、撞上』的过程中，需求减速度一路上升，DRAC 测得到。
> brief 4.2 节把『需求』当成了『施加』，这是概念错误。」

**Gemini**：三次碰撞的净距全是 2.401 = minGap 边界，是 SUMO 的 collision 判定问题，不是真撞。

**所以我的「尺子失灵」论据被推翻了。**

## 五、三家对「区域风险该用什么量」的建议（不完全一致）

3. **分母外生**（不能用被干预改变的车·公里）

**分歧点：具体用哪个量。需要研究者与 GPT 定。**
