## 三、必须如实报告的三个问题

### 3.1 D_brake 报 15 次碰撞，但不可复现

第一次跑：15 次。随后我写检查脚本想核实，**两次重跑都是 0 次**。

**原因已查明：我的第一个检查脚本（v1）没有复现刹车逻辑**——刹车是 traci 在运行中施加的，不在配置文件里，所以直接跑配置必然 0 碰撞。**这是检查脚本的错，不是结果的错。**

已重写 v2（完整复现刹车），正在跑。

### 3.2 SUMO 的 Collision 对象没有 gap 字段

我查了 `traci._simulation.Collision` 的源码，字段只有：
`collider / victim / colliderType / victimType / colliderSpeed / victimSpeed / type / lane / pos`

**没有 gap。** 所以此前汇报的「碰撞时最小净距 2.401」**不是碰撞记录里的，是我另算的全局最小净距**。这个表述必须更正。

### 3.3 「15 次碰撞」与「最小净距 1.217」可能不是同一件事

- `collisions=15` 来自 `traci.simulation.getCollisions()`
- `min_gap=1.217` 来自我逐帧算的几何净距

**两者同一次运行，但可能不是同一批车。** 必须等 v2 结果说话。
