## 三、台架 3.947 vs 区域 2.789，差在哪

| 项 | 台架（0.2.6） | 区域（0.2.7） |
|---|---|---|
| 初速 | **30 m/s** | **21.378 m/s** |
| 施刹净距 | 52.0 m | **36.36 m** |
| 停稳耗时 | 3.33 s | 2.4 s |
| 峰值 DRAC | **3.947** | **2.789** |

**速度低 29%、净距小 30%，两者同时不利。**

但注意：**净距更小本应让 DRAC 更高**（DRAC = c²/(2g)，g 在分母）。
如果只看净距，区域应该比台架**更高**。所以**净距不是压低峰值的原因，速度才是。**

这与 GPT 第八十五轮 Q3 的判断一致：**「绝对初速不直接进入相对运动；相同闭合速度下，净距越小，DRAC 反而越高。」**

### 3.1 为什么速度会压低峰值（机理）

后车能够用来制动的时间与距离，由「前车从 v 减速到 0 所走的距离」与「后车自身从 v 减速到 0 所需的距离」之差决定：

- **30 m/s**：前车刹停距离 = 30²/(2×9.0) = **50.0 m**；
  后车全力刹（4.5）距离 = 30²/(2×4.5) = **100.0 m**
  → 后车需要的距离比前车多 **50.0 m**，而初始净距只有 52.0 m
- **21.378 m/s**：前车刹停距离 = 21.378²/(2×9.0) = **25.4 m**；
  后车全力刹距离 = 21.378²/(2×4.5) = **50.8 m**
  → 多需要 **25.4 m**，初始净距 36.4 m **够用**

**关键在于：净距需求随速度平方增长，而区域场景的净距（36.4 m）相对富余，台架（52.0 m）相对紧张。**

## 四、这意味着什么（重要）

> 🔴 **本节（4.2、4.3）已于 2026-11-21 01:22 撤回。**
> 原因：解析式里的 `v_f` 应采用**峰值时刻后车**的速度，我用成了源车初速 21.378。
> 按正确口径（v_f=11.028），解析上界只有 **1.963**，实测 2.789 **超出 42%**。
> **解析式不是硬上界**，只在「安全约束刚卡住」那一瞬成立；峰值帧后车已侵入安全裕度 9.18 m。
> 详见 `0.2.8_峰值车对轨迹_解析式不是硬上界.md`。
> **本节以下内容保留仅为记录当时的推理过程，不得引用。**

### 4.1 区域场景在真实密度下，停车工况也不越阈

峰值 2.789，是阈值的 82%。**不是差一点点，是差 18%。**

### 4.2 这与 0.1.9 的解析天花板是同一件事

0.1.9 三家独立推出：**τ=1.584、b=4.5 下，22 m/s 前车静止时 DRAC 上限 2.73**。

**实测 2.789 —— 与解析上界 2.73 几乎完全吻合，高出 2%。**

这说明区域场景**已经顶在 Krauss 的解析天花板上**，不是脉冲不够猛、不是场景不够狠，
**是这个控制器 + 这组参数 + 这个速度下的物理上限。**

### 4.3 要越阈，必须动速度（这条我先前算错了，已更正）

按 0.1.9 的解析式 `DRAC_max = b/(1 + 2bτ/v_f)`，b=4.5、τ=1.584：

| 车速 | 解析上界 |
|---|---|
| 21.38 m/s（77 km/h） | **2.700** ← 区域场景 |
| 22 m/s（79 km/h） | 2.731 |
| 30 m/s（108 km/h） | 3.050 |
| 33 m/s（119 km/h） | 3.142 |
| 40 m/s（144 km/h） | 3.318 |
| **44.06 m/s（158.6 km/h）** | **3.399** ← 刚够 3.4 |

**要够 3.4，车速需要 ≥ 44 m/s（158.6 km/h）**，不是我先写的 33 m/s。
这与 0.1.9 记录的「要够 3.4 需 44 m/s」完全一致。

**而区域场景在 1600 辆/h 密度下只能跑到 21.4 m/s。**

实测 2.789 比解析上界 2.700 高 3.3%——因为施刹瞬间前车还在运动、
净距仍大于完全静止的假设，属正常偏差。
