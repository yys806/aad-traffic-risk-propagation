## 五、轨迹里发现的一个机制（待验证）

看 602.20 → 602.30：

- 前车速度从 **0.678 → 0**，一步降 0.678（**触零落地**）
- 后车速度从 11.478 → 11.028，一步降 0.450（4.5 m/s²，正常）
- **闭合速度从 10.800 → 11.028，涨了 0.228**

**前车「落地」那一步比稳态减速多给了 0.228 m/s 的闭合增量。**

原因：稳态时前车每步也降 0.9（9.0 m/s²），后车降 0.45，闭合每步涨 0.45；
但触零那一步前车只降了 0.678（因为从 0.678 到 0 就到底了），
**这反而是「少降」，不该让闭合涨更多**——

**需要重新核对：是不是后车那一步的降速小于 0.45？**
602.20→602.30 后车降 0.450，正好 4.5。前车降 0.678。
闭合增量 = 0.678 − 0.450 = 0.228 ✓
**而 602.10→602.20 闭合增量 = 0.9 − 0.45 = 0.45。**

**所以触零那一步闭合增量反而更小（0.228 < 0.45），不是更大。我上面写反了。**

真正让 DRAC 涨的是：**闭合速度还在涨（虽然涨得慢了），而净距在缩（22.909→21.806）。**
峰值出现在「闭合增长」与「净距收缩」的平衡点之后一帧，属正常数学结果。
