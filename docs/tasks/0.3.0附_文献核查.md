## 三、查到什么就能定什么（这一节才是重点）

| 要定的事 | 该查哪篇 | 查到/读到什么才能定 |
|---|---|---|
| **v0.3 §11 的检验方法** | #5 Canay 等 2017 | 若确认「近似对称性下符号翻转可用」，就把 v0.3 的「块内随机化」改成「原假设下块差分布对称」，并把检验写对；**不需要随机分配标签** |
| **服务门样本量** | #6 Schuirmann 1987 | TOST 双单侧、α=0.05、界值 ±2.0 s 的样本量公式，与我这轮算的 3.88 倍对上后写进 §7.5 |
| **τ 该不该重新标定** | #2 Coifman & Li 2017 | 若其明确指出 NGSIM 净距误差量级，就能说明「净距→τ」这条路本身不可靠，τ 只能作工程参数；这与 0.2.29 的结论一致但依据更硬 |
| **0.8 s 能不能叫反应时间** | #3 Markkula 2016 | 该文主张反应时间随运动学变化，不是固定常数 → 我们只能写「决策更新周期」，**不能写「人类反应时间」**（这条 v0.3 §10 已写对） |
| **DRAC 3.4 与截顶 5.6 的依据** | #1 Cunto & Saccomanno 2008 | 该文给 MADR 分布 N(8.45, 1.4²)，区间 4.23–12.68；**不能**用来给 5.6 背书，5.6 只能说是「9.0 − 3.4」的模型内推导 |
| **AAD 的新颖性边界** | #7 队尾预警实证 + #8 VSL 微观 | 若已有工作把「内容 / 交付时机 / 同等控速代价」三者拆开过，AAD 的新颖性就只剩「物理到达前的同钟反事实」，必须改写贡献声明 |
