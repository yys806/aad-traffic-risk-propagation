# 阶段 0：从现实校准到 E01 协议锁定

## 本阶段只解决什么

本阶段不检验“类超距作用”是否成立，只为正式四格实验准备一套不能随结果改变的测量协议。依赖顺序固定为：

> E15-A 真实风险测量 → E16-A 通信可观测边界 → E17-A 仿真现实覆盖 → E01 指标、路径、容差和样本量冻结 → `protocol_lock_v1.1.yaml`

只有最后的协议锁签署后，E02 才有资格启动。本阶段禁止运行 E02、优化控制器、扩大场景、使用 holdout 调参，或把 calibration 结果写成主效应证据。

## 共同数据边界

- Calibration：NGSIM US-101、NGSIM Lankershim、pNEUMA `20181101_d1_0800_0830`、按 `sha256(DeviceID|Trip)` 固定划分的 SPMD calibration trips。
- Locked holdout：NGSIM I-80、NGSIM Peachtree、SPMD holdout trips。本阶段只登记文件和校验和，不保留其结果。
- pNEUMA 道路快照：`athens_d1_bbox_20260907.osm`，仅用于 calibration 地图匹配。
- DRIFT：只读参考，不修改，也不把历史输出直接转成正式论文证据。

冻结清单以 `code/outputs/formal/calibration/calibration_inputs_v2/` 为准。旧 v1 保留为历史版本，不覆盖。

## E15-A：真实风险测量

NGSIM 全时间窗先完成单位换算、报告前车同帧匹配、净间距、闭合速度、TTC、DRAC 和连续风险帧合并。单帧告警不是独立风险事件；无前车、无法匹配、非闭合和非正间距分别保留不同状态，缺失不填零。

pNEUMA 先做道路和行驶方向匹配，再生成候选前车。当前所有道路与前车关系仍是 `candidate_unverified`，在 300 条人工审计完成前禁止计算 pNEUMA TTC。人工审计通过后才能形成包含 NGSIM 和 pNEUMA 的 300 个事件隔时盲复标包；第 2 轮与第 1 轮至少间隔 7 天。

E15-A 只有在两来源均形成可审计风险事件，且人工 precision、recall 均不低于 0.95、Cohen's kappa 不低于 0.90 时通过。做不到时停止，不降低标准。

## E16-A：现实通信能观察到什么

`RV_RX` 仅用于接收侧远车状态流和连续性。行数不是消息数，观测断点不是丢包，接收记录不是控制器采用。

先核验约 15.3 GB 的 `Packet.csv.zip`。只有真实表头和样本证明其能提供设备—行程关系、消息级时间或序号、发送机会分母，并预计可将歧义控制在 1% 以下，才允许下载约 55.7 GB 的 `BsmP1.csv.zip`。不得根据文档中的可能字段预先假定真实接口。

若官方 Packet 入口仍不可用或字段 Gate 不通过，本阶段的可观测边界固定为 `receive_state_continuity_only`；后续不得报告现实消息时延、丢包或采用。

## E17-A：仿真是否覆盖现实交通

现实参考只包含与主线有关的物理变量：速度、加速度、净间距、闭合速度和风险事件持续时间等。连续变量使用真实 calibration 数据拟合中位数/IQR 标准化；real-real 距离的经验 95% 分位作为自然差异上界，仿真—现实距离不得超过该上界。类别覆盖单独审计，至少覆盖 90% 的真实冲突层。

当前只允许封存现实参考。local-only SUMO 校准集必须等待 E15-A 的测量规则确认后再生成，并且不得包含指定远端消息作用、Stage II 控制器或主效应统计。

## E01：验证测量和时间判定

E01 先通过解析真值检查 TTC、DRAC、PET、碰撞、缺失掩码和事件合并，再用只读封存数据检查不可达、有限到达和右删失的物理路径。时间步依次比较 0.10、0.05、0.02 s，必要时使用 0.01 s 参考。

解析测试通过不等于 E01 通过。只有 E15-A、E17-A 已通过，且以下数值由 calibration 数据产生并形成严格间隔，才能继续：

\[
0\leq\delta^{\mathsf{eq}}<\delta^{\mathsf R}<\delta_{\mathrm{plan}}.
\]

随后才能运行 50 个 calibration seeds 估计配对方差与 E02 样本量；这些 seed 永不进入 E02 正式统计。
