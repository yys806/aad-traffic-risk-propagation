# 9.10 组会汇报：AAD 实验与论文推进计划

> 当前记录截至 2026 年 9 月 7 日。计划共 20 个有效工作周。时间用于安排工作，上一阶段的验收关口没有通过时，不因日期到期自动进入下一阶段。

## 一、研究问题和总体顺序

### 1.1 这篇论文要回答什么

本文关注一个问题：一条来源明确、确实被控制器采用的远端风险信息，能否在源风险的物理影响到达目标区域之前，先改变目标区域内车辆的动作，并最终改变目标区域的总体风险。

研究分为两个科学阶段。Stage I 先判断这种信息效应是否真实存在，并排除普通物理传播、提前保守驾驶、错误消息和程序误差等其他解释。Stage II 只有在 Stage I 通过后才开始，研究如何利用已经验证的信息机制降低平均风险和极端风险，同时避免过度制动、通行效率下降或新的安全问题。

### 1.2 为什么不能直接扩大四格实验

正式主效应实验开始前，必须先证明三件事：风险指标确实量对了，仿真交通没有明显偏离现实，实验规则不会在看到结果后被修改。因此，E00 先验证整个运行和复算系统；E15-A、E16-A、E17-A 用现实数据确定测量边界；E01 冻结指标、容差、时间步和样本量。只有这些内容写入 `protocol_lock_v1.1`，也就是“正式实验前锁死的规则文件”，E02 才能启动。

完整顺序为：

> E00 → E15-A / E16-A → E17-A → E01 与协议锁 → E02 → E03 → E04 → E05 → E06 → E07 → E08 → E10 → E09 → E15-B / E16-B / E17-B → E11 → E12 → E13 → E19-A → E14 → E19-B → E18 → 全文复算与投稿

这条顺序的核心逻辑是：先保证“尺子”和“实验系统”可信，再判断效应是否存在；效应存在后再解释它为什么出现；最后才讨论它能否推广、能否用于控制以及在极端情况下是否仍然安全。

### 2.8 实验与论文共同遵守的 NC 级规则

Nature Communications 看的是创新性、潜在影响、数据质量、对照是否充分和结论是否有足够证据支持，而不是实验编号或实验数量。为避免计划很大但证据很散，全文主干固定为“测量可信—断开拓扑核心效应—消息作用链—信息先于物理传播—适用与失效边界”。Stage II 只在 Stage I 成立后进入主文。

所有阶段共同遵守以下规则：

1. Stage I 只保留一个确认性主要终点，即目标区域事件级、归一化的积分 TTC 风险暴露；DRAC、最小 TTC、碰撞、舒适性和效率是辅助或安全终点，不能在看到结果后互换主次。
2. 正式统计的独立样本是完整的场景—seed 四格配对。帧、车辆和同一 seed 内的风险事件属于内部重复，使用分层模型或以四格配对为单位的 cluster bootstrap，不能拆开扩大样本量。
3. `protocol_lock_v1.1` 在 E02 前冻结主要终点、实际重要性门槛、样本量、seed、运行顺序、纳排规则、缺失和右删失处理。修改必须形成 amendment 和新版本，不能覆盖原锁。
4. 零效应和负对照使用等效检验，不能把“没有显著差异”直接解释成“没有效应”。辅助终点、控制器、风险类型和亚组采用预先规定的分层检验或多重比较控制；探索性结果单独标记。
5. 能隐藏实验条件的统计和人工标注使用匿名 ID。失败运行全部进入失败账本，不能因方向不利被删除。
6. 每个阶段同步产生图表草案、完整分布、效应量与置信区间、失败分母和 Source Data。最终代码、环境、命令、配置和数据清单均需封存，核心代码准备可生成 DOI 的公开版本。
7. 结论跟随证据收缩：E02 失败就停止核心主张；E03 失败就只说明提前保守控制；E05/E06 失败就不能声称消息作用链；E09/E10 失败就不能声称信息早于物理传播；E16/E18 受限就不能声称真实通信或真实控制栈已经验证。

这套计划在设计上符合高水平计算研究对可证伪、可复算和证据边界的要求，但计划本身不能保证达到 NC。最终能否达到该水平，取决于 E02 的核心效应、E03–E06 对替代解释的排除、E09/E10 的信息先行证据，以及这些结果相对已有工作的真正推进。核查依据包括 Nature Communications 的 [编辑标准](https://www.nature.com/ncomms/submit/editorial-process)、[审稿标准](https://www.nature.com/ncomms/for-reviewers/writing-your-report)、[数据与代码政策](https://www.nature.com/ncomms/editorial-policies/reporting-standards)和[计算研究复现指南](https://www.nature.com/documents/Computational_tools_reporting_guidelines.pdf)。

### 3.2 阶段 1 至阶段 6：尚未启动正式实验

E02–E19 目前仍是已经设计并预注册的后续工作，还没有产生正式科学结果。历史 Pilot、旧 DRIFT 输出和 calibration seeds 都不会被当成主效应证据；DRIFT 保持只读，AAD 的正式结果将在相应前置条件通过后重新生成。当前唯一应继续推进的是阶段 0，不能为了让汇报看起来更丰富而提前运行后面的实验。
