- [前期审计与预注册](./前期审计与预注册/README.md)：已有实验审计、NC 预注册方案和历史判断。
- [阶段 0：基础设施与测量](./阶段0_基础设施与测量/README.md)：当前正在执行的 E00、E01 和现实数据 calibration。
- [阶段 1：核心效应确认](./阶段1_核心效应确认/README.md)：E02–E04。

## 管理规则

1. 总计划保持全局方向稳定；每个阶段用自己的阶段计划管理具体执行。
2. 实验、统计、图表、Methods、Results 和易懂版解释在同一阶段同步更新。
3. 任何失败、零效应和协议变更都保留记录，不用新结果覆盖旧结果。
4. 阶段只能在前置 Gate 通过后推进；DRIFT 仍只读。
5. 所有 AI 生成的证明、定义和说明先做简化审查：先给易懂结论，再给最小必要的正式表达，禁止无关发散。
6. **Methods 与 Results 严格分工：** Methods 写定义、模型、实验设计、测量、统计和复现；Results 写观察、效应、不确定性、证据判断和失败边界。不得在 Methods 中提前写结果，也不得在 Results 中事后改写方法规则。
