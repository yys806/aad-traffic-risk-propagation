# 论文与阶段推进

这里是 AI 维护的当前执行账本。研究者日常查看的论文和文献仍分别位于根目录 `paper/`、`literature/`；个人对话笔记不要求同步到这里。

## 使用顺序

1. `总计划.md`：看阶段顺序、日期和交付物。
2. `阶段0_基础设施与测量/执行记录.md`：看当前 Gate 和下一动作。
3. 各 `阶段 X.X/执行记录.md`：看该子阶段的事实、证据、阻断与结果边界。
4. `docs/PROJECT_REGISTRY.json`：机器可读状态；`docs/STAGE_INDEX.md` 与 `docs/RESULTS_INDEX.md`：人类索引。

新运行一律使用人类标签“阶段 X.X”和机器标识 `stage_X_Y`。旧实验编号只在 `docs/归档/旧实验编号材料/`、`evidence/history/` 和历史输出中保留。
