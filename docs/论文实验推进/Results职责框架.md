# Results 职责框架

## 当前写作原则

当前阶段只固定 Result 1–6 的证据职责、核心问题和章节边界，不提前填写实验结论。待 Methods 冻结且相应实验完成后，再填入观察结果、效应大小、不确定性、审计结论和失败记录。

Results 只回答“观察到了什么、证据有多强、在哪些条件下成立或失败”。模型、变量、约束、实验流程、指标和统计方法均在 Methods 中定义，Results 不重复推导。

## Result 1：测量与分析链的有效性

- **核心问题：** 测量、运行和分析链是否足以支持后续结果。
- **证据职责：** 建立全文的质量门槛，证明工具与判定过程可用。
- **禁止越界：** 不回答核心效应是否存在，不用校准通过替代因果证据。
- **最终填入：** 校准表现、复现性、判定准确性和未通过项目。

## Result 2：非最近邻风险效应的核心识别

- **核心问题：** 排除物理传播后，指定远端消息是否产生可归因的增量风险效应。
- **证据职责：** 在全部预先登记的正式四格单元上估计 intention-to-run 效应，提供效应方向、大小与不确定性的核心证据。
- **禁止越界：** 不解释完整机制，不评价连通场景控制价值，不外推一般性。
- **最终填入：** 主要效应、实际意义、不确定性、工程失败、缺失数据界限和全部正式分母。

## Result 3：信息—动作—风险作用链的机制审计

- **核心问题：** 风险差异能否沿指定作用链追溯，关键替代解释能否被排除。
- **证据职责：** 闭合机制链条，并定位通信、校验、采用或实际输入环节的失败；机制状态不改变 Result 2 的样本成员关系。
- **禁止越界：** 不重复 Result 2 的主要效应，不把交付量或采用量当作效应证据。
- **最终填入：** 作用链通过率、时间顺序、负对照结果和失败环节。

## Result 4：物理连通场景中的信息先行与控制价值

- **核心问题：** 物理路径存在时，信息响应能否先于物理影响并形成安全、有效的闭环收益。
- **证据职责：** 检验机制向现实交通交互场景的迁移，并评价 Stage II 控制价值。
- **禁止越界：** 不替代 Result 2 的结构隔离；不以风险下降单独证明控制有效。
- **最终填入：** 时间先后、风险与控制收益、安全约束、效率代价和失败运行。

## Result 5：真实数据支持的外部校核与证据边界

- **核心问题：** 真实数据能够直接支持哪些测量、分布和可观测性校核。
- **证据职责：** 检查外部一致性，并明确真实数据的证据层级。
- **禁止越界：** 不从缺失的采用或动作字段推断闭环因果效应，不直接比较定义不同的指标。
- **最终填入：** 可支持的校核结果、不可观测字段、数据质量问题和结论限制。

## Result 6：适用域、稳健性与失效边界

- **核心问题：** 核心证据在条件变化时能否保持，在哪些条件下减弱、消失或失效。
- **证据职责：** 综合界定适用域、异质性、稳健性与失败边界。
- **禁止越界：** 不重复 Methods 定义或单场景主效应，不将有限扩展写成普遍规律。
- **最终填入：** 跨条件效应、异质性、稳健性、安全与效率权衡，以及零效应、不确定和失效条件。

## 填写顺序

1. Methods 与分析规则冻结后，先完成 Result 1 的质量门槛。
2. Result 1 通过后，填写 Result 2 的核心识别结果。
3. 用 Result 3 审计 Result 2 的作用链和替代解释。
4. 再填写 Result 4 的连通场景迁移与控制结果。
5. Result 5 只按真实数据直接支持的层级补入外部校核。
6. 最后汇总 Result 6 的跨条件证据和失效边界。

该顺序体现“工具有效—效应存在—机制闭合—现实迁移—外部校核—适用边界”的证据递进，不能用后一级结果补偿前一级证据缺失。
