# 前期审计与预注册

本目录保存正式阶段计划建立前形成的实验审计、NC 预注册和历史判断。它们是重要依据，但不替代后续阶段文件中的实际执行记录。

## 文件职责

- `NC级实验预注册与顺序执行方案_v1.0.md`：当前实验设计、预测、门槛和顺序的权威依据。
- `NC级实验审计与补强路线图.md`：前一版审计路线图，仅作历史参考。
- `实验登记表.csv`：O01–O16 历史实验和 E00–E19 新实验的结构化清单。
- `findings.md`、`progress.md`、`task_plan.md`：前期审计过程记录。
- `执行记录规范.md`：正式阶段执行记录的通用规则。
