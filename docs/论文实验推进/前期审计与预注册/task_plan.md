## Key Questions

1. AAD 过去到底运行过哪些实验，哪些结果具备原始证据和复算链？
2. 哪些结果只是小规模 smoke test、通信原型或字段审计，不能支撑论文主张？
3. 同类 NC 论文通常如何证明有效性、一般性、鲁棒性和可复现性？
4. 为支撑 Result 1–6，最小但完整的实验体系是什么？
5. 在算力和时间不设上限时，哪些扩展能显著提高 NC 竞争力，哪些只是无效堆量？

## Decisions Made

| Decision | Rationale |
|---|---|
| DRIFT 全程只读 | DRIFT 是已完成的上游交通流项目，不属于本次修改范围 |
| 规划文件放在本研究子目录 | 保持仓库根目录整洁，遵循用户既定目录结构 |
| 本轮先审计与设计，不直接启动大规模实验 | 先冻结主张、协议和统计计划，避免结果导向地反复改实验 |
| NC 论文以原文和补充材料为主要证据 | 搜索摘要只用于发现，不作为实验标准的最终依据 |

## Errors Encountered

| Error | Attempt | Resolution |
|---|---:|---|
| 全仓库关键词检索输出过长并截断 | 1 | 后续按文档、代码、配置和输出分组审计 |
| PowerShell `foreach` 结果直接接管道导致空管道解析错误 | 1 | 先将循环结果赋给 `$rows`，再格式化输出 |
| 一次性打印多个大型 JSON/CSV 摘要导致输出截断 | 1 | 改为逐文件解析并只提取关键字段，不重复整包输出 |
| 联网搜索接口返回响应解码错误 | 1 | 按 web-access 规范改用本机 Chrome CDP 代理检索原始论文页面 |
| 末尾空白检查再次将 `foreach` 直接接到管道导致 PowerShell 解析错误 | 1 | 按既有规则先收集 `$rows` 再输出，并纳入最终错误日志 |
| 本轮技能文件行数统计再次将 `foreach` 直接接管道 | 1 | 立即按已知方案改为 `$rows = foreach (...)` 后输出，不重复该写法 |
| 批量下载5份补充材料时第三个大 PDF 超过30秒并遗留 curl 进程 | 1 | 核验目标进程和文件后仅终止本次 curl；改为逐份带超时下载，已取得3份关键 PDF |
| Poppler 解析批量 PDF 时 `pdfinfo` 路径不可用且未完成的 Feng PDF 出现 XRef/trailer 错误 | 1 | 不把损坏文本当证据；逐文件验证 PDF EOF/页树，重新下载 Feng 到临时文件后原子替换；其余文件单独解析 |
| Sage 与 Wiley 原文页触发 Cloudflare 验证，PMC 复杂 selector eval 报 Uncaught | 1 | 不重复受阻页面；改用开放 PMC/PubMed 原始记录和已核验 DOI，简单 DOM 读取 PMC |
| FHWA 三个页面首次整页抽取输出过大并截断 | 1 | 停止整页转储，改为逐页按术语和标题抽取并用官方原文核验 |
| 试图清理本轮临时 PDF 目录时执行层拒绝 Remove-Item 命令 | 1 | 不猜测权限原因；临时文件仍位于 `code/tmp/`，不进入 Git，后续只做只读核验 |
