# 论文符号系统规范

> 状态：执行中；适用于主论文、Methods 工作稿和后续实验文档。  
> 原则提出：2026-08-20

## 总原则

1. **先定义，后使用。** 每个新符号第一次出现时给出对象、取值域和单位（适用时）；后文不重新赋予不同含义。
2. **语义标签放上标。** 车辆类型、网络类型、风险指标、时间事件、策略分量和区域角色等标签统一使用上标，并用 `\mathsf{}` 表示，例如 `G^{\mathsf P}`、`I_{j,\omega}^{\mathsf{TTC}}`、`t^{\mathsf{adopt}}`、`\kappa_i\in\{\mathsf{AV},\mathsf{HV}\}`。
3. **索引放下标。** 车辆、消息、配对单元、时间步和路径位置等索引统一放在下标，例如 `R_{j,\omega}`、`D_{q,j}(t)`、`v_\ell`。索引使用普通数学斜体，不使用 `\mathrm{}` 或 `\mathsf{}`。
4. **变量主体使用普通数学字体。** 标量、向量和函数名默认使用 LaTeX 的普通数学字体；只有集合、矩阵或明确的语义标签使用 `\mathcal{}`、`\mathbf{}` 或 `\mathsf{}`。不使用字体命令代替下标索引。
5. **同一对象只有一个写法。** 不再并列使用 `R_j^{(\omega)}` 与 `R_{j,\omega}`、`I_{\mathrm{TTC}}` 与 `I_{j,\omega}^{\mathsf{TTC}}` 等变体。

## 使用检查

- 新符号首次出现必须在同一句或紧邻公式前定义。
- 标签不得再次沉入下标：写 `G^{\mathsf P}`，不写 `G_P`；写 `I_{j,\omega}^{\mathsf{TTC}}`，不写 `I_{\mathrm{TTC}}`。
- 索引不得伪装成标签：写 `R_{j,\omega}`，不写 `R_j^{(\omega)}`；写 `v_\ell`，不写 `v^{\ell}`。
- `\mathsf{AV}` 和 `\mathsf{HV}` 只表示车辆类型标签；车辆实例仍由下标 `i,j` 标识。
- 当某个量需要显式区分车辆类型时，写作 `x_i^{\mathsf{AV}}` 或 `x_i^{\mathsf{HV}}`；类型标签不能写成 `x_{i,\mathrm{AV}}`。
- Results 只引用 Methods 已定义的符号，不在结果段临时改变符号含义。
