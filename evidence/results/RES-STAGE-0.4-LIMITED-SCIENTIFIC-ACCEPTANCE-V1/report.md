# Stage 0.4 有限科学验收（Limited Scientific Acceptance）

Stage 0.4 以研究者批准的**有限范围**正式通过并收束：**Gate = `pass_limited`；Stage Status = `Completed / Closed (Limited Scope)`**。

## 验收范围（仅）
真实通信数据的可观测性边界 + 已验证的描述性通信证据 + 后续通信仿真参数的不确定性处理原则。

## 不验收
真实通信性能模型准确性、真实 PDR/时延数值校准、距离相关通信函数、信息/控制器采用、AAD 核心因果效应。

## 分层证据
- **已验证**：RV_RX 接收状态连续性；RSE_BSM 车辆侧接收内容（无接收时间）；SEE-V2X 消息身份关联（48 对配对率 1.0）、描述性日志接收比例（室内 0.998–1.0/室外 0.22–1.0）、时延数值复算。
- **未验证（不因收口升级）**：真实链路 PDR、接收机会（无线模块在线）、绝对时延（时钟偏移）、距离—PDR、信息采用、自然交通 V2V 适用性。
- **候选参考（受控 PC5）**：配对方法、接收比例范围、相对时延排序、GNSS 时间对齐——仅作描述性/候选参数。
- **否定性结论（有效成果，保留）**：SPMD 不足以恢复真实 V2V 端到端时延；SEE-V2X GNSS 不足以支持距离函数；GNSS 覆盖≠无线模块在线；缺独立时钟证据不能冻结绝对时延。

## 参数未校准声明
通信时延、投递率、距离衰减**均未冻结、均未校准**；不足部分作为**标记为不确定的实验/敏感性参数**，不得以真实校准值表述。

## 历史追溯
RV_RX V3 的 `pending_official_packet_access` 审计保留为历史事实，未改写；原始 Packet HTTP-403 记录保留。本验收是对 Stage 0.4 整体有限科学目标的验收，**不代表官方 Packet 已下载或 packet-level 验证已完成**。研究者批准：任务 AAD-0.4.8（归档 `AI_CONTEXT/06_DECISIONS.md`）。
