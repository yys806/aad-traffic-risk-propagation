## 1. B1.2 阻断的原因及证据边界

B1.2 的 `4.6580112445444345e-6 m/s` 与公开终速 0 符合该清零机制的数值及调用顺序；本任务保留旧轻量审计，未读取旧 C 完整状态，未重判旧阻断。旧步的完整独立停车上下文未在本轮重新观测，**不能把源码解释一致写成旧边 Exact Numerical Equivalence Verified**。

## 2. 真实清零条件与三个速度

固定 SUMO 1.26.0 / commit `fa7df22d7f1c4ae245192ecc32410a49f1ffb2a3`。11 个具名官方源文件均登记原始字节 SHA；`MSVehicle.cpp` SHA 为 `8499ebe445906b19395d5c70945b012f320a439327e9cb3c20f0abd26d15a6a4`。依据见 [MSVehicle.cpp](https://github.com/eclipse-sumo/sumo/blob/fa7df22d7f1c4ae245192ecc32410a49f1ffb2a3/src/microsim/MSVehicle.cpp#L4644) 和便携 `near_zero_source_contract.json` 的文件/行号映射。

阈值为 `NUMERICAL_EPS_SPEED=0.1*NUMERICAL_EPS*TS`。`NUMERICAL_EPS=0.001` 是 SUMO 通用数值常数，`POSITION_EPS=0.1` 是内部位置比较常数；两者职责不同。`TS=0.05 s` 时速度阈值 `5e-6 m/s`，随内部步长变化。比较为严格 `<`，恰好等于正负阈值均不触发。

清零还要求 `myStopDist>POSITION_EPS`，**或**存在下一停车任务且当前 route iterator 等于下一停车任务 iterator。不能只检查速度。`myStopDist` 由构造/重置设为 doubleMax；决策规划中默认 doubleMax，处理首个停车任务时才写入有限 stopDist；非决策步跳过该规划。状态恢复中存在另一个置零分支，本轮明确排除。没有停车任务时，该私有距离反而可以保持 doubleMax，并不意味着清零条件为假。

计算顺序是：决策步 `finalizeSpeed/processNextStop`，或非决策步延续步初加速度 → 得到 `u_pre` → 条件近零清零 → TraCI 速度控制/混合动力覆盖 → 最终带符号 `u_final` → `updateState/getDeltaPos` 位移 → 公开速度 `max(u_final,0)`，公开加速度 `(max(u_final,0)-v0)/h`。本轮通过只读 worker、输入、运行时配置和设备 getter 排除后续覆盖。

| 分支 | u_pre / u_final / public 的关系 | 本轮资格 |
|---|---|---|
| 正常非决策步，绝对候选值不在严格近零区间 | u_final=u_pre；public=max(u_final,0) | 可精确 |
| 正/负近零候选且条件独立为真 | u_final=0；public=0 | 源码/合成验证；运行仅观察到负候选 |
| 条件独立为假 | 不清零；负候选仍由 public 钳制隐藏 | 解析反例，未声称实际一般 False 可识别 |
| 非决策步提前停车，负候选在近零区间外 | 位移使用负 u_final 截断停车时间，public=0 | 可精确，不用步末加速度反推 |
| 决策步终速 0、v0>0 | 隐藏最终带符号速度 | 仅必要范围 |
| v0=public=0 | 隐藏终速未必已识别，但位移 0 可识别 | 标明 stationary displacement，不声称恢复隐藏速度 |

## 3. 无位移反推的可识别范围

公开 `getStops` 是停车任务列表，源码会过滤 collision stop；`getStopState` 是到达/停车状态位；`getDrivingDistance` 是当前路径几何距离，均不等价于缓存的私有 `myStopDist`。空停车列表本身不能证明条件真或假。

本轮只采用两项**充分条件证明**：

1. 全新生命周期，无状态恢复、停车任务/路线动态修改、collision/teleport、特殊设备，输入无停车任务，公开列表持续为空，非循环路线已核对：构造、重置及有限赋值来源共同证明 stopDist 始终 doubleMax，第一 OR 分支为真。
2. 常规下一停车任务公开列表稳定、同一非循环当前路线 edge，且为非决策步：不调用会改变停车列表的 finalizeSpeed/processNextStop，第二 OR 分支为真。

第 2 项在 N1 有 101 条上下文证据边，但其中没有观察到需清零的非零近零候选。一般停车任务、状态恢复、未知修改、不同路径或其他私有上下文，仍是 `Near-Zero Context Unresolved`。运行未决近零数为 0 **不能说明一般可识别**；N1 有 382 条上下文未限定的边，因为它们不需要未知清零条件即可核验，未被混计为近零未决。

独立资格函数不接收被核验位移，不利用公开终速选择停车上下文；终速只用于独立选择后的输出一致性检查。未决分支仅允许源码两种精确替代 `{u_pre,0}` 导出的必要支持，范围一致不记 Exact。接口中解析测试的 False 真值不能自动迁移成真实运行 False 证明。
