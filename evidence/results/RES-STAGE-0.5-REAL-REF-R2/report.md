# Stage 0.5 R2 formal real-reference rebuild

This package rebuilds the approved real references only. US-101 is the primary highway risk reference, Lankershim is an independent auxiliary urban risk reference, and pNEUMA is urban kinematics only. No SUMO sample, calibration, coverage threshold, Gate decision, or Protocol Lock is included.

The bounded state tables are engineering previews. Formal P2 counts and rates come from the complete Stage 0.2 R4 event and exposure references; sampled rows must not be used to recompute P2 rates. pNEUMA duration-weighted statistics are cited from the sealed Stage 0.3 R2/R3 summaries because the canonical state table carries eligibility but not interval durations.
