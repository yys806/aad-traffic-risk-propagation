设内部步长为 (h)，步初速度 (v_0\geq0)，内部候选终速为 (u\)，内部常加速度 (a=(u-v_0)/h\)。这不是 TraCI 对外平均加速度。

正常分支 (u\geq0\)：

\[
\Delta x=\frac{v_0+u}{2}h,\qquad v_{\rm public}=u.
\]

提前停车分支 (u<0\)、(v_0>0\)：

\[
t_{\rm stop}=-v_0/a<h,\qquad
\Delta x=-\frac{v_0^2}{2a}=\frac12v_0t_{\rm stop},\qquad
v_{\rm public}=0.
\]

这是源码分支的解析改写，来自积分到真正停止时刻，不是用最终非负速度补齐整个步长。恰好步末停车 (u=0\) 时，两种表达相接，(t_{\rm stop}=h\)。初始已停止且负候选终速时位移仍为零。

`updateState` 对外保存的加速度为

\[
a_{\rm public}=\frac{\max(u,0)-v_0}{h}.
\]

提前停车的不同负 (u\) 都产生相同公共终速0和相同公共平均加速度。故这两个 getter **不具有可逆性**。禁止用待检查的位移反解 (u\) 再验证该位移，这会构成循环论证。

只有公开终速0而无独立内部观测时，当前可以验证必要范围：

\[
0\leq\Delta x\leq\frac12v_0h.
\]

范围检查使用同一个 `1e-6 m` 数值松弛量；范围一致只排除一部分异常，不证明正确停止时刻、加速度或精确积分。Euler 使用 (\max(u,0)h\)，不属于本协议；不能把 Euler 与 ballistic 混为一个步长敏感性比较。

源码还有一个可研究的受限观测途径：[第4589–4619行](https://github.com/eclipse-sumo/sumo/blob/fa7df22d7f1c4ae245192ecc32410a49f1ffb2a3/src/microsim/MSVehicle.cpp#L4589) 非行为决策步可能沿用前一步加速度；TraCI 有 `getLastActionTime`。必须独立确认决策时刻、其他约束和实现分支后才可利用。**当前冻结微型计划没有记录该时刻，未验证该重建，不事后利用它提升停车资格。** 一般行为决策步的负候选终速仍需独立调试观测。

## 3. 旧审计为什么不足

检查当前 B1 `run_worker` 源码，而非猜测旧运行：相邻记录检查同一ID、同一edge/lane和0.05s间隔，只对速度变化超过 `1e-5 m/s` 的边使用梯形关系。`for vid in sorted(data)[:10]` 每步重新选取当前订阅ID前十名，车辆进入/驶出后集合会变化。

这不是预先固定的十辆车队列。它偏向较早排序的计划车辆和在场更久的车辆；没有完整筛查匀速、持续停车及其余车辆；ID再出现时也没有独立 incarnation 契约。现有相同edge/lane和时间检查能阻止部分坐标跳变，却不能证明全部身份与坐标异常被覆盖。

封存的78,495条是该选择机制产生的变速检查边，不是全部边，也不是固定十辆车的覆盖率。没有保存抽样总体及异常边端点，无法由此计算总体覆盖、遗漏大残差的概率或归因最大残差。浮点时间差、位置精度可能产生小残差，但不能仅凭残差量级归因；微型正常分支的约 `1e-14 m` 也不能替旧C排除其他问题。

新 `stage_0_5_stopping_contract.py` 的契约：

- 每个已观测活动车辆的每条相邻边均轻量筛查；同一run/vehicle/incarnation、有限非负速度、精确一个内部步（时间比较容差 `1e-9 s`）、同edge/lane，才允许相减局部坐标。
- 分开统计正常、未停减速、已停、起步、明确提前停、明确步末停、停车时刻未识别、坐标转换及观测不足。独立带符号终速只接受解析输入或调试轨迹；本次真实微型场景没有这种轨迹。
- 坐标转换/显式不连续不直接相减；没有独立验证的全局里程映射就不可评价。公共速度很小但非零时不任意归零。
- 所有边保留计数、最大值、最坏边、残差方向和原因。异常最多保留严重度前16条，仍记录全部异常数及未保留数量；分支例子有界。每分支最多2048个确定性哈希样本用于中位/P95/P99，明确区分样本与总体分位；全量最大值不受抽样影响。
- 可选哈希cohort只控制详细覆盖说明，不关闭全量轻筛。本次modulus=1。有限端点无法发现伪装成正常运动的未标记teleport，需独立SUMO异常和生命周期审计配合。

每条异常包含run/合成工程车辆ID/incarnation、时间、位置、速度、step、edge/lane、分支、实际/预期位移或范围、残差/越界与原因。没有无限保存全部状态；本次微型完整状态仅在本地胶囊。

## 6. 队列的观测层与资格层

Observation Layer保留时间、坐标支持、车辆/身份、车道、车长、前后序、物理净间距、低速/停车车数、每车道密度、实际在场/进入/驶出、计划已到达/外部pending、独立入口空间证据和下游服务上下文。密度分母使用声明支持的车道数，不用当前有车的车道数。`position_m` 是车前端，物理后沿为position−length。

当前参考实现是**已验证单edge、同车道坐标域的合成契约**；未自动映射跨edge、junction或多路径。多车道各自连接，不拼成一条队列；lane change打断时间连续性。这可能产生保守漏检，应标观测受限，不能偷偷桥接。真实运行接入还必须分别提供全网守恒与观测域进出账；当前合成frame的present/counters与所列车辆同域，不可直接把全网counter和局部子集混用。

Qualification Layer逐层报告：

| 现象/候选状态 | 必要证据与限制 |
|---|---|
| 局部低速状态 | 指定域内速度低于描述阈值，单车即可观测；不是队列 |
| On-Road Queue Observed | 至少两个在路低速车辆满足空间连接；另有下游服务上下文。没有上下文仅报告慢车空间簇，原因Unresolved |
| Upstream Queue Extension Observed | 相同已验证坐标/同车道、相邻时间匹配组件，其上游边界区间向更小坐标移动；保留区间和历史，不拟合真实交通波速度 |
| Inlet-Adjacent Queue Observed | 内部队列边界的支持区间到达预声明入口邻近空间；区间跨界则Unknown |
| Entry Spillback Supported | 下游锚定的同一路径队列持续到入口邻近区，且独立入口空间约束证据、有效到达/服务上下文与已到达未插入车辆共同存在 |
| No On-Road Queue | 在足够观测域、有效观测下未识别队列；不推断域外不存在 |
| Evidence Insufficient | 坐标/身份/时间/支持错误，前沿出域、缺少因果上下文或不能识别连续性；不填零、不虚构前沿 |

外部待插入需求始终独立计数，不能并入道路密度，不能单独推出内部回溢。Entry Spillback Supported仍是有限工程证据标签，不使用Confirmed，不证明唯一原因；`supported=false`表示证据未满足，不能等同于物理上不存在回溢。内部慢车/拥堵可以被观测，同时数值或测量质量仍阻断；二者不互相抵消。

当前 `onroad_queue_observed` 是有服务上下文的**瞬时队列候选**，并不自动表示持续队列已经合格。入口回溢单独施加持续时间。通用队列持续资格、实际车群周转下的身份匹配和更复杂拓扑仍需接入级验证，不能把合成快照的瞬时检测外推为实测持续拥堵识别已完成。

## 7. 三种空间方法及时间规则

旧网格的严格性有合理用途：50m、每格≥2辆低速、连续锚定下游，提供很强的特定形态资格；不满足不等于全部内部低速不存在。其并非一般队列的必要条件：网格边界、稀疏前沿、释放间隙会断链，跨车道合并可能把不相关慢车拼接。50m不随车长/间距变化，不能保证物理接触关系。旧末60s入口资格≥25%也只是冻结的特定持续性规则，本次不重算、不修改、不让旧C获准。

新网格候选：仍50m，以车道分别计算占据与低速占比；非空格中至少1低速且低速占比≥0.5，连续活动格合并，总计至少2车。空格不补齐；网格只给边界支持区间，不伪造精确前沿；同格仍可能合并分离车群。它便于可视化，但不解决全部连接问题。

车辆连接候选：每车道按前端坐标排序，相邻车辆均低速、同edge、保险杠净间距在 `[0,10]m` 才连接；中间快车、负间距、断开的车群、不同车道/edge不桥接。组件至少2车。上游边界为最上游车后沿，附坐标不确定区间。它依赖真实车长、坐标、顺序与拓扑，无法据当前合成测试确认实际道路上的充分性/必要性。

共同时间候选：1s观测，必须连续；缺帧、非单调时间、坐标改变、换道或释放导致中断，不插值、不平滑。入口持续2s意味着三个连续快照；这只是测试尺度，**不等于现实持续拥堵阈值**。上游扩展历史与当前队列状态分别输出，不能因为曾扩展就覆盖当前No Queue。

| 候选值 | 依据与批准状态 |
|---|---|
| 低速5m/s、停车0.1m/s | 5继承B1描述口径；0.1是工程描述候选，非科学Gate |
| 网格50m、低速占比0.5 | 50保留便于旧法对照；0.5为合成候选，未从C调参 |
| 最小2车、连接净距10m | 需要观察相互空间关系；10m取两个合成5m车长，**没有真实队列间距识别依据** |
| 入口/锚定各50m | 明确物理支持，保留B1入口尺度，未来几何需重新核验 |
| 持续2s、采样1s、位置不确定0.01m | 独立合成测试假设；现实精度、持续时间和释放处理均待批准 |

这些数值只冻结为 `Candidate; synthetic demonstration only`，不是已批准交通测量协议。旧C没有参与选择。

## 8. 独立合成真值与结果

完整输入、真值与42行方法结果在 `synthetic_queue_truth.json` / `synthetic_queue_test_matrix.json`。14个案例包括要求的十类，另加同格断裂、孤立慢车、换道连续性与原因未知。真值先于微型运行冻结。
