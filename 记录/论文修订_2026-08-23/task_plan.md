# 顶刊标准全文一致性修订计划

## 目标

依据 2026-08-23 全文审查，修正主论文、Methods 工作稿、符号规范和实验预注册之间会影响识别、实验执行或解释边界的问题。所有实验数值继续保留为冻结前参数，不提前填写结果。

## 阶段

- [x] 1. 修正 Stage I 主分析集合、消息溯源和效应判定
- [x] 2. 修正 Stage II 消息采用、连通场景归因和控制目标
- [x] 3. 补齐实验设计、统计口径、缺失值和随机流规则
- [x] 4. 统一符号、预测编号、术语和章节衔接
- [x] 5. 同步 Methods 工作稿并完成 LaTeX、引用和全文复核

## 不变边界

- Methods 只定义模型、识别、实验、指标和统计规则，不提前写 Results。
- 正式主效应采用 intention-to-run 原则，不按处理后响应筛除正式运行。
- Stage I 识别效应，Stage II 优化控制；后者不能反证前者。
- DRIFT 仅作上游参考，不修改其文件。
- 未经校准或实验确认的数值不虚构。

## 错误记录

| 错误 | 处理 |
|---|---|
| 排版补丁第一次因效率公式上下文多出一个对齐符而未匹配 | 重新读取真实行并拆为最小补丁 |
| 符号表与预注册联合补丁因动作代价行的花括号写法不匹配而未应用 | 重新读取符号表并分别修改两个文件 |
| 候选消息语义补丁因主稿段落包含额外引导句而未匹配 | 读取真实段落后按完整行与短公式分别修改 |
| ITR 与效率权重补丁因 LaTeX 花括号上下文不匹配而未应用 | 作为确定性的跨文件符号重命名，使用 UTF-8 无 BOM 的机械替换并立即检索验证 |
| 评估分布补丁因 P2 说明段包含额外后续句而未匹配 | 读取实际段落后完整替换并同步工作稿与符号表 |
